关于国家教材建设重点研究基地（高等学校理学教材研究）规划课题发布的通知

日期：2025-10-24 点击数：

本科生院、教师教学发展中心、数学学院、物理学院、化学学院、生命科学学院、商学与管理学院：

为深入贯彻党的二十大和二十届二中、三中全会精神，贯彻落实习近平总书记在全国教育大会上的重要讲话和关于教材工作的重要指示精神，落实《教育强国建设规划纲要（2024—2035年）》部署要求，依据《国家教材建设重点研究基地（高等学校理学教材研究）课题管理办法（试行）》，现启动国家教材建设重点研究基地（高等学校理学教材研究）2025年规划课题申报工作。有关事项通知如下：

一、课题研究方向

本次教材研究规划课题重点围绕以下研究方向开展，申报者可结合所在学科专业特点，在对应方向下自主拟定具体课题名称。

研究方向：教材数字化转型与智能化应用研究、高水平教材建设队伍培养、教材研究队伍建设、教材研究人才培养、教材建设的激励机制等。

二、申报要求

1. 申报人须遵守中华人民共和国宪法和法律，具有独立开展研究和组织开展研究的能力，能够承担实质性研究工作，品行端正、学风严谨优良。

2. 申报人须具有副高级（含）以上专业技术职称（职务）。

3. 同一人员作为项目组成员同年度最多可参与2个教材研究项目的申报。项目组成员参与须征得本人同意。

4. 项目申报人须依托所在单位申报。基地不直接受理个人申报。

5. 数学学院、物理学院、化学学院、生命科学学院限报4项，本科生院、教师教学发展中心、商学与管理学院限报2项。

三、申报流程及时间安排

1. 自本通知发布之日起，各单位可通过基地网站（https://nrcem.jlu.edu.cn）下载《XXX单位-教材基地2025年规划课题汇总表汇总表》、《XXX（单位）-XXX（项目负责人）-教材基地2025年规划课题申报书》。

2. 材料提交截至时间为2025年11月5日16点，纸质材料请报送至国家教材建设重点研究基地（高等学校理学教材研究）办公室（鼎新图书馆9楼），电子版材料（《汇总表》、《申报表》须为盖章扫描件与可编辑文档）请发送至quxr@jlu.edu.cn，邮件主题请注明“【教材基地2025规划课题申报】XX单位”，逾期不予受理。

3. 国家教材建设重点研究基地（高等学校理学教材研究）将组织教材领域专家进行评审，确定立项名单及资助等级。

4. 评审结果将在基地网站（https://nrcem.jlu.edu.cn）公示5个工作日，无异议后发布立项通知。
