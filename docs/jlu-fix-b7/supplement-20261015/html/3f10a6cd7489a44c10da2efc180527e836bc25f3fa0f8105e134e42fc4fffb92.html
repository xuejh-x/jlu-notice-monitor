关于2026年下半年成人高等教育本科毕业生申请学士学位工作的通知

作者：发布时间：2026-09-15浏览次数：

各自学考试主考学院、网络教育各校外学习中心、成人教育毕业生：

根据《吉林大学学士学位授予工作细则（暂行）》的相关规定，现将2026年下半年成人高等教育本科毕业生（包含高等教育自学考试、网络教育、成人教育毕业生）申请学士学位工作的有关事项通知如下：

一、申请学位条件

1.已取得吉林大学成人高等教育（含自学考试、网络教育、成人教育）本科毕业证书；

2.参加符合申请吉林大学成人高等教育学士学位条件的外语考试，并达到符合条件的成绩，具体可参加的外语考试参见《吉林大学成人高等教育学士学位授予工作细则（暂行）》https://dec.jlu.edu.cn/html/xljy/jxzl/xj/sylc/2024081582.html  （成人教育毕业生参看细则中关于外语水平规定的第4、5、8点）；

3.符合吉林大学成人高等教育学士学位其它授予条件（参见《吉林大学成人高等教育学士学位授予工作细则（暂行）》）；

4.办学单位及学生个人必须确保申请成人学士学位毕业生的毕业论文符合“全国本科毕业论文抽检信息平台”论文上传标准的要求。

二、申请学位方式、材料

1.继续教育学院负责成人高等教育、网络教育毕业生申请学士学位的组织工作，各自学考试主考学院负责高等教育自学考试毕业生申请学士学位的组织工作。各单位须通知拟申请学士学位毕业生持毕业证书、成绩单、外语合格证书、身份证等原件及复印件到相关单位进行审核（审核后原件返还学生本人，留复印件备查）。成人教育毕业生向在校就读期间班主任提出学位申请，由各班主任初步审核其相关条件并向继续教育学院提出申请以及提供相关材料。

根据学位授予信息管理平台有关要求，各单位需按专业准确填写附件 1.《吉林大学申报成人学士学位名单及成绩汇总表》和附件2.《申请学士学位上报数据表》，附件1和附件2纸质版须由学院分管负责人签字并加盖公章，报送至继续教育学院，电子版发送至邮箱：xjb309@jlu.edu.cn。

2.各单位务必审核拟申请学士学位毕业生提交的照片是否符合标准。电子版照片格式标准如下：大小为5K-200K，像素为宽110-390、高150-576，照片背景为蓝色，被拍摄人服装要求为白色或浅色系，照片为JPG格式，用身份证号作为文件名。学位照片必须保证与学历照片（毕业证书照片）一致。如因提交的电子版照片与学历照片不一致导致最终纸质学位证书与学信网数据不一致，责任自负。

3.高等教育自学考试毕业生申报资格及成绩由主考学院初审，继续教育学院复核。主考学院学科学位评定分委员会讨论通过后将附件3.《吉林大学成人学士学位授予审批意见表》纸质版送交继续教育学院。

4.自学考试各主考院校需按照要求上报有关材料。

（1）前期提供的电子版及部分纸质版材料（仅经办人签字）包括以下四项：

①附件1吉林大学申报成人学士学位名单及成绩汇总表（电子版及纸质版）；

②附件2申请学士学位上报数据表（电子版及纸质版）；

③身份证复印件、毕业证复印件、外语考试合格证、个人成绩单（纸质版）；

④个人照片（电子版）。

以上材料报送时间为2026年10月16日16：00前。

（2）通过数据初审之后需要提交的纸质版材料（经办人及负责人签字）包括以下三项：

①附件1吉林大学申报成人学士学位名单及成绩汇总表；

②附件2申请学士学位上报数据表；

③附件3吉林大学成人学士学位授予审批意见表。

具体时间另行通知。

三、平台填报的截止时间

针对网络教育毕业生及成人教育毕业生的学位申请，继续教育学院学位填报平台于2026年10月16日16:00关闭，逾期不予开放（网络教育毕业生及成人教育毕业生只由各学习中心及成人教育班主任在平台填报数据，如无特殊情况，不需要提交纸质版材料）。

四、收费标准

根据吉政办发［2006］31号《吉林省人民政府办公厅转发省教育厅等部门关于进一步规范高等学校教育收费管理若干规定的通知》的有关规定，申请学士学位每生交学费200元（校内专业学院负责管理的自考学生，由专业学院联系吉林大学财务处收费科沟通交费事宜）。

五、关于学位论文报送的重点提示

根据教育部学位与研究生教育发展中心《关于通过全国本科生毕业论文（设计）抽检信息平台开展2025/2026学年度本科毕业论文（设计）抽检工作的通知》的相关要求，办学单位申请成人学士学位时，除发送原有申请材料之外，必须同时发送所有申请学位毕业生的毕业论文原文、查重报告简版以及相应的数据报送表，并必须确保以上材料可以按要求上传至“全国本科毕业论文抽检信息平台”。

六、工作要求

1.成人高等教育本科生申报学士学位工作应严肃认真、保证质量，严禁弄虚作假。

2.各相关学院务必按照规定时间开展相应工作，因超期未完成工作影响学位授予工作由相关学院负责。
