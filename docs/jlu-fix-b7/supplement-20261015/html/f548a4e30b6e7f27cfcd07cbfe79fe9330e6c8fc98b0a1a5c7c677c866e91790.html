基础医学院召开学习贯彻习近平新时代中国特色社会主义思想主题教育总结会议

发布时间：2023-09-15    

9月13日下午，基础医学院学习贯彻习近平新时代中国特色社会主义思想主题教育总结会议在二楼报告厅召开。学校主题教育第12巡回指导组副组长籍海春、联络员宫新统、基础医学院领导班子成员、党委委员、纪委委员、学术委员会、学位评定委员会、教学委员会主要负责人、党支部书记、各学系、中心、科室负责人、教职工代表、学生代表等参加会议。会议由党委书记王晓荣主持。

会议共分为三项议程。首先，王放院长通报了学院主题教育专题民主生活会情况。

王晓荣书记从理论学习、调查研究、推动发展、建章立制等方面对学院主题教育完成情况做了系统回顾和全面总结。她表示，学院将在今后的工作中更加深刻领悟“两个确立”的决定性意义，切实增强“四个意识”、坚定“四个自信”、做到“两个维护”，不断巩固和拓展主题教育成果成效。持续推动“以学铸魂”、“以学增智”、“以学正风”、“以学促干”，推动基础医学事业高质量发展，切实把主题教育成果转化为干事创业的工作热情，为加快建设教育强国贡献基础力量。

学校主题教育第十二巡回指导组副组长籍海春作总结讲话。他充分肯定学院主题教育取得的成绩，学院党委认真谋划，精心组织，高起点开局，高质量推进，高标准落实，政治建设得到新加强、理论武装取得新成效、调查研究取得新成果、推动发展取得新进步。同时提出四点工作要求：一是进一步加强理论武装，坚持不懈用习近平新时代中国特色社会主义思想凝心聚力；二是进一步提高政治站位，坚定不移把党中央决策部署落实到学院建设发展的具体实践；三是进一步聚焦教育强国建设，坚持扛起新时代高校肩负的历史使命；四是巩固教育成果，做好主题教育后半年，认真总结和全面梳理主题教育成果，持续抓好理论学习和检视整改、建章立制。
