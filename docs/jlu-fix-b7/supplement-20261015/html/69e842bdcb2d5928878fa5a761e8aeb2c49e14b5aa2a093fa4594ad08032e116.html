关于加强春季学期传染病防治工作的通知

发布时间：2025-03-05

校内各单位：

春季是万物复苏的季节，同时也是各类传染病的高发期。根据国务院联防联控机制疫情防控组发布的《关于做好2025年春季新冠病毒感染等重点传染病防治工作的通知》，为了保障全体师生的健康安全，维护正常的教学和生活秩序，学校将进一步加强春季传染病的预防和控制工作。现将有关事项通知如下：

一、常见春季传染病类型

春季常见的传染病包括但不限于：

1. 流感：由流感病毒引起，症状包括发热、咳嗽、咽痛、全身乏力等。

2. 诺如病毒感染：主要症状为呕吐、腹泻、腹痛等。

3. 水痘：由水痘-带状疱疹病毒引起，症状为皮肤出现红疹、水疱，伴有发热。

4. 手足口病：常见于儿童，症状为手、足、口腔等部位出现疱疹。

5. 麻疹：症状包括高热、咳嗽、流涕、眼结膜炎及皮肤出现红色斑丘疹。

6.结核病：结核分枝杆菌引发，常见症状为咳嗽、咳痰、低热等。

二、预防措施

1.加强健康监测：校内各单位要加强对师生的健康监测。落实好晨午检、健康教育、环境消毒、因病缺勤缺课追踪与登记等措施。如发现疑似传染病病例，请及时上报上级部门。

2.加强个人卫生：勤洗手，尤其是在就餐前、如厕后、接触公共物品后；咳嗽或打喷嚏时，请用纸巾或肘部遮挡口鼻，避免飞沫传播；不与他人共用毛巾、餐具等个人物品。

3.保持环境卫生：教室、宿舍、食堂等公共场所应定期通风，保持空气流通。定期对公共区域进行消毒，尤其是门把手、桌椅、电梯按钮等高频接触部位。

4. 增强免疫力：保持规律作息，避免熬夜，确保充足的睡眠；合理膳食，多摄入富含维生素和矿物质的食物；适当进行户外运动，增强体质。

5.及时就医：如出现发热、咳嗽、腹泻、皮疹等疑似传染病症状，请及时到校医院或就近医疗机构就诊；确诊传染病的师生应积极配合治疗，并上报辅导员及学院。

6.加强预防接种：继续动员引导师生、基础性疾病患者等重点人群接种流感等疫苗，提升人群免疫水平。

三、开展健康教育

学校将通过宣传、线上讲座、培训等形式，普及传染病防治知识，提高师生的防病意识。近期将开展一次线上讲座，邀请吉林大学第一医院李亚男，主任医师，教授，博士生导师，现任小儿呼吸科副主任，感染亚专业组长。擅长各种呼吸系统疾病如肺炎、哮喘、慢性咳嗽、反复呼吸道感染、闭塞性细支气管炎等疾病的诊治。

时间：3月7日晚18点-19点30分

讲座地点：腾讯会议室 会议号：404376200。

讲座内容：春季传染病的预防与治疗。

欢迎师生观看。
