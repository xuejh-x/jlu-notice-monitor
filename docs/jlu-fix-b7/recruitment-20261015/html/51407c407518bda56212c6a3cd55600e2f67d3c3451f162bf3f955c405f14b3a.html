关于包大恒等职务任免的通知

时间：2026-05-09    点击：


校人字〔2026〕97号


校内各单位：


根据《吉林大学第二医院科级干部选拔任用实施方案（2026年修订）》有关规定，经学校研究决定，


聘任：


包大恒为第二医院审计工作部主任（正科级）；


张贺丽为第二医院社会公益办公室主任（正科级）；


胡明为第二医院人力资源部主任（正科级）；


赵凌志为第二医院采购中心主任（正科级）；


陈慧斯为第二医院物资供应中心主任（正科级）；


冉晓宇为第二医院运营管理部主任（正科级），免去其第二医院采购供应部副主任（副科级）职务；


张磊为第二医院安全生产与应急办公室主任（正科级）。


以上人员职务任免时间为2026年3月11日。
