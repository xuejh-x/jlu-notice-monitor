庆祝吉林大学计算机学科成立50周年系列暨 计算机科学技术专家讲座（十）——庞巍

发布日期：2026-06-29     作者：     编辑：符号与知识     点击：

报告题目：BCML实验室科研成果概览及基于潜在类别分析的AI公平性量化研究

报告时间：2026年7月1日14：00-15：00

报告地点：吉林大学中心校区王湘浩楼B122

报告人：庞巍

报告人简介：

庞巍现为英国赫瑞瓦特大学计算机系教授。他是英国国家机器人中心和爱丁堡机器人中心的核心学术成员。现领导赫瑞瓦特计算机系的生物启发计算和机器学习实验室。

他的主要研究兴趣包括生物启发算法，机器学习与数据挖掘及其在健康，材料，和循环经济等领域的应用。他参与或主持的项目共计超过1000万英镑，近年来在ICML，CVPR，NeurIPS，AAAI等会议发表多篇论文。

报告内容简介：

本次报告将分为两个主要部分。首先将简要介绍生物启发计算和机器学习（BCML）实验室的基本情况，并重点分享过去几年团队在承担多项英国国家项目（如DCEE、RAInS、Manufacturing Immortality等）中积累的丰硕成果与宝贵经验，为听众展现科研团队在大型前沿项目运作上的宏观视野与实践心得。

随后，报告将深入聚焦于近期受英国工程和自然科学研究委员会（EPSRC）资助的大型项目——PRIME。在“不让任何人掉队（Leave No One Behind）”的倡议背景下，AI工具在健康、能源、住房等多部门资源分配决策中的公平性愈发重要。庞教授将详细阐述其团队在PRIME项目数据分析方面的核心贡献，即创新性地利用潜在类别分析来量化用户定义群体之间的跨部门交叉差异。

该研究结合了EVENS和2021年英国（英格兰与威尔士）人口普查等真实数据集进行验证，并与政府公开指标进行了相关性分析，准确揭示了少数族裔群体内部及群体间的显著差异。这一研究成果不仅为政策制定中的定向干预提供了坚实的科学依据，也为更好的理解和确保机器学习系统中的公平性提供有价值的洞见。
