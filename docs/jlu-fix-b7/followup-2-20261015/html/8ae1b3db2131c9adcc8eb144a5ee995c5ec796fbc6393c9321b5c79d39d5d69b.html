关于开展2022-2023学年对口支援新疆塔里木大学、青海师范大学退休教师招募工作的通知

发布时间：2022-07-27    [    动态浏览次数： 次    |    发布人：    ]

各适龄退休教师：

为贯彻落实教育部《高校银龄教师支援西部计划实施方案》（教师函〔2020〕1号）精神，我校于2020-2022年共选派了23名优秀退休教师支援塔里木大学，在教育部老干部局和塔里木大学取得了较好的反响。根据教育部办公厅《关于做好2022—2023学年高校银龄教师支援西部计划有关实施工作的通知》要求，塔里木大学和青海师范大学分别成为我校对口支援高校。为持续推进优秀退休教师支教、支研工作，不断加强西部对口支援高校的教师队伍建设和教育教学质量，助推西部高校扩大办学规模与高质量发展，现将塔里木大学、青海师范大学招聘“高校银龄教师支援西部计划”教师（以下简称“银龄教师”）有关事项通知如下：

一、需求计划

2022-2023学年，塔里木大学面向教育部直属高校新聘银龄教师73名，详见《2022-2023学年塔里木大学银龄教师需求计划表》（附件3），青海师范大学面向吉林大学聘请银龄教师12名，详见《青海师范大学2022-2023学年银龄教师计划需求表》（附件4）。

二、应聘条件

我校退休教师，年龄在70岁以下，申请线上教师年龄一般在75（含）岁以下，具有副高级以上职称，教育教学经验丰富；政治可靠，师德高尚；身体健康，能从事正常的教学科研工作。

三、岗位职责

银龄教师以课程教学、教学指导、课题研究、学科建设指导为主，以短期授课、远程教学、同步课堂、学术讲座（报告）为辅。采取“传、帮、带”方式，以先进教学方法和科研理念指导本学科教师做好教学和科研工作，详见《塔里木大学2022-2023学年招聘“高校银龄教师支援西部计划”教师公告》（附件1）和《青海师范大学2022—2023学年高校银龄教师支援西部计划工作方案》（附件2）。

四、招聘程序

采取个人报名、资格审核、组织援派等招聘程序进行。

1.个人报名。填报《银龄教师报名登记表》（附件5或附件6）。其中申报塔里木大学的支教老师填报附件5，将申请登记表发送至塔里木大学受援学院指定邮箱（邮件命名：银龄教师+姓名+学科）；申报青海师范大学的支教老师填报附件6，将申请登记表发送至邮箱bleding@126.com。

2.资格审核。受援高校对报名人员材料进行审核，择优确定拟聘银龄教师名单。

3.组织援派。受援高校将拟聘银龄教师名单报支援高校，由支援高校协助开展考察、体检等援派工作。

4.签订协议。受援学校与银龄教师、支援高校签订协议。

5.上岗任教。按开学时间或约定支援时间来校开展支教、支研工作。

五、工作待遇与政策保障

（一）经费保障

1. 长期银龄教师税前补助标准为正高级职称教师10万元/年、副高级职称教师8万元/年，按月发放。受援省份和高校根据实际情况，可适当提高补助标准，高出部分由受援省份和高校自行负担。

2. 短期银龄教师税前补助标准为正高级职称教师8000元/月，副高级职称教师6400元/月。

3. 通过在线教育、微信辅导、同步课堂等柔性方式支教，课时费为100元/课时。受援省份和高校根据实际情况，可适当提高课时费标准，高出部分由受援省份和高校自行承担。

4. 到校开展学术讲座（报告）等的劳务费或咨询费参照受援高校相关标准执行。

5. 受援高校提供岗前培训费、派出地往返交通差旅费、意外保险费、必要的商业医疗保险费、采暖费等保障性经费。支援高校提供派出前体检费、选派工作经费等。

（二）政策保障

1.教师援派期间人事关系、现享受的退休待遇不变。长期援派教师，享受受援单位同类同级别人员的各项福利待遇，按受援地有关规定正常享受探亲和寒暑假。未休假的，按有关规定可由受援单位报销一名家属往返受援地的交通费。

2.受援高校会为援派教师创造良好的工作环境，提供必要的教学科研设备和生活条件，做好日常服务工作，落实相关待遇与保障措施。

3.我校将关心关注援派教师及其家属，全力解决他们工作和生活中的困难；负责提供远程授课设施设备，协助受援高校做好后勤保障工作。

4.援派期间因病因伤发生医疗费用，按本人医疗关系和有关规定办理；援受双方可通过商业医疗保险、校内医疗互助基金等多种方式灵活提供补充支持。患有慢性疾病需定期开药的教师，我校会尽可能提供必要的便利。援派期间生病或受伤的教师，参照受援学校相关制度，给予探望慰问等待遇。

六、报名时间

报名时间从即日起至8月20日。其它未尽事宜，请与相关受援高校或我校离退休工作处联系。

塔里木大学联系电话：0997-4680614（许老师），4682638（严老师）；

青海师范大学联系电话： 0971-6317924，13250586417   （侯老师）；

吉林大学离退休工作处电话：0431—85168314（曲老师）
