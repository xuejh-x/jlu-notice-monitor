吉林大学2026年辅导员招聘补充公告

时间：2026-04-23    点击：


校人字〔2026〕85号


《吉林大学2026年辅导员招聘公告》（校人字〔2026〕82号）已于2026年4月17日发布。为进一步做好辅导员选聘工作，经研究决定，对原公告内容中年龄条件做出调整，并延长报名时间。现公告如下。


一、年龄条件由“应聘人员硕士研究生毕业的，年龄应未满30周岁（1996年1月1日及以后出生）；博士研究生毕业的，年龄应未满33周岁（1993年1月1日及以后出生）。”调整为“应聘人员年龄应未满38周岁（1988年1月1日及以后出生）”。


二、报名截止时间延长至2026年5月2日16:30。原公告中其他信息不变，此前已经报考人员继续有效，无需再次报名。
