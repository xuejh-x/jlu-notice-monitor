校园网主干光缆运维服务
发布日期：2026-05-25 浏览次数：次

项目名称：吉林大学校园网络主干光缆线路运维服务

预算金额：10万元（人民币）

服务范围：吉林大学7个校区

服务内容：

1.应急抢修

对学校网络光缆突发故障进行抢修，保证线路修缮后相关网络设备可以正常运行。抢修方案待与甲方确定后，按施工规范要求，确保安全的前提下在服务要求规定的时间内进行修复，并做好抢修记录。

2. 巡检维护

(1). 巡检主要任务，对架空及管线光缆线路存在的隐患进行处理，防患于未然。制止未经甲方许可，在光缆路由上进行可能造成破坏的施工活动。光缆线路的防腐蚀、防雷击、防强电的维护和测试。架空线路的检修，吊线、挂钩的检修更换等工作。巡检工作，每周一次，到相应校区按照维保考核要求登记并填写签到表，每月月末汇总当月抢修工程单及巡检工程单统一由维保单位交至工程部。

(2). 维护主要任务，建立健全光缆线路路由资料，在学校重大活动期间按任务下达要求，进行线缆线路值守工作。配合学校网络相关的运营商或教育网出口等相关单位，完成线缆维护工作。

3.服务范围

(1). 吉林大学各校区互联主干光缆，包含架空布放及地下铺设光缆巡检维护及抢修。

(2).吉林大学各校区校园网已覆盖的楼宇间互联光缆，及楼宇内配线间互联光缆巡检维护及抢修。

(3).吉林大学家属区光改区域主干段(一级分光器以上链路)光缆巡检维护及抢修。

(4).如应急抢修过程中，原线路确因客观原因无法使用，需更换整条线路（或更换路由布放），需征得甲方确认后方可实施，竣工后按照新建（改建）工程与甲方单独结算。

服务要求：

1.故障响应时间：接到报修3小时内到达故障现场。

2.故障抢修时间：一般性故障12小时内抢修完成。因不可抗力（如天气原因、自然灾害、线路产权等客观因素）导致抢修无法马上实施的，需向甲方说明情况，抢修时间可根据实际情况顺延。

3.严格按照国家有关通信光缆行业维修、维护规程进行操作。

4.当维护工作涉及其他部门或单位时，应主动与所在校区用户部以及工程部取得联系，制定出具体实施方案后方可进行。

5.维修工作前应做好相关安全措施，维修中应认真执行“安全操作规程”以及其他有关安全操作的规定，防止发生人员及设备仪器损坏事故。

6.维护工作应做好记录备忘，遇到重大问题及时请示并及时处理。

7.光缆抢修后，应进行详细的检查和妥善处理，并由甲方对光缆线路的传输质量予以验收。

8.因地制宜做好校园周期性、季节性维护工作。在雨雪，台风到来之前，对易受灾害影响或破坏的地段进行认真的检查，关键线路和重点线路应重点检查排除隐患，施工高发期对相关区域的校园光缆线路加强防护，尽可能减少抢修频度。

9.乙方及参与项目的乙方工作人员应具有以下资质：

乙方应具备有效的营业执照，并能够提供加盖公章的副本复印件。

乙方必须确保所有进场施工的人员，年满十八周岁且身体健康。

10. 乙方在施工期内各班组及个人要增强安全意识，做好自身安全保护，出现大小事故均由乙方负责，甲方概不负责。乙方要提供至少三名技术工人处理吉林大学光缆线路问题。

11. 乙方需要提供人员名单，当人员发生变化时，需及时通知甲方做好备案工作。

12. 乙方相应配置一台车辆，以便于技术工人处理各个校区光缆问题及运送工具与材料，车辆进出校园产生的所有费用由乙方自行解决。

13. 服务期间内，乙方遵守甲方制定的规章制度，服从甲方的管理，接受甲方的监督和检查。

14. 乙方应配备必要的维护设备（如光纤熔接机、梯子等）、维护工具、通讯工具，确保系统的正常维护。乙方应登记详细的代维系统运行管理和维护记录，确保代维线路的安全、可靠运行。

15. 甲乙双方应协商制定相应的考核办法，对乙方的服务工作进行评价，当乙方连续三个月不能达到考核评价要求，甲方有权终止合同，由此产生的损失，由乙方承担。

16. 除合同约定外，免费提供额外7个月服务期，完成服务内容内各项服务。

响应文件提交

1.所投服务报价

2.营业执照副本复印件
