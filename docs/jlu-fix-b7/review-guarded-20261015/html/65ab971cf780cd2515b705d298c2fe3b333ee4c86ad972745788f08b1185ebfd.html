    实验室会议室预约和使用规范
    发布日期： 2025-06-26  浏览：

  • 为规范实验室会议室管理，提高使用效率，保障各类会议顺利开展，现就会议室预约和使用相关事项明确如下：

    一、预约方式

    微信扫描二维码，通过微信小程序“简约会议室”在线预约。紧急情况可联系办公室预约。

    二、预约时间

    至少提前1个工作日预约，重大会议请提前3个工作日预约，临时取消需及时告知办公室。

    三、使用规范

    按预约时间使用，不得超时占用。

    爱护设备设施，保持环境整洁，会议结束后带走个人物品，恢复桌椅原状，关闭设备电源和门窗。

    四、注意事项

    优先保障实验室重要会议，不得擅自外借或改变用途，违反规定将暂停使用权限。

    五、其他说明

    设备故障及时联系办公室。
