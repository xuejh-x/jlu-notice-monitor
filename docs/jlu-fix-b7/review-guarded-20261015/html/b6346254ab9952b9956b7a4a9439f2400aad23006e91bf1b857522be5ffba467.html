手作雅香 静拾时光∣妇委会成功举办吉林大学女教职工“健康美丽计划”系列活动
来源： 发布日期：2026/09/29 点击量：

为持续推进学校“健康美丽计划”，丰富女教职工课余文化生活，提升个人气质与礼仪修养，缓解涵养优雅气质、提升礼仪素养、舒缓工作压力、陶冶身心情操。近日，由学校妇委会主办、吉林银行长春高新开发区支行承办的“手作雅香静拾时光”古法制香主题体验活动在中心校区鼎新图书馆四楼会议室顺利举行，全校70余名女教职工参加活动。活动由妇委会副主任刘星彤主持。

活动特邀吴艳红老师现场授课。吴老师现任云熹艺术画室素描教师、吉林省社区老年大学水彩兼任讲师，常年开展非遗文化与艺术体验课程，擅长将艺术审美融入日常生活，有着丰富的美育实践经验，为本次古法制香活动提供了扎实的专业指导。

活动现场环境清雅、香气怡人。在授课环节中，吴老师为大家普及传统香道的发展历史，详细讲解各类天然香料的特性、搭配技巧以及古法制香的基础工艺，分享香文化静心修身的传统内涵，让大家近距离了解传统非遗技艺，感受中华香道文化的独特韵味。在手作体验环节，参加活动的女教职工们认真跟随教学步骤，依次完成选料、研磨、配比、揉泥、塑形等一系列古法制香流程。大家暂时放下繁忙的工作，静心投入手工制作，相互交流制作心得、分享体验感受，在轻松舒缓的氛围中放松心情、舒缓压力，享受沉浸式手作带来的宁静与惬意。

本次古法制香体验活动将非遗传承、美育提升与身心疏导有机融合，既丰富了我校女教职工的精神文化生活，有效提升个人审美与气质修养，也增进了同事之间的沟通情谊，让大家在雅致的传统文化体验中涵养心境、调适状态，充分展现了我校女教职工从容优雅、积极进取的精神风貌。下一步，学校妇委会将持续落实“健康美丽计划”，贴合教职工实际需求，常态化开展形式多样、内涵丰富的文化活动，不断厚植校园文化底蕴，激励全体女教职工以昂扬饱满的精神状态履职干事、深耕教育岗位，为学校高质量发展贡献巾帼力量。
