吉林大学党委启动第五轮巡视工作
发布时间：2026-04-26 15:43 点击数：

4月24日，中共吉林大学第十五届委员会第五轮巡视动员部署会召开。校党委书记、党委巡视工作领导小组组长田辉出席会议并讲话。他强调，要深入学习贯彻习近平总书记关于巡视工作的重要论述，全面落实党的二十大和二十届历次全会精神，认真落实全国巡视工作会议精神，把树立和践行正确政绩观贯穿始终，坚定拥护“两个确立”、坚决做到“两个维护”，不断增强巡视监督震慑力、穿透力、推动力，以高质量巡视监督护航学校中国特色、世界一流大学建设。

田辉指出，党的十八大以来，以习近平同志为核心的党中央始终从战略和全局的高度谋划推进巡视工作，巡视监督成为管党治党的利剑、治国理政的利器。习近平总书记发表一系列重要讲话，作出一系列重要指示，为我们扎实推进巡视工作指明了前进方向、提供了根本遵循。要深学细悟习近平总书记重要讲话、重要指示批示精神，不折不扣落实党中央决策部署，强化使命意识和奋斗意志，更加坚定维护党的团结统一，坚定捍卫党的先进性和纯洁性。要从推动中国特色、世界一流大学加速发展，全面跃升的全局看待本轮巡视，突出使命担当，紧盯政绩观这个根本性问题，切实增强抓好巡视工作的责任感、使命感，为“十五五”开好局起好步提供坚强保障。

田辉强调，要突出政治巡视，重点围绕推动党中央决策部署落地见效、落实意识形态责任、推动高质量发展、推进从严管党治党、落实新时代党的组织路线、做好巡视“后半篇文章”六个方面，深入了解被巡视党组织政治建设、理论武装、基层党建、权力运行、正风肃纪、干事创业精气神等领域的真实状况，着力破解“上热中温下冷”“三个特殊论”，以及发展合力不足、师德师风、“躺平”“佛系”等突出问题，着力推动解决制约本单位高质量发展、师生反映强烈的深层次矛盾，推动问题见底清零，护航学校事业发展。

田辉强调，要突出责任落实，相关部门要各司其职、各负其责，深化上下联动、同向发力。巡视组要坚持问题导向，发扬斗争精神，敢于较真碰硬，善于深挖细查。被巡视单位党组织要切实增强接受巡视的政治自觉、思想自觉和行动自觉，扛牢全面从严治党主体责任，党政主要负责同志要严负其责，班子成员要切实履行“一岗双责”，自觉接受监督，切实做到以巡促改，以巡促建，以巡促治。全体巡视干部要切实提升政治能力和监督本领，坚持实事求是，依规依纪依法开展工作，严明纪律作风，筑牢思想防线，切实履行好巡视工作职责使命。

校党委副书记、纪委书记，国家监委驻吉林大学监察专员，党委巡视工作领导小组副组长胡漫主持会议。会上，党委副书记、组织部部长、党委巡视工作领导小组成员姚毓春宣读《中共吉林大学第十五届委员会第五轮巡视巡视组成员任职及任务分工》。根据学校党委统一部署，本轮巡视对12个院级党组织开展常规巡视。

党委巡视工作领导小组成员，相关职能部门人员，第五轮巡视巡视组全体成员以及被巡视单位领导班子成员参加会议。
