    国家安全学科粮食安全合作研讨会在长春市粮储局召开
    发布日期： 2026-03-30  浏览：

  • 为深入贯彻落实习近平总书记在听取吉林省委和省政府工作汇报时的重要讲话精神，进一步加强国家安全学科建设，拓展学科服务区域发展能力，2026年3月30日，公共外交学院、国家发展与安全研究院院长肖晞率队赴长春市粮储局，共同召开推进粮食安全合作研讨会。长春市粮储局党组书记、局长卢天恒主持会议。

    会上，市农业农村局党组成员、副局长孔翔介绍了长春市农业相关情况；市粮储局一级调研员、干部人事处处长衣丽伟介绍了长春市粮食有关情况。

    公共外交学院、国家发展与安全研究院院长肖晞介绍了国家安全学科有关情况，并着重介绍了交叉学科平台建设、粮食安全合作的背景及方向。她指出，粮食安全事关重大，吉林省是我国的产粮大省，推进粮食安全合作是落实习近平总书记“把论文写在祖国的大地上”的务实举措，国家安全学科团队有义务在服务国家战略发展中积极探索。

    市粮储局党组书记、局长卢天恒指出，下一步，双方将努力推动理论研究和实践应用深度融合，推动合作事项落地。在粮食安全政策研究、实验室平台建设、实践教学等方面加强合作，实现优势互补、互利共赢，为国家粮食安全做出积极贡献，更好服务国家安全战略。

    与会人员就粮食安全涉及领域进一步合作进行了交流研讨。
