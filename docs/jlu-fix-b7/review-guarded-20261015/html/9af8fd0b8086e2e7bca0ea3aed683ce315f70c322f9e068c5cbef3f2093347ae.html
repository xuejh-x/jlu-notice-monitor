关于开展2026年医学研究生创新实验设计大赛的通知

时间：2026-10-12        点击：


医学部各研究生培养单位：

为贯彻落实吉林大学医学教育创新发展专项会议精神，推进实施“白求恩医学拔尖创新人才培养工程”和“医学研究生培养质量提升工程”，强化科教协同育人，推动医学研究生早开题、早科研、早实践，提升医学研究生创新精神和科研能力，白求恩医学部组织开展2026年医学研究生创新实验设计大赛工作。现将有关事项通知如下：

一、活动时间

2026年10月-11月

二、参赛人员范围

医学部各研究生培养单位2025级、2026级在籍博士研究生和硕士研究生。

注：在往届医学研究生实验设计大赛中获得一、二、三等奖的研究生，不得重复参赛。

三、参赛组别与名额分配

   比赛设博士研究生、学术型硕士研究生、专业型硕士研究生三个组别。参赛名额根据各培养单位研究生数量按比例确定。

   注：各组别参赛名额不得调配，如名额未报满，视为放弃。
          四、参赛作品要求

    实验设计作品应为与本人课题研究方向相关的科学研究实验设计，要求具有创新性、科学性、可行性和应用性。要求学生本人独立完成或在导师指导下独立完成。

    作品要自主选题、自主设计、自主撰写，不得抄袭或借用指导教师各类基金项目的内容，可在各基金项目的拓展方向上选题。

    参赛作品不得与全国生命科学（创新创业）类、挑战杯、“互联网+”及全国大学生基础医学创新研究暨实验设计论坛等国家级和省级、校级赛事作品重复。

五、评比程序

   本项目以作品展示、专家评审方式进行，分为博士研究生和硕士研究生（学硕、专硕）组分别评比，分初赛和复赛两阶段。

   第一阶段：初赛阶段，2026年10月13日至2026年11月6日。由医学部各研究生培养单位组织实施，各研究生培养单位按分配名额（单独发至各院）推荐参加复赛。

   第二阶段：复赛阶段，2026年11月16日至2026年11月27日。由医学部医学研究生办公室组织实施，以线下答辩形式（PPT汇报）进行评审，答辩要求见附件1，专家评审确定奖项，颁发获奖证书并给予奖励。

六、奖项设置及数量

   奖项设置博士研究生、学术型硕士研究生和专业型硕士研究生三个组别分别设置一、二、三等奖，并予以奖励，对组织工作完成较好的培养单位颁发优秀组织奖。

七、相关要求

   请各单位研究生秘书于2026年11月9日前将本单位参加复赛名单汇总表（见附件2）、个人作品摘要（见附件3）、原创性声明（签字后扫描为PDF版，附件4）报送至医学部医学研究生办公室邮箱（所有材料均为电子版）。逾期申报及个人申报不予受理。相关内容解释权归白求恩医学部医学研究生办公室。
