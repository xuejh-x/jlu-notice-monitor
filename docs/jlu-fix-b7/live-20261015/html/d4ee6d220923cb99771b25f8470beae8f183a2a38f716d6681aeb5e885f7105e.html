“卡伦湖绿色经济青年特别论坛（2026）”会议论文入选名单

发布日期：2026-07-01编辑：国有经济点击：

党的二十届四中全会提出，牢固树立和践行绿水青山就是金山银山的理念，以碳达峰碳中和为牵引，协同推进降碳、减污、扩绿、增长，筑牢生态安全屏障，增强绿色发展动能。为深入贯彻党的二十届四中全会精神、加快培育绿色生产力，由卡伦湖绿色经济论坛组织委员会主办，吉林大学绿色金融与碳中和创新实验室、吉林省高校绿色金融与碳中和哲学社会科学实验室、吉林工商学院财政金融学院、吉林大学中国国有经济研究中心联合承办的卡伦湖绿色经济青年特别论坛将于2026年7月4日在长春举行。截至6月28日，本次会议共收到投稿近200篇，经评审委员会评选，现公布会议论文入选名单，具体名单附后。

衷心感谢每一位来稿作者！后续我们会统一发送回执，烦请尽快填写。

欢迎学界同仁继续关注和支持“卡伦湖绿色经济青年特别论坛（2026）”。期待各位学者莅临！
