第四届研究生清晏廉政论坛暨“廉政建设理论与实践优秀论文奖”征文启事

点击量：

“河清海晏，朗朗乾坤”是新时代廉政建设的价值追求。吉林大学廉政研究院是致力于廉政理论与实践研究、培养纪检监察人才、开展廉政学术交流、传播廉政文化、开展反腐倡廉国际合作的重要基地。为助力廉政研究不断向纵深拓展、迸发新见，鼓舞青年学者潜心钻研、勇于求索，吉林大学廉政研究院定于2026年9月举办第四届研究生清晏廉政论坛暨“廉政建设理论与实践优秀论文奖”评选。诚邀全国各高校及科研机构研究生踊跃撰文，共赴研讨之约。

一、征文主题及分议题

主题：廉洁文化建设与传播的路径创新

分议题（包含但不限于）：

1. 廉洁文化建设的传统渊源与现代转化

2. 数字技术赋能廉洁文化建设的理论逻辑

3. 基层社区廉洁文化传播的困境与路径

4. 廉洁文化建设的制度保障、协同机制与长效发展

5. 数字时代廉洁文化的国际传播与跨文化比较

二、主办单位

吉林大学廉政研究院（吉林省廉洁文化研究基地）、吉林大学行政学院

三、论坛时间及地点

1.时间：2026年9月（具体时间以正式邀请函为准）

2.地点：吉林省长春市（具体地点以正式邀请函为准）

四、论文征集

1.征文对象

国内高校与研究机构从事廉政建设与腐败治理领域学习与研究的博士、硕士研究生，及具有一定研究基础的高年级本科生。

2.论文要求

论文须围绕征文主题，具体题目不限，具有一定创新见解和学术价值；论文尚未在任何刊物公开发表；论文字数以15000字左右为宜，格式请参照《政治学研究》的发文体例及注释格式。

3.论文提交及评审

征文截稿时间为2026年8月15日；论文投稿邮箱为jlu_lzyjy@163.com；邮件主题命名为“姓名-单位-题目-研究生清晏廉政论坛投稿”。

研究院将组织专家对论文进行评审，评出优秀论文并给予一定奖励，根据专家评审结果邀请入选作者参加论坛。

五、会议费用

本次会议不收取会务费。参会人员的餐饮费、住宿费由主办方承担，交通费等其他费用请自理。
