吉林大学代表队在2023年国际遗传工程机器大赛（iGEM）中斩获一金二银

发布时间：2023-11-14  点击次数：

【供稿：国际合作与交流处 白求恩第三临床医学院 生命科学学院 计算机科学与技术学院】近日，在“吉林大学国际竞赛资助计划”支持下，吉林大学三支代表队在2023年国际遗传工程机器大赛（International Genetically Engineered Machine Competition）中脱颖而出，斩获一枚金牌和两枚银牌。2023年的iGEM总决赛吸引了来自约60个国家的超过7,000名学生参赛，全球参赛队伍达到404支。吉林大学白求恩第三临床医学院组织指导的CJUH-JLU-China代表队获得金牌，生命科学学院组织指导的Jilin-China代表队和计算机科学与技术学院组织指导的JLU-China代表队分别获得银牌。

CJUH-JLU-China代表队由白求恩第三临床医学院胡鑫教授和万由衷教授共同指导，来自数学学院、物理学院、公共卫生学院、药学院、白求恩第二临床医学院、白求恩第三临床医学院等6个学院的14名学生组成。

CJUH-JLU-China代表队开发出一种名为BreFast的乳腺癌早期快速筛查试剂盒，旨在通过将CRISPR/Cas13a技术与侧向层析流动试纸相结合，以达到快速便捷地完成乳腺癌早期筛查的目的。为了提高公众对于乳腺健康的重视程度、增进其对于乳腺癌的了解，团队进行了广泛的调查研究和专家咨询，设计出乳腺保健操和棋盘游戏等一系列公益活动；同时在小学、初中、高中、大学、社区以及边远山区开展了诸多科普教育活动，受到了一致好评。

Jilin-China代表队由吉林大学生命科学学院于湘晖教授、陈妍教授、侯阿澧副教授、詹杨副教授及王嘉麟助理工程师共同指导，来自商学与管理学院、化学学院、生命科学学院、公共卫生学院和白求恩口腔医学院的19名学生组成。

Jilin-China代表队致力于建立一种针对黑色素瘤患者的温和、低成本、可调控的治疗方法，参加本年度治疗赛道项目角逐。在近10个月的备赛过程中，全体队员在头脑风暴、项目设计与讨论、开展实验、生物建模与数学建模、实验结果处理与分析、硬件设计与制作、社会实践与网页制作等每一个阶段不懈努力，积极拼搏，最终完成了“针对黑色素瘤的基于温控翻转系统的温和治疗方法”项目的全部内容，并把项目成果带到法国巴黎参赛。

JLU-China代表队的PI由计算机科学与技术学院的张永刚教授和谷方明老师组成，实验组由公共卫生学院的申延男主任的科研团队指导，学生团队由9个学院的20名学生组成。

该项目主要针对隐形眼镜佩戴者的眼部感染问题，尤其是铜绿假单胞菌引起的角膜炎，提出了利用含有DMBT1蛋白抑制该细菌的活性来降低感染的安全解决方案。基于该方案，设计并实施了生成DMBT1蛋白的生物合成实验，并制作了智能监测隐形眼镜盒的硬件原型。同时，项目团队分别以护眼常识和合成生物学为主题开展了多次科普活动。

iGEM是全球大学生顶级国际科技赛事，是合成生物学领域最高水平、最具影响力的国际性学术竞赛，涉及生物学、医学、数学、计算机、统计学、工程学等领域交叉合作。

吉林大学第一支iGEM参赛队伍是成立于2014年的Jilin-China，2016年获得首枚金牌，在2018至2022年间代表吉林大学获得了“五连金”的优异成绩。
