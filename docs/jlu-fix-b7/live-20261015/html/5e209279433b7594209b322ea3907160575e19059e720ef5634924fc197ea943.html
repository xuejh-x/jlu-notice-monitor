关于遴选资产处置专家库成员的通知

发布者：   发布时间：2026-09-15   浏览次数：

校内各单位：

为加强学校国有资产管理，提升资产处置工作的规范性与科学性，现面向全校公开遴选资产处置专家库成员，具体事项通知如下：

一、遴选条件

1.政治素质良好，恪守职业道德，坚持原则、秉公履职；

2.熟悉仪器设备使用或了解国有资产处置工作，可承担评审、论证、现场踏勘等工作，如实出具专业意见；

3.具有中级及以上职称，且在相关专业领域工作满5年，专业实践经验丰富；

4.自愿参与学校资产处置相关工作并接受监督管理，身体健康，年龄一般不超过65周岁；

5.能够妥善统筹工作时间，保障按时完成各项评审任务。

二、专家主要职责

1.参与学校资产处置项目评审、论证，就资产现状、使用价值、处置方案等出具专业意见；

2.参与现场踏勘与实物鉴定，对资产处置相关技术问题提供专业咨询；

3.为学校资产处置工作提供意见建议。

三、报名时间及要求

请有申报意愿的老师，于2026年9月21日16：30前填写《资产处置专家报名表》，经所在单位审核并加盖公章，将电子版及盖章扫描件（命名格式：姓名+所在单位+资产处置专家申报）一并发送至邮箱niewb@jlu.edu.cn。资产管理处将根据工作需要遴选入库专家。
