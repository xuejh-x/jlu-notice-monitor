关于人兽共患病研究教育部重点实验室开放日活动安排的通知

作者：时间：2024-03-12点击数：

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，深入实施创新驱动发展战略，坚持“简约朴素、安全保密、稳妥有序”原则，实施全民科学素质行动，大力弘扬科学家精神，树立热爱科学、崇尚科学的社会风尚，现人兽共患病研究教育部重点实验室于2024年3月21日开展“实验室开放日”活动。

本活动主要面向社会大众展示实验室的研发成果，科研环境，普及生物安全知识。

本次活动采用现场参观形式，时间定于2024年3月21日-3月29日，欢迎大家参加！报名时间截止至2024年3月28日。
