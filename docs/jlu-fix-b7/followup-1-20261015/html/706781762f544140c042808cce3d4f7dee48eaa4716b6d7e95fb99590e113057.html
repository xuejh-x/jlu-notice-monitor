关于国家教材建设重点研究基地 （高等学校理学教材研究） 研究课题中期检查的通知

日期：2026-07-13 点击数：

本科生院、教师教学发展中心、图书馆、数学学院、物理学院、化学学院、生命科学学院、商学与管理学院：

为规范基地课题全过程管理，依据《国家教材建设重点研究基地（高等学校理学教材研究）课题管理办法（试行）》，基地现组织开展2025年度立项研究课题中期检查工作，现将有关事项通知如下：

一、检查范围

2025年度经国家教材建设重点研究基地（高等学校理学教材研究）准予立项的全部17个研究课题。

二、检查内容

重点核查课题前期实施推进情况，主要包含三方面：一是项目整体研究开展进度；二是现阶段已产出的阶段性研究成果；三是课题推进过程中存在的难点、堵点及待解决问题。

三、检查方式

本次检查采用线上检查的方式，各课题负责人需在2026年7月13日—2026年7月17日16点前登录基地课题管理平台（网址：https://jckt.jlu.edu.cn/）完成申报书信息核对，并上传已签字盖章的项目申报书（PDF版）；2026年7月18日—2026年7月26日16点前在线填报中期检查相关材料。

四、其他要求

1.坚持实事求是原则。各课题负责人须客观、完整填报课题真实进展，严禁瞒报、漏报、虚报、弄虚作假等行为。

2.严格遵守报送时限。逾期未提交中期检查材料、课题研究停滞或无法持续推进的项目，基地将视实际情况作出立项调整或撤销立项处理。

3.压实主体工作责任。各课题负责人须高度重视本次中期检查工作，对照立项申报书既定研究计划有序推进各项研究任务。

4.如已完成课题研究内容，本次可直接申请课题结题并提交相关成果。

5.在检查工作中如有疑问，请及时与基地相关工作人员联系。
