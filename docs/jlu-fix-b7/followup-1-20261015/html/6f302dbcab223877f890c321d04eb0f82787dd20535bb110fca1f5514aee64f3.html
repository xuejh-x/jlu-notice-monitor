关于开展2025年人畜共患传染病重症诊治全国重点实验室“开放日”活动安排的通知

作者：时间：2025-05-19点击数：

为深入学习贯彻习近平总书记关于科技创新的重要论述，广泛宣传习近平总书记对科技工作者关心关爱，向社会公众展示关键核心技术和攻关成果，大力弘扬科学家精神，按照《科技部中央宣传部 中国科协关于举办2025年全国科技活动周和全国科技工作者日活动的通知》要求，现人畜共患传染病重症诊治全国重点实验室于2025年5月18日开展“实验室开放日”活动。

本活动主要面向社会大众展示实验室的研发成果，科研环境，普及生物安全知识。

本次活动采用现场参观形式，时间定于2025年5月19日-5月30日，欢迎大家参加！报名时间截止至2025年5月23日。
