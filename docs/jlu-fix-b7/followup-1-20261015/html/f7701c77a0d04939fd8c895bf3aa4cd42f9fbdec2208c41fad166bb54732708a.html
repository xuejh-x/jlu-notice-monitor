第二届高清海学术基金评奖公告

高清海先生（1930-2004）是当代中国著名哲学家，为繁荣和发展我国哲学事业做出了重大贡献。他一生致力于哲学理论的创新，把深沉的哲学反思与对中国社会发展的关怀内在结合起来，形成了鲜明的学术个性和思想人格，为中国哲学界留下了弥足珍贵的思想财富。

为了推动我国哲学基础理论研究的创新和发展，弘扬先生的学术精神，鼓励青年学者，吉林大学高清海学术基金决定面向全国哲学界，举行第二届高清海学术基金评奖活动。2021年是高清海先生去世17周年，界时我们将举行缅怀高清海先生纪念会和学术研讨会，并于会议上进行颁奖。现将评奖活动公告如下：

一．奖项名称

高清海学术基金奖。基本奖项：评选优秀哲学著作2部，优秀哲学论文6篇，特殊贡献奖1项。

二．评奖范围

高清海学术基金奖包括优秀成果奖和特殊贡献奖。优秀成果奖主要奖励体现理论创新精神和具有深厚学术含量的哲学基础理论研究成果（专著和论文）；特殊贡献奖主要奖励在国外出版的高清海先生译著。

三. 成果要求

1.坚持马克思主义的基本立场和方法；2.具有重要的学术价值和社会影响；3.代表本专业的发展方向和水平，对学科建设有突出贡献；4.参评成果至少公开发表或出版2年以上，

四．申报条件

凡全国普通高校教师、研究机构研究人员、党校教师及国家机关工作人员，均可申报。每人限报1项。合作研究成果须由第一署名人申报。优秀成果奖作者年龄原则上在50岁以下。下列成果不予受理：（1）著作权存在争议；（2）违反学术规范；（3）成果作者非第一署名人。（4）已获国家社科基金项目优秀成果奖、教育部高校人文社科奖、中宣部“五个一”工程奖、国家图书奖等奖项的成果不再参评。（5）高清海学术基金管理委员会成员的成果不参加评选优秀成果奖。

 五．申报办法

（1）本人自报或专家推荐（申报和推荐的空白表格可以在“高清海学术基金网站http://gqhfund.jlu.edu.cn/index.htm下载）。

（2）著作类成果须提交成果原件2份，内容提要（1500字左右）及有关佐证材料各1份；论文类成果须提交成果原件1份，成果复印件（隐去作者单位和姓名的封面、目录、正文）、内容提要（500字左右）及有关佐证材料各1份。

（3）申报材料装订方式：著作类成果按照《申报表》、内容提要及佐证材料的顺序左侧装订；论文类成果按照《申报表》、成果复印件、内容提要及佐证材料的顺序左侧装订。

（4）申报时间：2021年5月20日到8月30日。

 六．评奖方式

2021年9月，聘请国内著名学者，组成评奖委员会，对符合申报条件的成果进行评审。评审采取无计名投票方式进行表决。评审结果将在公开媒体向社会各界公示，公示无异议后，邀请获奖者参加高清海先生去世十七周年纪念会和学术研讨会，并举办颁奖仪式，颁发奖金和获奖证书。

七．联系方式

第二届高清海学术基金奖评选办公室设在吉林大学哲学社会学院，邮政编码：130012，邮寄地址：吉林省长春市吉林大学前卫校区哲学社会学院，联系人：崔爱红，电话：0431-85166090（办），13504318673（手机）， 电子邮箱：cuiaihong@jlu.edu.cn。
