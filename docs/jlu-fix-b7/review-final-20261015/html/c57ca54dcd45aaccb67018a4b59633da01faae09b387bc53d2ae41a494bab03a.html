    未来科学交叉研究分会场口头报告报名通知
    发布日期： 2026-10-07  浏览：

  • 第六届“唐敖庆”博士生学术论坛暨吉林大学第十九届博士生国际学术论坛化学分论坛将于2026年10月20日至21日在吉林大学举办。本届论坛由吉林大学化学学院与未来科学国际合作联合实验室联合承办，在实验室设置“未来科学交叉研究”分会场（英文报告专场）。分会场将邀请来自英国伦敦大学学院、德国马普学会高分子研究所、澳大利亚昆士兰大学、香港理工大学等世界知名高校及科研机构的博士生参会并作口头报告。现诚邀实验室各科研团队及课题组博士生报名参会并作口头报告。有关事项通知如下：

    一、分会场时间与地点

    · 时间：2026年10月20日（具体时段另行通知）

    · 地点：未来科学园

    二、报告形式与要求

    1. 口头报告，每人15分钟（含提问时间）。

    2. 本分会场为英文报告专场，须使用英文撰写摘要并作口头报告。

    3. 投稿论文应为博士生本人以第一作者完成的学术成果，已发表/未发表成果均可投稿。投稿须征得导师同意，确保论文不侵权、不涉密，文责自负。每人限投稿一次。

    4. 请提前准备PPT，并于会前提交至会务组。

    5. 现场由评委进行评审。


    三、奖励设置

    论坛设一、二、三等奖，所有完成报告的同学均可获证书及奖金。具体奖项由现场评委评定，奖项名额及奖金标准以最终评审结果为准。

    四、报名方式

    1. 请于10月11日前登录报名网站注册并投稿：https://doctor.oonekj.com/。

    2. 论坛组委会将根据投稿情况进行评审，预计于10月13日左右发布第二轮通知，公布口头报告录用名单。

    3. 本次分会场口头报告名额不超过10人，按投稿评审结果择优确定。

    4. 更多论坛信息详见：https://mp.weixin.qq.com/s/J8NWowkUml9Jxc9rzPY2XA
