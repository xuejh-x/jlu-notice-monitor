国家教材建设重点研究基地（高等学校理学教材研究）协办2026年高等学校工科数学课程与教学研讨会

日期：2026-09-07 点击数：


9月4-7日，2026年高等学校工科数学课程与教学研讨会在辽宁大连召开。会议由教育部高等学校工科基础课程教学指导委员会指导，清华大学数学基础教学中心、清华大学出版社主办，大连民族大学承办，国家教材建设重点研究基地（高等学校理学教材研究）作为协办单位参与会议。基地专职副主任郭玉鹏教授，基地专职研究人员、吉林大学公共数学教学与研究中心副主任高彦伟教授，朱本喜副教授，基地工作人员曲信儒、吴煜靓等出席本次会议。

开幕式上，郭玉鹏教授代表基地致辞。他指出，在高等教育内涵式发展与人工智能发展背景下，数学是工科人才培养的重要根基，新工科教学改革应结合产业实际，打造数智化教学模式。作为理学教材国家级智库，基地将以本次会议为纽带，吸纳一线教学实践案例，推动教改经验向课程、新形态教材转化。他结合学科交叉实践，强调数学对理工科研的支撑作用，呼吁各方协同发力，推进工科数学课程与教材建设。

本次会议聚焦数智时代工科数学育人革新，围绕AI赋能教学、课程思政、教材建设等开展研讨。高彦伟教授主持专题报告环节，与参会同行就工科数学课程、教材建设等相关议题开展交流研讨。吉林大学公共数学教学与研究中心朱本喜副教授作题为《新工科背景下吉大数学一流课程与精品教材的建设探索》的大会主旨报告，提出以新工科需求导向下的教材建设为核心枢纽，落实跨学科深度融合路径，打通多主体协同育人链路，推动AI、大数据与传统数学知识有机融合，构建适配新工科人才核心能力培养的教材框架。

下一步，基地将持续对接高校教学一线，凝聚教改成果，助力理学教育高质量发展。
