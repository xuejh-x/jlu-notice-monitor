2021年吉林大学附属中学公开招聘教师

初审通过人员名单公示

吉林大学附属中学根据工作需要面向校内外公开招聘7名教师，于2021年12月8日发布了招聘启事。根据报名教师的申报材料，经过招聘工作考核专家组、纪检监督组、工作小组的审核，现将通过资格审查的人员名单公示如下：

 

艾东宇   敖  莹   董瑾煜   范贝妮   宫  名

  巩天横   侯  静   冷  雪   李术光   李  雪

卢  静   鲁  静   马晶晶   孟中华   权万秋

宋  佳   宋文佳   吴  晗   杨  杉   于  琪

于晓东   张馨月   张  颖   赵  敏   朱慧媛

特此公示。

 

请相关人员看到此公示后于2021年12月20日携带身份证到吉林大学附属中学（解放大路正门）领取笔试准考证。领取时间：上午8:00—10:00，逾期未领取者视为自动放弃笔试资格。
