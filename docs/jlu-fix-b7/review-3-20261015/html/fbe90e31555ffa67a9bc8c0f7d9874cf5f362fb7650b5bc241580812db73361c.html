关于举办学校党委理论学习中心组2022年第5次（扩大）集体学习的通知

日期：2022-10-24 点击数： 来源:
校内各单位：

    为深入学习贯彻党的二十大精神，根据学校党委理论学习中心组2022年度学习计划，结合学校处级领导干部培训计划，学校党委决定举办党委理论学习中心组2022年第5次（扩大）集体学习，现通知如下：
    一、学习时间
    2022年10月26日（星期三）上午9:00   

二、会议地点

中心校区东荣会议中心二楼多功能厅

三、参会人员

学校党委理论学习中心组全体成员，机关部门正处级干部，各院级党组织书记、常务副书记

四、学习内容

专题学习党的二十大精神

五、相关要求
    （一）请全体参会人员妥善做好工作安排，准时参加学习。
    （二）全体参会人员请提前10分钟进入会场，并严格遵守学校疫情防控有关要求，会议全程须佩戴口罩。
    （三）参会人员原则上不得缺席和请假。如因特殊情况确需请假的，请提前报党委宣传部备案。

    党委组织部：联系人：孟欢  联系电话：85167730
