吉林大学校门伸缩门、铁门及部分空调维保服务采购项目

日期：2026-07-07 点击数： 来源:

依据公平、公正、公开的原则，保卫处、党委保卫部就吉林大学校门伸缩门、铁门及部分空调维保服务采购项目工作组织竞争性谈判采购，现邀请符合条件的供应商参与谈判，供应商必须符合《中华人民共和国政府采购法》第二十二条之规定。

一、采购项目名称：《吉林大学校门伸缩门、铁门及部分空调维保服务采购项目》

二、报名条件：供应商应具有独立承担民事责任的能力，依法在国内注册，具备有效的营业执照，且经营范围需包含相关服务内容。

三、项目预算：人民币22万元

四、报名方式

时间：2026年7月7日至2026年7月9日16:30前

地点：吉林大学中心校区商贸楼2楼213室

联系人：张红军

联系电话：0431-85152335

五、评选流程：

保卫处、党委保卫部组织评选会议，工作人员现场开封送达响应文件；评审人员现场对响应文件进行评选，确定得分最高的报名供应商为选用供应商（若得分相同，以评选人员现场投票的方式确定选用服务商）。评选结束后，告知报名供应商选用结果。评选会议时间、地点另行通知。


保卫处、党委保卫部
