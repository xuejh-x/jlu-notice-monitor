　　 吉林大学古籍研究所是在全国高等院校古籍整理研究工作委员会直接领导下的重点研究所。1983年8月经吉林大学历史系于省吾、金景芳两位著名学者与当时历史系主任张忠培教授筹划创建。吉林大学古籍研究所建立后，隶属于全国高等学校古籍整理研究工作委员会，其工作受到高校古委员会的具体指导。吉林大学院系整合后，确定为部属校管所，有独立的行政机构和人员编制…[ MORE]
