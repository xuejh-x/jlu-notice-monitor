吉林大学原子与分子物理研究所举办量子信息物理基础系列学术讲座

时间：2024-11-18 点击数：

近日，原子与分子物理研究所邀请我校物理学院长期从事量子力学、高等量子力学和量子信息科学教学工作及相关理论研究的曾国模教授为我所师生举办“量子信息物理基础”系列学术讲座。此讲座自2024年10月18日开始，持续六周。内容上涵盖经典计算、量子力学引论、量子计算和量子通信四部分。

曾国模教授首先扼要介绍了量子信息科学的主要内容，接下来概述经典计算和量子力学的基础理论，进而过渡到量子计算和量子信息原理的核心部分，并与师生们深入交流了量子计算、量子通信以及量子精密测量等量子信息科技的最新研究进展和未来应用前景。曾老师的讲座图文并茂、资料详实、讲解细致，吸引了研究所众多教师和学生前来学习。师生们纷纷表示收获颇丰，对未来的科研方向有了更明确的规划和认识。

此次系列学术讲座不仅加深了研究所师生对量子信息科学的理解，进一步夯实了研究所在量子信息领域的研究基础，也极大地激发了师生们对量子信息科技的研究热情。
