吉林大学超硬材料国家重点实验室项目资助博士后拟聘人选公示

发布时间：2024-07-02浏览次数：次

按照《吉林大学博士后招收、在站管理实施细则》中的相关工作程序，经过公开发布、资格审查、合作导师考核，超硬材料国家重点实验室博士后工作领导小组审核，确定项目博士后拟聘人选为：

李晨一 高压下二维材料结构相变及超导电性调控课题组

张可为 高压下新型轻元素化合物超导体设计和制备课题组

王元元  高压富氮材料课题组

公示期为2024年7月2日至2024年7月6日。如有异议，请在公示期内实名以书面或电子邮件形式向超硬材料国家重点实验室反映。
