校园网入网指南（新生版）

各位新同学：

热烈欢迎您加入吉林大学校园网，请按照下面步骤办理入网手续，详情点击链接查看说明，具体如下：

第一步：充值并确认校园卡余额

确保校园卡余额超过120元（IP使用费为20元/月，按自然月计算，其中2月和7月为免费月），本科生的校园卡号就是注册号（通知书号），校园卡可以通过以下几种方式充值：

·加入“智慧吉大”企业微信号，查找“A一卡通”，进入后选“微信充值”（建议同学们在报到前通过此方式完成充值）

·校园一卡通网上自助服务平台

·食堂的圈存机、相应网点

第二步：网络开户

到校后，首先连接校园网（可以通过使用手机等终端连接校园网无线ID：JLU.PC或JLU.WIFI）或通过其他已连接校园网设备，登录校园网络业务自助服务平台，在线办理开户。具体步骤请点击此处。

第三步：下载客户端并认证登录

用户上网需要使用吉林大学学生邮箱用户名和密码进行认证（查询邮箱及密码重置请点击此处）。请各位同学根据终端选择具体配置方法：

·无线ID1：JLU.WIFI （适用于手机、平板和笔记本等设备使用）

·无线ID2：JLU.PC （适用于电脑、笔记本电脑使用）

·有线网络配置

用户开户后，一个账号可以同时使用于有线终端和无线终端（同一时刻JLU.PC只能使用一个终端），登录成功就可以在吉林大学6个校区7个校园享受校园网无线漫游服务，访问互联网和我校各大内部网站。

特别提醒：邮箱账号密码属于个人重要信息，用于校内多个系统身份鉴别，请妥善保管。

如有问题请随时联系我们，24小时网络报修电话：85166000，希望您用网愉快！

再次对各位同学的到来表示欢迎！
