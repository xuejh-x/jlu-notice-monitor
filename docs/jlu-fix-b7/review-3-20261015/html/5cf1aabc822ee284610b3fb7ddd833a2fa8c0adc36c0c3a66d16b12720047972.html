吉林大学经营性资产改革和管理办公室法律顾问服务项目采购公告
发布时间：2026-09-21 09:50  点击：

依据公平、公正、公开的原则，吉林大学经营性资产改革和管理办公室就本次采购项目组织采购评审，现邀请符合条件的供应商参与，供应商必须符合《中华人民共和国政府采购法》第二十二条之规定并达到响应单位资质要求方可报名。

1.采购项目名称：吉林大学经营性资产改革和管理办公室法律顾问服务

2.采购数量：1家律师事务所

3.报名方式：电话报名

联系人：陈老师

联系电话：0431-85167919

4.报名时间：2026年9月21日—2026年9月23日15:00

5.采购评审时间：2026年9月28日，具体时间另行通知；

6.采购评审地点：吉林大学南湖校区后勤综合楼113会议室；

7.采购机构：吉林大学经营性资产改革和管理办公室
