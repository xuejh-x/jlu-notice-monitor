关于开展南岭校区“文化星期二”（第十六期）——“永吉有约・健康进校园”活动

时间：2026-09-28 点击：

各学院、全体师生：

为丰富校园文化生活，精准服务师生健康需求，面向在校师生普及口腔健康、眼健康、中医亚健康调理等专业知识，学校将开展南岭校区第十六期“文化星期二”——“永吉有约・健康进校园”活动。现将有关事项通知如下：

一、活动时间

2026年9月29日（星期二）9:30—15:30

二、活动地点

南岭校区文化活动中心前广场

三、活动主题

“永吉有约・健康进校园”——多学科公益义诊暨健康科普服务活动

四、活动内容

（一）长春市口腔医院

免费建立个人口腔健康电子档案；为经义诊评估需后续就诊的师生发放专属保健机构卡，可享受对应诊疗优惠服务。

（二）易视顿眼科医院

现场提供免费裸眼视力检测、电脑验光、裂隙灯检查、眼部雾化体验、眼镜清洗服务；围绕近视防控、散光矫治、干眼症缓解、视疲劳改善等内容开展科普答疑；发放成人及儿童通用VIP眼检卡。

（三）恩林医院

开展免费皮肤专项检查，同步建立个人皮肤健康档案；发放免费到院体检名额。

（四）云舟门诊

现场提供免费睡眠亚健康检测、中医脉诊、针灸美容体验、非遗孙氏理筋推拿技法体验，同步开展中医药食同源茶饮品鉴服务。

欢迎全校师生踊跃参加。
