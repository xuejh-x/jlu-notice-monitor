教师教学发展进学部：数智赋能课程建设专项培训（农学部）

时间：2026-06-16 点击：

各有关单位：

为助力教师积极主动地迎接教育变革与创新，实现数智时代教育理念与教学范式的转型，教师教学发展中心携手各学部推出“教师教学发展进学部——数智赋能课程建设专项培训”系列活动。该活动以学科特色为根本遵循，以目标导向为实施准则，聚焦不同学科教师的差异化发展需求，系统培养教师运用数字化教学工具的专业能力。本场活动中心联合农学部共同开展，由植物科学学院协办，具体安排如下：

一、时间

2026年6月18日（星期四）13：30

二、地点

吉林大学和平校区图书馆二楼报告厅

三、活动主题

师-生-机三元协同：智慧课程驱动的未来教学新生态

四、主讲嘉宾

王医术，吉林大学教师教学发展中心主任。

宝钢优秀教师，全国教育变革先行者，吉林省最美教师暨黄大年式好老师，吉林省长白英才计划教育教学领军人才，吉林省杰出青年科学研究计划资助学者，吉林省卫生系统拔尖创新人才。高等学校教师教学发展指导委员会委员，教育部高等学校虚拟仿真教学创新实验室负责人，吉林省普通本科高校优秀基层教学组织负责人。领衔推出省内乃至国内第一门《病理学》AI课程，国家混合式一流课程负责人。

五、参加人员

1.农学部各学院教师。

2.请参加活动的教师务必于6月17日（星期三）下午15:00前登录“智慧吉大”企业微信，进入“工作台”，点击“教师教学发展数据与业务管理系统”，在对应的“培训活动”模块中进行报名。

六、其他
