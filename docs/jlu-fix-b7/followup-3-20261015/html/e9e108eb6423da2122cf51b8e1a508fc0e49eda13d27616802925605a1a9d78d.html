关于开展教师教学奖励津贴和科研奖励津贴核发工作的通知

时间：2026-01-09    点击：


校发〔2026〕2号

校内各单位：

根据有关文件精神，结合学校实际，经研究决定，现开展教师教学奖励津贴和科研奖励津贴核发工作，现将有关事宜通知如下。

一、核发原则和要求

1、依照“放管服”改革要求，本着“学校测评单位、单位测评个人”的原则，给予各教学科研单位更大的自主决策权，进一步激发各单位的教学科研活力。

2、教师教学奖励津贴依照学校本科生院、研究生院掌握的相应学年实际发生的教学工作量，并注重教学的质量和效果，按照规定标准进行核发。

3、各单位在发放教师科研奖励津贴时要注重成果的质量和贡献，建立以质量和结果为导向的教学科研奖励机制。

4、科研贡献评价逐步推行“代表成果”同行评议制度，评价工作聚焦标志性学术成果，强调成果的创新内容和学术贡献，突出科学精神、创新质量、服务贡献。建议各学院组织学术委员会对每位教师的科研工作进行客观评议。

二、有关问题的界定

1、教学奖励津贴以学校当年度学年的教学工作量为准；科研奖励津贴以当年度自然年的数据为准。

2、科研奖励津贴所涉及的信息数据，原则上应以学校有关职能部门备案为准。

3、对于离退休人员和2024年度在我校工作、现已调出我校的人员，各单位在测评时应给予适当考虑。

三、工作实施及分工

1、人力资源处负责统筹核定全校教学奖励津贴和科研奖励津贴的总额度，并对整体核发工作进行协调和监督。

2、本科生院、研究生院参照各教学科研单位的教学工作量，核定教学奖励津贴额度，各单位核算具体教师的教学奖励津贴金额。

3、科研院、社会科学研究院、本科生院、研究生院以学校掌握的相关数据为基础，合理测算各单位的科研奖励津贴。

4、各单位依据科研院、社会科学研究院、本科生院、研究生院下拨的相应奖励津贴额度，制定本单位当年度的奖励津贴分配方案，依据分配方案制作分配明细，并将分配明细报送相关职能部门。科研院、社会科学研究院、本科生院、研究生院审核后，报人力资源处汇总并完成最终发放工作。

四、时间安排

1、2026年1月9日（星期五）-1月14日（星期三）

学校相关职能部门完成奖励津贴总额度的核定、相应教学和科研业绩津贴发放额度的测算工作，并将相应额度数通知各教学科研单位。

2、2026年1月15日（星期四）-1月16日（星期五）

各教学科研单位依照上述核发原则和要求，制定本单位的奖励津贴分配方案，依据职能部门测算的本单位发放额度，制作分配明细。需于2026年1月16日下午16:00前，将本单位的奖励津贴分配明细纸质版（需单位主要负责人签字并加盖公章）报送学校相应职能部门。

3、2026年1月19日（星期一）以后

学校职能部门对各单位报送的分配明细进行汇总。核定无误的单位，人力资源处协调完成发放工作。

五、其他

1、教师奖励津贴的核发工作是关系到广大教师切身利益的重要工作，各单位负责人要高度重视，加强领导，认真组织，努力做好这项工作。

2、各单位要合理安排，提高效率，确保奖励津贴及时发放。

3、结合往年度发放工作实际，校外人员在经财务处核发时存在发放困难或无法发放的情况，提请各单位在具体分配时做好提前咨询或规避工作。

4、各教学科研单位对本单位相应分配额度有疑问的，可向相关职能部门提出，由相关职能部门给予政策解释；如教职工对本人的分配额度有疑问，可向本单位负责此项工作的负责人提出，由相关负责人给予具体解释。
