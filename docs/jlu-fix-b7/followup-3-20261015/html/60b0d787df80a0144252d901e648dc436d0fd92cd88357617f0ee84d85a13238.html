关于吉林大学2020年度第一批 “鼎新学者”拟聘人选公示的通知

时间：2020-06-29    点击：

校人字〔2020〕158 号

 

根据《吉林大学“鼎新学者”支持计划》（校发[2020]68号）文件规定和《吉林大学“鼎新学者”招收选拔、聘期管理实施细则》（校人字[2020]91号）要求，经学院考核推荐、校内和校外专家同行评议、学校会议评审等环节，确定王宇洋等51人为吉林大学2020年度第一批 “鼎新学者”拟聘人选(具体名单见附件)。

现对拟聘人选进行公示。公示期为2020年6月29日至2020年7月1日。如对上述人选有异议，请在公示期内具实名以书面形式向人力资源处反映。
