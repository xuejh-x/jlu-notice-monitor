政策与法规办公室召开2026年工作务虚会

作者：   时间：2026-03-06   点击数：

为深入学习贯彻学校党委工作部署，分析当前形势任务，谋划下一阶段重点工作思路与举措，2026年3月4日，政策与法规办公室召开工作务虚会。会议由冯浩主任主持，办公室全体人员参加会议。

会上，政策研究科、法务管理科、制度建设科、综合信息科科长依次作代表交流发言。各科室分别围绕政策研究、依法治校与风险防控、制度体系建设与审查服务、信息服务保障等重点工作，总结年度工作开展情况，梳理存在的问题与短板，深入分析当前面临的新形势、新任务、新要求，并就下一阶段工作思路、重点任务、推进举措提出具体设想。

冯浩主任指出，在过去的一年中，在学校党委的领导下，政策与法规办公室紧紧围绕学校中心工作，全力服务学校建设发展大局，切实履行业务职能，在构建现代化治理体系、防控学校法律风险、为学校改革发展提供决策建议等方面发挥积极作用。冯浩对新一年的工作提出三点要求。一是要提高政治站位，主动对标党和国家在法治建设、教育改革等领域最新部署，紧盯外部政策与立法动态，增强工作前瞻性与主动性。二是要聚焦主责主业，强化政策研究、法律保障、制度建设、综合服务协同发力，推动工作从“被动应对”向“主动预判、提前布局、源头防控”转变。三是要夯实工作基础，坚持问题导向，以新技术促进工作效能提升，不断加强知识库、案例库、制度库建设，提升对学校和学院的服务支撑能力。

会上，与会人员围绕各科室发言内容开展深入研讨和交流，就政策研究精准化、法律风险防控、制度体系完善、数字化建设、普法宣传、人工智能工具应用能力提升等方面问题充分交换意见、凝聚共识。

本次务虚会的成功召开为下一阶段工作理清了思路、划定了重点。下一步，政策与法规办公室将以此次会议为契机，进一步明任务、强举措、抓落实，不断提升政策研究、法治服务、制度建设、综合保障水平，为学校高质量发展提供坚实支撑。
