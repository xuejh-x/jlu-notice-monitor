关于举办南岭校区“文化星期二”（第八期）——“汽车芯片强国路”专场报告会的通知

时间：2026-05-30 点击：

各学院：

为持续加强校园文化建设，厚植学生实业强国、科技报国的理想信念，引导学生深耕专业领域、立志投身国家汽车产业高质量发展，南岭校区将举办“文化星期二”（第八期）——“汽车芯片强国路”专场报告会。现将有关事宜通知如下：

一、活动主题

汽车芯片强国路

二、活动时间

2026年6月2日（星期二）15:30—17:00

三、活动地点

南岭校区逸夫教育大楼B516

四、主讲嘉宾

金星，吉林大学物理学本科、大连理工大学材料学博士，国家级特聘专家，中国科协海智专家

五、组织机构

（一）主办单位

吉林大学、吉林省科学技术协会

（二）承办单位

吉林大学东区事务办公室、机械与航空航天工程学院、汽车工程学院、交通学院，吉林省科学技术协会学会服务中心

六、活动内容

1.金星教授作“汽车芯片强国路”专题报告

2.现场互动交流

七、嘉宾简介

金星，吉林大学物理学本科、大连理工大学材料学博士，国家级特聘专家，中国科协海智专家。1996年在欧洲微电子研发中心(IMEC)开展微电子领域博士后研究；1999年入职荷兰飞利浦半导体公司（后更名为恩智浦半导体公司，NXP Semiconductors），长期从事汽车电子芯片设计与研发工作；为欧洲华人微电子中国论坛创始人，2009年提交的《发展有中国自主知识产权的汽车电子专用芯片》荣获海外学者优秀建议奖。2011年回国后，担任中科院上海微系统与信息技术研究所汽车电子工程中心（第八研究室）主任、研究员、博士生导师，兼任国家科技重大（02）专项——“汽车电子芯片工艺与制造”项目副总指挥；2014年投身汽车零部件研发领域；2022年作为核心筹划者，出任上汽集团、嘉定区、新微集团联合组建的“上海汽车芯片工程中心”首席科学家/CTO；2024年加入上海机动车检测认证技术研究中心有限公司，担任“国家汽车芯片质量检验检测中心”主任，同时受聘为上海大学教授。

欢迎广大师生积极参会交流。
