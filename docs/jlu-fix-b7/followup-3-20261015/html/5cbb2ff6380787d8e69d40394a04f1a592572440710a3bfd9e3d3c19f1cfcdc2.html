东北与东北亚研究院“吉林省省属高校教师培养计划”博士研究生招生进入综合考核的考生名单及时间安排

发布日期：2026-05-18 浏览量：

一、进入综合考核环节人员

我院“资格审核小组”对考生提交的申请材料进行评估，根据考生的外语水平、学习成绩、硕士论文、参与科研、发表论文以及获奖等情况，按百分制给出成绩，最终按照不超过每位导师招生计划名额1:2的比例择优进入综合考核面试环节，进入面试学生名单如下。
