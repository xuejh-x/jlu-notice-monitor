第二届东北铸牢中华民族共同体意识研究高端论坛成功举办

发布日期：2024-05-25编校： 浏览：

为深入学习贯彻党的二十大精神，深刻领会习近平总书记关于加强和改进⺠族工作的重要思想，推进新时代中国特色⺠族理论研究体系建设，2024年5月24—25日，“第二届东北铸牢中华⺠族共同体意识研究高端论坛”在吉林省⻓春市隆重举行。

本次论坛由吉林大学⻢克思主义学院、吉林大学东北⺠族研究中心共同主办，出席此次会议的领导嘉宾有：国家民委理论研究司科研管理处刘丽丽处长，吉林省民族事务委员会田磊主任、安东梅调研员，长春市民族事务委员会主任王飞、处长潘爽，吉林大学党委副书记、教育部长江学者韩喜平教授，吉林大学党委统战部常务副部长苗艺璇，吉林大学党委宣传部副部长张倩，吉林大学社会科学研究院曲红梅教授，吉林大学马克思主义学院党政班子成员钟新书记和吴宏政院长。

论坛由吉林大学东北民族研究中心牵头，齐聚东北三省国家民委铸牢中华民族共同体意识基地单位、对口支援高校铸牢基地单位，分别是：哈尔滨工业大学计算社会科学协调创新中心、东北师范大学东北民族民俗博物馆、延边大学中华民族共同体研究基地、辽宁师范大学国家民委中华民族共同体研究基地、大连民族大学中华民族共同体意识教育研究基地、渤海大学中华民族共同体研究中心、西藏藏医药大学马克思主义理论教学部、新疆医科大学“铸牢中华民族共同体意识研究与实践基地”。参会人员单位还有：吉林省民族宗教研究中心、吉林省社会科学院、吉林省文物考古研究所、东北师大思想政治教育研究中心、四川文化教育高等研究院、《学习与探索》杂志社、《中国社会科学报》吉林站等，共计29所高校、科研机构和期刊媒体，80余名专家学者参与了本次论坛。参会人员共同围绕“铸牢中华民族共同体意识理论与实践研究”开展了实践调研、主题发言、主旨发言、分论坛讨论等活动，以期带动铸牢中华⺠族共同体意识理论与实践同频共振，提高铸牢中华⺠族共同体意识研究水平。

24日下午，与会人员一同前往伊通满族小学和伊通县博物馆（国家三级博物馆）进行了参观调研。伊通满族小学是“全国民族团结进步创建活动示范学校”，学校把铸牢中华民族共同体意识教育贯穿办学治校、教书育人全过程，构建了“初心筑基、正心铸魂、慧心筑梦、匠心筑行、丹心筑业”的“五心”育人模式，成立了40余个“石榴籽”社团，涵盖“传统文化、歌舞、体育、美育、科技”等方面，每班一品，各具特色。参观人员纷纷赞不绝口，予以高度评价。

千年文脉延绵不绝，灿烂文明生生不息。文物有了生命，文化才会有力量。参观完伊通满族小学之后，参会人员来到了伊通县博物馆。伊通满族博物馆，是一座展示满族历史、文化和满族风情的专业性博物馆。馆内设有满族源流、政治、经济、文化、风俗、信仰和古今伊通等八个展厅，通过满族传世文物六百个种类，三千余件展品及图片和模型景观等各种艺术表现形式，展现出一幅幅纷繁的满族历史风情画卷，描绘出满族先民用智慧和汗水创造的绚丽的民俗文化。在这里，参会人员沿着满族历史足迹，感受、领略了厚重的满族文化。

25日上午，开幕式由吉林大学东北民族研究中心主任罗克全教授主持，吉林大学党委副书记韩喜平、国家民委理论司科研管理处处长刘丽丽先后致辞。吉林大学党委副书记韩喜平在会议致辞中指出：今天我们东北三省一区、国家民委铸牢基地，对口支援高校铸牢基地负责同志以及为东北历史文化研究做出贡献的专家和学者相聚与此，共同举办“第二届东北铸牢中华民族共同体意识研究高端论坛”，是落实习近平总书记关于加强改进民族工作重要思想的具体行动。今后，我们将进一步整合东北三省国家民委铸牢基地力量，主要致力于四方面工作，一是提高政治责任，紧扣铸牢中华民族共同体意识这条主线；二是践行使命担当，努力把基地建设成为铸牢中华民族共同体意识的示范高地；三是推进理论的体系化学理化，引领东北铸牢中华民族共同体意识学术研究新突破；四是推动学科融合，打造基地品牌，发挥基地特色。

韩喜平

吉林大学党委副书记

国家民委理论司科研管理处处长刘丽丽在会议致词中指出：本次论坛聚集了学术界众多的专家学者，以“铸牢中华民族共同体意识理论和实践研究”主题来开展研讨，意义重大，是贯彻落实习近平总书记加强和改进民族工作重要思想的有力行动，是对民族工作高质量发展的极大推动。中华民族是一个民族实体，不是西方理论视角下的想象的共同体，铸牢中华民族共同体意识，不仅是中华民族大家庭统一团结的历史延续，更是现实写照。铸牢中华民族共同体意识，不是喊喊口号，而是要从马克思主义民族理论出发，正本清源地讲；要立足中华民族共同体文明的根基，充满自信地讲；要结合中国共产党百年民族工作的实践，实事求是地讲；要跳出西方民族理论的智库，有理有据地讲。

刘丽丽

国家民委理论司科研管理处处长

下午分论坛分为三个会场，《学习与探索》杂志社副研究员巩村磊、吉林大学文学院教授宋卿、吉林大学东北民族研究中心主任罗克全教授分别作为召集人主持，分论坛包括学者发言、专家评议、互动讨论等环节，既有理论问题，也有现实问题。
