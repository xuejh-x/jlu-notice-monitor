    通知公告

    关于确定王观竹、许耘嘉同志为2026年计划发展对象的公示

    发布时间：2025-12-26    点击量：

    为了加强对发展党员工作的民主监督，确保发展新党员的质量，现将王观竹、许耘嘉同志列为2026年计划发展对象的有关情况进行公示。

    公示时间为2025年12月26日至2026年1月4日（5个工作日）。

    公示期间，党员和群众可通过电话和电子邮件等方式，反映发展对象在理想信念、政治立场、思想作风、工作表现、群众观念、廉洁自律等方面的情况和问题。反映问题应实事求是、客观公正。以个人名义反映问题的，要签署本人真实姓名。党支部将对反映人和反映问题严格保密，对反映问题进行调查核实，弄清事实真相，并以适当方式向反映人反馈。

    联系电话：85166542

    联系邮箱：houqc@jlu.edu.cn
