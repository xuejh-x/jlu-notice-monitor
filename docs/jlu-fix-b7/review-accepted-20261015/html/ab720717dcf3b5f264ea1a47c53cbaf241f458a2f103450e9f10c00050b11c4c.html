通知公告

吉林大学人民政协理论研究中心2026年接收推荐免试攻读研究生复试工作安排及进入复试名单（第二轮）

发布时间：2025-09-30    作者：    点击量：

一、复试方式和内容

1、复试方式

复试采用综合面试的方式。复试方式为现场复试，不设置线上考场。

2、复试内容

综合面试整体考核考生的专业素质和能力、综合素质和能力和外语听说能力。

（1）专业素质和能力

专业素质和能力包括：大学阶段学习情况及成绩；全面考核推免生对本学科（类别）、专业（领域）理论知识和应用技能掌握程度，利用所学理论发现、分析和解决问题的能力，对本学科（类别）发展动态的了解以及在本专业（领域）发展的能力；创新精神和创新能力。

（2）综合素质和能力

综合素质和能力包括：思想政治素质和品德考核，内容应包含推免生的政治态度、思想表现、道德品质、遵纪守法、诚实守信等方面；本学科（类别）专业（领域）以外的学习、科研、社会实践（学生工作、社团活动、志愿者服务等）或实际工作表现等方面的情况；事业心、责任感、纪律性（遵纪守法）、协作性；人文素养；心理健康情况。

（3）外语听说能力

由精通外语的教师担任主考教师进行现场问答，保持整个测试过程评分的一致性、连贯性和公正性。

二、复试名单

经学生申请、材料审查、专家评议，招生工作领导小组审核，确定《人民政协理论研究中心2026年接收推荐免试攻读研究生复试名单》（详见附件一）。工作人员将会与进入复试的人员逐一确认，请保持联络方式畅通。

三、复试安排

1、进入复试的同学请及时关注中心网站发布信息

2、复试地点为：吉林省长春市前进大街2699号吉林大学前卫南区东荣大厦B104，请拟参加复试的考生提前安排行程，避免出现因交通原因无法参加复试的情况。

3、复试时间：

政治学理论、行政管理专业：10月9日（周四）上午9点

四、复试成绩及录取方法

1、复试成绩满分100分，60分以上（含60分）为合格，不合格者不予录取。（成绩四舍五入，取小数点后2位。）

2、全部考生严格按照综合考核成绩由高到低排序，根据各专业名额情况确定录取资格，名额外但成绩合格的考生获得递补资格。

3、思想政治素质和道德品质考核不合格者不予录取。

4、拟录取的推免生应在规定时间内通过“全国推荐免试攻读研究生（免初试、转段）信息公开暨管理服务系统”（网址：https://yz.chsi.com.cn/tm）完成网上“同意待录取”确认，完成最终录取工作，逾期则视为自动放弃。

5、中心将根据实际录取情况开展后续工作

（1）如已达到预期接收目标，即结束本年度接收工作，不再组织后续推免复试；

（2）如有空余名额，我中心将对具有递补资格的考生进行“顺位递补”录取，请考生保持联络方式畅通；

（3）顺位递补后仍有空余名额的专业，将视情况决定是否组织后续推免复试，请及时关注中心官网通知。

五、注意事项

1、考生向中心提交的各类信息、材料，必须真实准确。凡提供虚假信息的，一经查实将取消录取资格。

2、获得人民政协理论研究中心录取资格的考生，须在规定时间内尽早完成报名及接收复试、待录取通知等相关工作。

3、考生最终录取的专业，以教育部推免服务系统的录取信息为准。

六、复试的监督和复议

1、实行信息公开制度，中心网站公示各专业拟录取推免生名单，公示期为3天。

2、招生工作领导小组对复试过程中出现的各类问题负责解释。

3、考生对复试、录取结果提出质疑时，在复试结果公示期内，可以向中心办公室提出实名申诉，电话：0431-85159032。

4、其他未尽事宜，均按照学校相关文件执行。
