    关于公示吉林大学国家发展与安全研究院2026年度研究生国家奖学金评审工作细则、国家奖学金评审委员会名单的通知
    发布日期： 2026-10-10  浏览：

  • 根据2026年度吉林大学研究生国家奖学金评审工作相关要求和《吉林大学研究生国家奖学金评审办法》（校发〔2025〕300号）文件精神，国家发展与安全研究院成立了国家发展与安全研究院研究生国家奖学金评审委员会，制定了《吉林大学国家发展与安全研究院2026年度研究生国家奖学金评审工作实施细则》，经党政联席会审议通过，现予以公示。

    公示期为2026年10月10日至2026年10月13日。

    如有异议，请在公示期内具实名向研究生与留学生工作办公室反映。

    联系电话：0431-85167204

    邮箱：cuiyue@jlu.edu.cn
