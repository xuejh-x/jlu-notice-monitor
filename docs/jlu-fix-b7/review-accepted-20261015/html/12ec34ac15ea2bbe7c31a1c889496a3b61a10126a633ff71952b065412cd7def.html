关于申报《吉林省2026年度地质勘查资金项目立项指南》的通知

2025-10-11

校内各相关单位：

按照吉林省新一轮找矿突破战略行动部署，结合吉林省“十五五”基础地质调查和找矿突破重点项目研究谋划成果。为充分发挥吉林大学地学领域的专业优势，积极响应吉林省自然资源厅和吉林省地质勘查基金管理中心关于《吉林省2026年度地质勘查资金项目立项指南》申报的号召，促进我省新一轮找矿突破工作取得一进步成效。现转发立项指南，请据此编报《立项建议书》。

请申报项目的单位、团队及个人，于2025年10月19日前，将相关材料报送至吉林大学地质调查研究院（地址：长春市建设街2199号吉大鸽子楼324-2）
