中共吉林大学第十五届委员会第五轮巡视完成进驻
发布时间：2026-05-12 15:18 点击数：

根据学校党委巡视工作统一部署，对数学学院党委、生命科学学院党委、物理学院党委、原子与分子物理研究所党委、化学学院党委、应用技术学院党委（预科教育学院党委）、离退休党委、校医院党委、附属学校党委、后勤服务集团党委、产业党委、出版社有限责任公司党委等十二家基层党组织开展常规巡视。被巡视党组织于2026年5月6日至8日分别召开巡视工作动员会，完成巡视工作进驻。

会上，蒋磊、王晓荣、徐仁元、王巍、李莲英、钟绍峰、冯浩、陈希贵等八位巡视组组长对本次党委巡视工作目标、巡视重点、工作纪律作简要介绍，并明确相关工作要求：一是准确把握巡视目标。坚持围绕中心、服务大局，坚持问题导向、严的基调，坚持系统观念、发挥综合监督作用，坚持实事求是、依规依纪依法，深入学习贯彻落实党的二十大和二十届二中、三中、四中全会精神，认真落实二十届中央纪委五次全会部署，落实学校第十五次党代会精神，深入了解“十五五”规划推进情况，突出政治巡视定位，全面贯彻巡视工作方针，旗帜鲜明把“两个维护”作为根本任务。二是准确把握巡视重点。重点检查贯彻落实党的路线方针政策和党中央重大决策部署、教育部党组工作部署、学校党委工作安排情况；落实意识形态工作情况；落实高质量发展要求情况；落实全面从严治党主体责任和监督责任情况；落实新时代党的组织路线情况；落实巡视整改和成果运用情况。三是准确把握纪律要求。巡视组成员要认真履行职责，广泛听取群众意见，客观公正地了解和反映情况；严肃工作纪律，严格遵守保密、回避、廉洁自律等有关规定，在巡视期间不处理业务工作，不干扰被巡视单位工作，不具体查办案件。被巡视单位领导班子及其成员应当自觉接受监督，积极支持、配合巡视组开展工作，不得隐瞒真实情况，不干扰巡视工作。

被巡视党组织党政主要负责人表示坚决拥护学校党委的决定，坚决扛起政治责任，全力配合巡视工作。提高政治站位，把思想和行动统一到学校党委部署要求上来，以高度自觉主动接受监督。严守纪律规矩，实事求是汇报情况、全面提供资料，全力保障巡视高效推进。坚持问题导向，对巡视指出问题照单全收、立行立改，建立台账、深挖根源、健全长效机制。提高“五强”能力，加强“七优”作风建设，同时以巡促改、以巡促建，把巡视成效转化为推动事业高质量发展的强大动力，切实服务学校 “双一流” 建设。

学校党委第十五届委员会第五轮巡视时间为五周，期间设立专门值班电话、邮政信箱和电子信箱，主要受理反映被巡视党组织领导班子及其成员的问题来信来电来访，重点是关于违反政治纪律、组织纪律、廉洁纪律、群众纪律、工作纪律和生活纪律等方面的举报和反映。
