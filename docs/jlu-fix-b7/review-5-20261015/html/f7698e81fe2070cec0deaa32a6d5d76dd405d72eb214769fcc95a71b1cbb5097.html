关于发布新加坡高校2027年寒假短期交流项目及宣讲会的通知
发布时间：2026-10-15

校内相关学生：

现将新加坡国立大学、南洋理工大学2027年寒假短期交流项目信息汇总通知如下，项目详情请见附件1：

一、项目基本情况

（一）新加坡国立大学访学项目

该项目将开设不同主题课程，涵盖工、商、理、医、文等方向，由新加坡国立大学专业老师授课，授课语言为英语，项目还包括城市参访活动。

项目时间：

第一期：2027年1月16日—1月23日

第二期：2027年1月23日—1月30日

项目费用：16,800人民币/人，包含学费、课程材料费、住宿费（双人间）、境外意外保险费、项目内交通费，不包含往返机票费、餐费、办理护照费，以及其他个人消费等。

（二）南洋理工大学访学项目

该访学项目分为常规项目和创新交叉科研实践/实习项目。项目将开设不同主题学术或科研课程，涵盖人工智能、人文社科、集成电路、生物医药、自动化等方向，由南洋理工大学相关专业老师授课，授课语言为英语，项目还包括城市参访活动。

项目时间：

第一期：2027年1月16日—1月22日（常规项目）

第二期：2027年1月23日—1月29日（常规项目）

第三期：2027年2月20日—2月28日（创新交叉科研实践/实习项目）

项目费用：16,800人民币/人（常规项目）、18,800人民币/人（创新交叉科研实践/实习项目），费用包含团体国际段机票费、学费、课程材料费、住宿费（双人间）、意外伤害保险费、市内交通费，不包含办理护照费、餐费，以及其他个人消费等。

二、报名条件

1.吉林大学全日制学生；

2.独立自主、身心健康，无违纪行为，能顺利完成学习任务；

3.具有良好的英语水平，能用英语完成学术课程。

三、宣讲会

项目方将通过腾讯会议平台举办宣讲会，具体信息如下，欢迎感兴趣的同学积极参加：

时 间：2026年10月16日（星期五） 19:00-20:00

会议号：639-181-996

会议链接：https://meeting.tencent.com/dm/gm2tF8Q5dJhP

四、报名方式与截止时间

请申请人填写吉林大学学生短期出国交流项目申请表（附件2，由教学科研单位相关负责人签字并加盖单位公章）后，将纸质版于2026年11月27日（星期五）16:00前交至国际合作与交流处交流与学生项目管理科（中心校区鼎新楼A628室）；同时，请申请人点击以下链接完成网申：https://yueshi.mike-x.com/WJMBB，并扫描下方二维码加入qq群，与项目负责人联系进行报名，最终录取结果以项目方通知为准。

五、注意事项

本项目学生自主自愿参加并对自己的境外事务和安全负责。最终入选此项目的同学须于项目开始前完成出国（境）任务审批，须登录https://oge.jlu.edu.cn/网站进行申请。上述出国（境）任务审批手续不接受补报。出国（境）学生须严格按照出国（境）任务同意书执行任务，未经批准不得随意增加在外停留天数，不得随意改变行程。
