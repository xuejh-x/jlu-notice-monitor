吉林大学2026年硕士研究生招生考试初试成绩查询及复核公告

更新时间：2026-02-26 点击次数：次

根据教育部及吉林省教育考试院相关文件要求，现将我校2026年硕士研究生招生考试初试成绩查询及复核相关事宜公告如下：

一、关于成绩查询

我校2026年硕士研究生招生考试初试成绩预计于2026年2月28日8:00开通查询，考生可通过中国研究生招生信息网（http://yz.chsi.com.cn/）进行成绩和排名查询。

排名为初试总成绩（不含各类加分）排名，区分院系、专业及学习方式，不区分研究方向，不包含推免及各类专项计划考生；排名仅供参考，不作为是否进入复试的依据；各类专项计划考生不提供排名查询；请广大考生静待我校公布复试基本分数线要求。

二、关于成绩复核

我校2026年硕士研究生招生考试初试成绩，已由吉林省教育考试院与我校完成严格复核。为切实保障考生合法权益，现将成绩复核申请的相关事宜通知如下：

1.考生须登录指定网址（https://zsb.jlu.edu.cn/cjfuhe）申请成绩复核。我校仅受理该网址线上申请，不接受任何其他形式的复核申请。

2.考生须凭本人考生编号、证件号码及联系电话登录系统，并按要求上传身份证件、准考证及承诺书等相关材料扫描件。

3.成绩复核申请通道与成绩查询通道同步开通，受理时间截止至3月3日8：00，届时系统将自动关闭，逾期不再受理任何申请。

4.国家统考试卷由吉林省教育考试院统一保管，相关复核申请由我校汇总后，统一报送至吉林省教育考试院核查；自命题科目复核工作由我校组织专人负责实施。

5.成绩复核结果将由我校统一反馈，考生可于2026年3月5日10：00后登录成绩复核申请网址查询结果。

三、关于复试分数线公布及复试时间

我校暂定于2026年3月中旬左右公布复试基本分数线（请随时关注吉林大学招生网：http://zsb.jlu.edu.cn/），3月下旬进行复试（具体时间以各研究生招生单位通知为准）。

成绩复核联系电话：0431-85166195、0431-85168419（仅限工作时间拨打）
