关于开展“健康校园行，轻身不‘负重’”公益服务活动暨“一站式”学生社区“健康成长学堂”启动仪式的通知
发布日期：2026-10-13

各学院：

为深入贯彻落实立德树人根本任务，积极弘扬白求恩精神，发挥“一站式”学生社区育人功能，充分发挥学科专业优势及育人特色，推动优质临床资源与健康服务精准下沉学生社区，以学科专业实践赋能师生成长，引导师生树立正确的健康饮食和科学减重观念，党委学生工作部、白求恩第三临床医学院将在新民校区“一站式”学生社区开展“健康校园行，轻身不‘负重’”公益服务活动暨“一站式”学生社区“健康成长学堂”启动仪式。

一、时间

2026年10月17日（星期六）9:00-13:00

二、地点

新民校区 “一站式”学生社区

三、主题

“健康校园行，轻身不‘负重’”

四、活动内容

1、“一站式”学生社区“健康成长学堂”启动仪式

通过在新民校区“一站式”社区建立“健康成长学堂”，切实服务在校师生，为师生身心健康和科学饮食提供专业建议和帮助，实现“一站式”学生社区服务与育人的双向赋能，着力培养具备“创新图强 兴北报国”精神和白求恩精神的新时代医学人才。

2、健康饮食和体重管理科普讲座

由中日联谊医院临床营养科主任王雪教授为师生带来健康饮食和科学减重主题科普讲座，围绕科学减重核心原则、日常膳食营养搭配、校园健康饮食方案、常见减重误区破解等内容开展科普讲座，助力师生树立科学的饮食与体重管理理念，养成终身受益的健康生活方式。

3、健康营养宣传展

由白求恩第三临床医学院学生志愿者为参加师生提供健康科普讲解服务，进行健康知识交流，近距离感知医学专业内涵，深化学科理解与专业认知。

4、健康体检公益义诊服务

由中日联谊医院临床营养科、超声科等专家团队和学生志愿者为在校师生进行公益义诊，内容包括免费健康查体、人体成分分析（体脂检测、骨骼肌含量等）、肝脏彩超、骨密度测量等内容。针对检查结果出具专业体检报告，并提供科学化指导和免费减重食谱。

五、参与方式

1.请参与同学扫描活动报名二维码，并根据预约时间段前来进行检查，活动现场请出示报名成功截图。（预约流程见附件）

2.活动期间请同学们遵守现场秩序与安全规定，听从工作人员安排。

六、联系人

丰裴培、施博书

联系电话：84995323
