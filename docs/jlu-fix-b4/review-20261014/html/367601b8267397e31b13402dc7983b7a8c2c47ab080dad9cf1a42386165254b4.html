关于我校学生跨校参加2026年“挑战杯”中国大学生创业计划竞赛东北振兴产业升级专项赛的公示

发布时间：2026-09-20  点击：次

根据挑战杯中国大学生创业计划竞赛组委会要求，现对我校动物科学学院2021级动物科学四年制本科生刘展鹏（学号：85210226）跨校参赛情况进行公示。

项目具体情况如下:

项目名称：衡曲中草药一体化产业链平台

申报单位：北京第二外国语学院

参赛成员：徐慧林、刘展鹏（吉林大学）、Alejandro Rodríguez Aguilar

指导老师：申达宏

现予以公示。

公示期间，如有异议请与校团委联系。

公示时间:9月20日-9月24日

联系人:房檬檬

联系邮箱:fangmengmeng@jlu.edu.cn
