通知公告

关于对吉林大学大学生艺术团2027年优秀应届本科毕业生免试攻读研究生艺术类竞赛加分资格认定的通知

发布时间：2026-08-25  点击：次

按照《吉林大学推荐优秀应届本科毕业生免试攻读硕士学位研究生工作管理办法》（校发［2022］59号）规定，结合我校实际，现将有关事宜通知如下：

一、认定条件

具备下列条件的大学生艺术团2027届优秀应届本科毕业生可申报参加艺术类竞赛加分资格认定：

1. 申报人应满足《吉林大学推荐优秀应届本科毕业生免试攻读硕士学位研究生工作管理办法》（校发［2022］59号）规定的基本条件。

2. 申报人还需满足以下条件：

（1） 参加艺术类竞赛加分资格认定的学生需为大学生艺术团在编团员且工作满一年以上，在团期间积极参与艺术团组织的各项演出任务。

（2） 应在通过学校认可的国家级、省级艺术类赛事中获取名次，且该项赛事应为吉林大学大学生艺术团统一组织参与的。

二、工作程序

8月26日—8月29日学生自愿申报。申报人需准备《加分资格认定申请表》、学院教务部门统一出具的学业成绩单（横版，由教务秘书签字并加盖学院教务专用章）以及艺术类赛事获奖证明。上述材料的电子版扫描件（含公章）应于8月29日16点前以压缩包形式发至邮箱dl_yn@jlu.edu.cn，逾期视为自动放弃。纸质版材料于8月29日16点前交至校团委办公室（鼎新楼C区3楼C344）；8月29日提交截止后，校团委对申报人提交的电子材料进行资格审查，确定拟审核名单；8月30日—9月1日校团委组织专家组开展业务审核，确定加分资格认定名单并进行公示。

三、业务审核

业务审核分为器乐类、声乐类、舞蹈类和播音主持类。

（一）器乐类业务审核分为视奏和独奏展示两部分。申报人应自备独奏曲目及乐器，不允许使用伴奏，独奏展示时间不超过5分钟。

（二）声乐类业务审核分为自备歌曲演唱和音乐素养考察两部分。自备曲目应为中文歌曲，不允许使用伴奏，演唱时长不超过3分钟；音乐素养考察为随机抽取指定题目作答。

（三）舞蹈类业务审核分为形体形象、舞蹈基本功展示和剧目展示三部分。申报人应自备舞蹈作品、音乐伴奏及服装，剧目展示时间不超过3分钟。

（四）播音主持类业务审核分为形象气质、稿件播读、模拟主持和即兴表演等四部分。其中稿件播读、模拟主持和即兴表演均为随机抽取指定题目作答。
