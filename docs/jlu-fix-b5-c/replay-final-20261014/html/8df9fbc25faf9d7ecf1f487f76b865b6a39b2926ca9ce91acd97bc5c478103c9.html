关于征集《吉林大学2026年大学生创新创业训练计划优秀论文》的通知

发布日期：2026-01-06作者：点击：

校内各教学单位：

为深入贯彻落实国务院办公厅《关于进一步支持大学生创新创业的指导意见》（国办发〔2021〕35号）文件精神，扎实推进大学生创新创业训练计划实施，着力强化学生创新思维与创业实践能力，培养适应创新型国家建设需求的高水平创新人才，系统梳理并推广我校大学生创新创业训练计划优秀项目成果，本科生院、创新创业教育学院联合吉林大学出版社，拟编辑出版《吉林大学2026年大学生创新创业训练计划优秀论文》。该论文集为正规出版物，收录论文将予以公开发表。现将具体征稿事宜通知如下：

一、征稿对象

全校在读本科生。

二、选题范围

本论文集按新工科、新医科、新文科、新农科四大领域分类编排，主要收录我校大学生创新创业训练计划立项项目的研究成果，选题须聚焦“四新”学科领域前沿方向，突出学术创新性与实践应用价值。

三、稿件要求

1.论文观点新颖、论点明确、论证严密、材料翔实、文理通顺，字数控制在5000-8000字（含图表），格式严格参照附件要求。若投稿人在2026年3月13日（星期五）前未收到录用通知，稿件可自行另投其他刊物。

2.摘要需完整、准确概括论文核心内容与研究结论，字数控制在300字左右；关键词选取3-5个，需精准反映论文主题与学科范畴。

3.作者信息需完整规范。第一作者及通讯联系人须注明姓名、所在学院及专业、联系电话、通讯地址、电子邮箱等关键信息，便于后续联络。

4.项目信息标注。凡依托大学生创新创业训练计划项目撰写的论文，须明确注明项目名称、项目编号及项目来源（如国家级、省级、校级）。

5.稿件须为作者原创成果，严禁抄袭、剽窃等学术不端行为。拟录用论文将统一通过学术不端检测系统进行查重，检测不合格者将取消录用资格。

四、投稿方式及流程

1.投稿截止时间：2026年3月9日（星期一）。请投稿人在此前登录吉林大学创新创业教育学院官网（https://cxcyjyxy.jlu.edu.cn/），通过“论文投稿”专项板块提交电子文稿，稿件标题格式统一标注为“姓名+联系电话+论文题目”。

2.评审与出版。本科生院、创新创业教育学院将组织相关领域专家组成评审委员会，对投稿论文进行严格评审，择优确定收录篇目并编辑出版。
