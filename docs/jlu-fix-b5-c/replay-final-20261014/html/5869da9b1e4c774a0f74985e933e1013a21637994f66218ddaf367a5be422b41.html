关于软件学院2025级魏辰坤同学体育Ⅱ课程成绩更正的公示
来源： 发布日期：2026/10/08 点击量：
根据《关于进一步明确本科生课程考核等有关问题的通知》（校教字[2018]47号）文件有关精神，现对以下课程成绩更正进行公示：
开课学期 2025-2026学年第2学期 课程名称 体育Ⅱ
课程号 ae22921002 课序号 04
开课单位 公共体育教学与研究中心 任课教师 柳钢
联系电话 18686530078
变更理由及
学生基本信息		 变更理由：魏辰坤同学未在已选的柳钢老师班级上课（转专业后进入班级），期末未及时联系选课老师，导致期末没有成绩。经调查，该同学在孙大利老师处完成了学习任务，并参加了期末考试，成绩为78分。特此申请将成绩变更为78分。
软件学院数据科学与大数据技术2025级魏辰坤55251219

公示日期: 2026年_10月_8日至2026年_10月_13日如有异议请于公示期内向本科生院教学运行科反映。
