关于开展“学科星图·探索吉大”跨学科学业交流系列活动（第八期）——农业试验基地一日野外生存实训活动的通知
发布日期：2026-10-10

各学院：

为全面落实立德树人根本任务，进一步强化学生实践教育，锤炼学生意志品质，提升青年学生吃苦耐劳、团结协作与野外应急处置综合能力，党委学生工作部、党委武装部将组织开展“学科星图·探索吉大”跨学科学业交流系列活动第八期，农业试验基地一日野外生存实训活动。本次实训采用理论导读、实地实操、复盘总结相结合的形式，引导广大同学走出课堂、走进野外实训现场，在沉浸式实战历练中磨砺坚韧品格、凝聚团队合力，夯实野外应急应变素养。现将有关事项通知如下：

一、主 题

锤炼野外生存技能，强化实战历练素养

二、时 间

2026年10月16日（星期五）8：00-15：30

三、地 点

农业试验基地（和平校区），依托基地开阔场地、林地、田间道路开展实训。

四、参与人员

面向全校全日制本科学生，限额30人。

五、组织单位

党委学生工作部、党委武装部

六、活动内容

1、 野外生存帐篷搭建：指导教师讲解野外营地选址原则、帐篷搭建规范流程、固定加固技巧及营地安全注意事项。学生分组协作完成帐篷搭建、场地整理、营地隐患排查，掌握野外快速搭建营地实操技能。

2、 埋锅灶饭野外炊事：指导教师讲解野外无烟灶台挖掘、灶体加固、生火技巧、防火安全及野外食材处理规范。学生分组自主完成灶台搭建、食材清洗加工、野外烹饪，餐后落实灶台填埋、场地清理，落实野外炊事环保、安全、规范要求。

3、 识图用图与定向越野：开展地形图识别、比例尺运用、等高线判读、方位角测算、指南针使用教学，依托基地地形布设打卡点位。学生单人及小组组合开展定向越野打卡，掌握野外识图、定位、寻点、快速通行的实战能力。

  七、参与方式

1、请有意向参与的同学填写活动报名表，并加入活动通知群，乘车集合等相关细节将在活动群内通知。

2、本次活动以实操项目为主，对动手实践能力与团队协作能力有一定要求，请同学们结合自身情况报名。

3、活动期间请同学们严格遵守现场秩序与安全管理规定，听从指导教师安排。
