青春有“理”，等你来讲！—— 吉林大学博士生讲师团纳新啦！

发布日期：2026-09-09 编辑：高越 浏览次数: 次

时代有问，青年作答

用青年视角解读国家发展，以青春之声传递真理薪火

—— 吉林大学博士生讲师团 新学年 邀你共赴新程

我们是谁？

吉林大学博士生讲师团（以下简称“博讲团”）成立于2010年6月，是吉林大学党委领导下、党委研究生工作部具体指导下的研究生团学组织。以朋辈宣讲和浸润教育为切入点，强化思想政治教育和价值引领，旨在通过面向校内外开展党的创新理论宣讲，不断提高广大青年学子及人民群众思想政治觉悟，促进党的创新理论入脑入心。

在十六年的发展历程中，博讲团累计开展校内外理论宣讲600余场，参与人数超过6万人。先后荣获“中宣部2023年基层理论宣讲先进集体”“吉林省基层理论宣讲先进集体”“2024年中国研究生院院长联席会研究生案例成就奖、优秀组织奖”“2024年高校服务吉林振兴优秀案例”等20余项国家级、省部级荣誉。相关活动和经验获得新华网、光明日报、中国教育报、学习强国、全国高校思想政治工作网等多家媒体报道。

我们在做什么？

01 打磨特色课程 开展校内校外宣讲

2021年以来，博讲团先后策划推出“新征程·青年讲”学习贯彻党的二十大精神、“深入贯彻中央八项规定精神学习教育”“北上精神”“赓续荣光启新程 擘画蓝图谱新篇”学习贯彻党的二十届四中全会精神、“白山黑水 铁血丰碑”东北抗联精神等二十余个系列宣讲专题。讲师们走进校内研究生培养单位，结合学科背景及相关知识，将理论讲出高度、讲出热度、讲出亲和度，成为党的最新理论、大政方针、时政热点的“知之者”“好知者”“乐之者”。

坚持推动“七进七讲”工作走深落实做细。博讲团通过走进机关、企业、社区、农村、校园、网络、军营，充分发挥自身理论优势与专业优势，针对不同受众群体开展分众化、针对性宣讲，教育引导广大人民群众运用党的创新理论研究新情况、解决新问题，提升博讲团在社会的知名度与影响力。

02植根学府厚土 拓展交流合作

博讲团既扎根吉林大地，又面向全国开展校际联学联讲联建。先后受到北京大学、清华大学、复旦大学、南开大学、陆军工程大学等多所高校邀请，参加校际联合宣讲活动，相互交流、激荡思想，通过朋辈之间的交流互动，不断提升讲师自身的理论水平。

2025年6月11日，博讲团主办“青春向北启新程·青年力量谱新篇”全国高校接力宣讲吉林大学站活动。来自吉林大学、哈尔滨工业大学、大连理工大学、东北师范大学、中南财经政法大学、中国科学院长春光学精密机械与物理研究所等11所高校、科研院所的宣讲团代表，围绕“夯实基础研究根基，激发创新源头活水”进行宣讲交流活动，从科技智造、教育兴邦、乡村振兴、医疗健康等多角度阐释了新时代青年的使命与担当。

2025年12月10日至12日，吉林大学博士生讲师团携手国内15所高校的青年宣讲团体开展“赓续抗联精神 奋进时代新程”全国高校接力宣讲活动。来自吉林大学、中央党校、浙江大学、哈尔滨工业大学、华中科技大学、山东大学等16所高校的宣讲团代表，围绕东北抗联精神与青年强国担当展开宣讲。各代表从不同视角出发，结合历史史实、地域特色与时代使命，生动讲述了东北抗日联军艰苦卓绝的斗争历程，阐释了东北抗联精神中蕴含的爱国主义情怀、坚定信念、艰苦奋斗和勇于牺牲的核心内涵。

03角逐全国赛场 矢志争创一流

博讲团积极参与全国性理论宣讲比赛，紧密追踪青年理论宣讲的前沿动态，不断汲取先进的宣讲理念、技巧与经验，持续推动宣讲内容与形式的创新升级。团队成员获评首届“东大-昆山”杯全国高校青年研究生理论宣讲邀请赛总决赛特等奖、“美丽中国 我是行动者”高校研究生生态文明宣讲比赛决赛一等奖、“筑梦讲理·青年向北”吉林省大学生理论宣讲比赛文魁奖等各类赛事荣誉。

04丰富活动形式 助力团队成长

博讲团定期开展“研行春城 艺路生花”“艺心向党 研路同行”等美育浸润活动和素质拓展活动，走进吉林省美术馆、吉林省自然博物馆、长春市博物馆、长春市规划展览馆、长光卫星航天科普教育基地等参观体验；组织前往吉林省近现代史展馆、东北沦陷史陈列馆、侵华日军第731部队罪证陈列馆开展实地研学，铭记烽烟历史、汲取奋进力量。丰富多彩的拓展活动有效加强了讲师之间的团队协作精神，提升其人际交往能力与动手能力，促进讲师综合素质的全面发展。

我们需要这样的你

1.讲师

职责：代表博讲团进行校内外宣讲及参与宣讲课程设计。

应聘条件：

①全校在读博士研究生；

②政治面貌需为中共党员（含预备党员）、共青团员；

③关注时事政治和社会热点问题，具有较强的语言表达能力；

④有授课经验或教学实习经历者优先。

2.运行机构

①综合事务部

职责：负责博讲团内部建设和日常事务管理，统筹规章制度制定、会议文书、档案年鉴、人员考核及后勤保障等工作，并协助各部门开展相关活动。

②教务管理部

职责：配合指导教师制定工作目标和宣讲计划，组织集体备课、试讲培训和专家授课，负责宣讲稿、PPT等内容审定及宣讲审批、统计、存档。

③组织发展部

职责：关注党的理论创新最新成果和重要时间节点，协同做好校内外宣讲工作的规划设计与组织保障，负责博讲团见面会、动员备课会等大型活动及社会实践活动的策划与组织。

④外联业务部

职责：负责开拓宣讲单位，开展宣讲单位与讲师团队的对接，联合其他高校开展联学联讲活动。

⑤宣传研究部

职责：以“吉大研究生”公众号为主阵地，负责宣传平台的运营维护，对博讲团各类活动进行记录与宣传，总结汇编博讲团各阶段工作。

应聘条件：

1.全校在读博士研究生、硕士研究生（博士研究生可兼报讲师和行政部门岗位）；

2.工作态度认真负责，耐心细致，具有较强的组织沟通协调能力；

3.能熟练进行拍摄剪辑、文案编辑者优先。

你将收获

深度成长——系统学习党的创新理论，提升政治素养与表达能力；

广阔平台——走进党政机关、基层一线，展现青年担当；

荣誉加持——团队屡获全国、省级荣誉，为你的简历增添亮色。
