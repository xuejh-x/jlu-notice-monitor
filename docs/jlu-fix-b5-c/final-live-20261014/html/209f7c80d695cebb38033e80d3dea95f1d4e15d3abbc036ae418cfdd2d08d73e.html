第十一届华为ICT大赛-中国区路演-吉林大学站

发布日期：2026-10-14 发布人： 点击量：

“华为ICT大赛”是华为公司面向全球大学生打造的ICT人才竞技交流的国际赛事，连续多年入选全国普通高校学科竞赛排行榜，是广为认可的含金量高、参赛价值大的竞赛项目。吉林大学竞赛目录B*类竞赛，具备推免加分、竞赛奖励、创新学分等政策支持。

第十一届（2026-2027年度）华为ICT大赛已启动。为助力同学们高效备赛，进一步熟悉各项赛事政策，吉林大学与华为公司联合举办专题路演活动。

路演时间：2026年10月16日12：10-13：15

路演地点：吉林大学王湘浩楼B108

路演议题：第十一届华为ICT大赛介绍、校招宣讲、往届优秀师生分享、线程QA等。

请有意参赛的师生加入大赛校内QQ群（699958793），二维码后附。竞赛官网：https://e.huawei.com/cn/talent/ict-academy/#/ict-contest?compId=85132018
