关于公示2026届优秀国际学生毕业生评选结果的通知

发布时间：2026/06/05 14:14    浏览次数：   

根据学校《吉林大学优秀本科毕业生评选办法》（校发〔2019〕385号）和《吉林大学优秀毕业研究生评选办法》（校研院字〔2021〕110号），经国际学生个人提出申请、培养单位推荐和国际教育学院审核，现将我校吉林大学2026届优秀国际学生毕业生推荐名单予以公示（详见附件，排名无先后顺序）。公示时间：2026年6月5日至11日。公示期间，如有异议，请与国际教育学院联系。

    联系人：郝老师，0431-85167163。

    邮箱： cie_affairs@jlu.edu.cn
