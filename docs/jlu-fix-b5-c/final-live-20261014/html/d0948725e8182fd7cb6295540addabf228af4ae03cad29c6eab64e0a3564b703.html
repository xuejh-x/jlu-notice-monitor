软件学院2027年拟推荐直接攻读博士学位研究生人选名单公示
来源： 发布日期：2026/06/17 点击量：



根据《关于开展吉林大学2027年招收优秀应届本科毕业生直接攻读博士学位研究生校内预选工作的通知》文件精神，按照《软件学院2027年推荐优秀应届本科毕业生直接攻读博士学位研究生工作实施方案》要求，经学生本人申报、学院推免工作领导小组考核通过，确定刘芊彤为软件学院2027年直接攻读博士学位研究生拟推荐人选。现将以上人选名单公示。

公示期为2026年6月17日----2026年6月19日，如对上述人选有异议，请在公示期内实名以书面或电子邮件形式向教务办反映。
