关于2026年中国政府奖学金年度评审结果的公示

发布时间：2026/05/13 16:20    浏览次数：   

根据《中国政府奖学金管理办法》及《2026年吉林大学中国政府奖学金年度评审工作实施办法》有关要求，本次奖学金评审采取学生登录系统进行自评，各培养单位对学生道德品行、学习成绩、学习/科研态度、活动表现进行定量打分和定性评价，国际教育学院汇总审核后代各培养单位将考评结果导入系统。经5月13日吉林大学2026年中国政府奖学金年度评审会议审核，现将本年度中国政府奖学金年度评审结果公示如下：

本年度共有 160 名学生（含申请延长奖学金资助期限博士生14名）参加此次奖学金年度评审。经评审，1名学生（CSC编号：2024GBJ001578）因无故不参评，取消其奖学金资格；其余159名学生均顺利通过年度评审，评审结果为合格。

公示期自2026年5月13—19日，如有异议请至友谊会馆115办公室反馈。




国际教育学院

2026年5月13日
