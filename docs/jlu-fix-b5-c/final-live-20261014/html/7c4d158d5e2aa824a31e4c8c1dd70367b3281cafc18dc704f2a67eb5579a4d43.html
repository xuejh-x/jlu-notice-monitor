软件学院程序设计类竞赛获奖学生申请课程免修工作通知
来源： 发布日期：2026/10/10 点击量：



根据《计算机学院软件学院关于进一步鼓励程序设计类竞赛学生参赛积极性的办法》。现学院开展2026-2027学年第一学期程序设计类竞赛获奖学生课程免修申请工作。

一、申请条件：

1、高中竞赛特长学生：高中阶段获得信息学奥林匹克竞赛全国竞赛（NOI）的金银铜选手及达到金银铜分数线的夏令营选手。

2、大学竞赛特长学生：代表吉林大学，在国际大学生程序设计竞赛（ICPC）、中国大学生程序设计竞赛（CCPC）、中国高校计算机大赛-团体程序设计天梯赛（天梯赛）、大学生计算机系统与程序设计竞赛（CCSP）的全国赛中获得银牌或二等奖以上的学生，以及在计算机软件能力认证（CSP）获得340分以上的学生。

注：达到以上申请条件不等于已确认免修，所有免修申请需经过学院竞赛指导教师会议通过，经学院教学委员会批准后，由学院通知任课教师，学生方可免修课程。

二、免修课程

1、高中竞赛特长学生：可以申请《程序设计基础》、《程序设计基础课程设计》免修。

2、大学竞赛特长学生：可以申请《数据结构》、《算法设计与分析》、《数据结构课程设计》免修。

说明：以上课程只限第一次选课学习时申请有效，不追溯获奖以前的选课和成绩。

三、成绩认定

最终成绩建议记为95分(具体成绩由任课教师视实际情况而定)，绩点为4.0。

四、报名时间

请于2026年10月15日11：00前将免修申请表（需竞赛责任教师和任课教师签字）及相关获奖证明材料交到王湘浩楼B337，逾期不再办理。
