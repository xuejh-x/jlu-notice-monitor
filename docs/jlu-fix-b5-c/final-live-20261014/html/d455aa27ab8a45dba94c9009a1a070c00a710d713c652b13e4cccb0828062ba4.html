关于开展国家级创新创业学院教材建设项目申报工作的通知

发布日期：2024-06-26作者：双创教育办公室点击：

各教学单位：
    为推动我校创新创业教育的发展，提升教学质量，根据教育部、吉林省教育厅关于国家级创新创业学院工作的相关要求，我校现启动国家级创新创业学院教材建设项目申报工作。具体事宜通知如下：
    一、申报对象
    全校各教学单位教师、研究人员，鼓励有创新创业教育经验的教师和团队积极申报。
    二、申报内容
    1.教材类型：创新创业基础教材、案例教材、专题教材等。
    2.教材要求：应体现创新创业教育的前沿性、系统性和实用性，注重理论与实践相结合，具有较强的教学指导意义和应用价值。
    三、申报条件
    1.申报教材应为原创作品，符合国家有关知识产权的规定。
    2.教材应有明确的教学目标、内容结构和教学方法，具备较高的学术水平和实践指导意义。
    3.申报人应具备相关学科的教学或科研经验，团队成员结构合理、分工明确。
    四、申报程序
    1.提交材料。申报人需提交《吉林大学国家级创新创业学院教材建设项目申报书》，如已完稿可提供教材样本。
    2.审核评审。学校将组织专家组对申报材料进行审核评审，评选出优秀教材全额资助出版。
    五、时间安排
    材料提交截止日期：2024年7月1日（星期一）
    联系人：杨婷婷  李赫
    联系电话：85167970 85167825
    电子邮箱：cxcy@jlu.edu.cn
    请各教学单位高度重视此次申报工作，积极参与，为我校创新创业教育贡献力量。
