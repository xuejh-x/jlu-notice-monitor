关于2023-2024学年秋季学期线上通识课程选课通知

发布时间：2023-09-19  点击次数：

各教学单位、各位同学：

    为丰富我校通识教育课程资源，向本科生提供更多优质通识教育课程，本学期选课中提供校外引进的22门线上形式的公选课。请各单位做好此通知在学生范围的转发工作，为师生提供准确到位的指导与解答。相关要求如下：

    一、课程设置

    我校将于2023-2024学年秋季学期开设通识教育公选课线上课程22门，具体课程名单及相关信息详见附件1。

    二、选课方式

    学生通过电脑（或手机）登录选课服务平台（https://icourses.jlu.edu.cn）自行选课。

    三、学分要求

    各类教学改革试验班、唐敖庆班、各类卓越计划相关专业学生在校期间内应至少有2门公选课（含“大学生心理健康”）通过在线课程公选课途径学习并获得学分。

    四、开课平台

    线上通识课将根据课程来源不同，分别在“东西部课程联盟”（网址：http://www.zhihuishu.com/）、“吉林大学在线学堂（网址：http://jlu.fy.chaoxing.com/portal）”两个平台上开设，在选课系统选课成功后，须登录课程所在平台完成学习过程，具体流程详见附件2、3。

    五、平台使用

    选择线上课程的同学，若之前没有登录过相应的学习平台，需要注册账号并将学号等信息输入平台，系统后台与选课信息进行关联并实名认证。之前已将自己的学号关联至手机号的同学如更换手机号或遗忘了密码，请与平台客服联系。注意完善平台上各类联系信息，手机、邮箱等，以保证能够及时接收到相关通知。具体操作详见附件中的学生手册。此部分在线课程的学习任务全部在线完成，请同学们注意平台上的各类通知，并严格按照手册中的说明执行，以免影响学习进度，导致无法获得学分。如遇网页无法刷新等问题，第一时间咨询平台线上客服或致电网页上的技术服务部门，切莫因为网络问题放弃学习进度，以至无法获得成绩。各门课程均可在平台上查询到成绩评定的方式，考查、考试时间，及各部分占总成绩的比例。课程成绩一般在期末考试周结束后至下一学期退补选开始前登录至教务管理系统。

    六、选课时间

    在线通识课的选课时间与全校退、补、改选校公选课选课时间同步，即9月25日-27日。

    七、课程学习时间

    在线通识课程的学习时间为2023年10月9日-2023年12月10日。

    八、注意事项

    无论校内或校外平台，同学只需在选课系统上进行选课操作，待退补选结束后系统会自动在课程对应的课程平台上将所选课程与学生账号绑定，学生只需登录对应的平台并进行身份认证即可看到所选课程，不需要在课程平台上重复选课。此次开设的在线通识课程的学习过程集中在线上（主要使用pc或移动端app进行学习），此类课程学习不设置实体课堂，学生请登录对应的课程平台进行学习。

    开始学习前，务必确定选课所属平台，仔细阅读平台课程说明，以免错过考试时间。课程平台设置“学习习惯分”，学习期间需自行安排好时间计划，避免集中刷课。课程设置线上考试，请关注平台课程通知，按时参加考试，并关注考卷线上提交结果，避免提交失败造成考试成绩缺失。线上通识课程的成绩不可撤销。

    九、学前指导

    采用线上直播的形式为同学们进行学前指导，明确要求。

    直播时间：9月28日9:00-9:30（直播后可回放观看）
