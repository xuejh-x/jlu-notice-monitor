关于开展2025年度吉林大学研究生“中科美菱奖学金”评选工作的通知

发布日期：2025-02-27 编辑：齐乾坤 浏览次数: 次

相关研究生培养单位：

吉林大学研究生“中科美菱奖学金”是由中科美菱低温科技股份有限公司在我校设立，用于奖励我校“德、智、体、美、劳”全面发展的优秀学生的社会奖学金。为做好2025年度吉林大学研究生“中科美菱奖学金”的评审工作，根据《吉林大学研究生社会奖（助）学金评审办法》（校发[2018]24号）及设奖方要求，现将相关事宜通知如下：

一、奖励范围

生命科学学院、基础医学院、公共卫生学院、药学院、白求恩第一临床医学院、白求恩第二临床医学院、白求恩第三临床医学院、动物医学学院的基础学制内的非定向全日制研究生。

二、奖励名额及标准

每年奖励研究生20人，奖励标准为0.5万元/人，奖励总金额为10万元人民币。

具体奖励名额按设奖方要求分配如下：

1.生命科学学院3名；

2.基础医学院2名；

3.公共卫生学院3名；

4.药学院2名；

5.白求恩第一临床医学院3名；

6.白求恩第二临床医学院2名；

7.白求恩第三临床医学院2名；

8.动物医学学院3名。

三、申报条件

1.坚持以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，树立共产主义远大理想。

2.热爱祖国，热爱人民，拥护中国共产党的领导。积极践行社会主义核心价值观，具有敢于担当、不懈奋斗、自强不息的精神。

3.遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯，无违法违纪行为。

4.具有乐观向上的人生态度，尊敬师长，身心健康，热爱集体，积极参加校园文化活动。

5.德智体美劳全面发展，能够激励和带动身边同学敦品励学、奋发向上、顽强拼搏。

6.吉林大学研究生“中科美菱奖学金”参选人员在满足上述条件的同时，还必须在以下某一方面表现特别优秀：

（1）热爱科学研究工作，勇于探索，敢于创新，具有较强的科研能力，当前学历阶段取得的代表性成果在五个价值（科学价值、技术价值、文化价值、社会价值和经济价值）的某一方面或多个方面突出；

（2）在热心公益、服务社会等方面事迹突出；

（3）自强自立，拼搏进取，在励志成才方面事迹突出，具有示范和引领作用；

（4）荣获国家级荣誉称号。

7.同一学历阶段，研究生不能重复获得吉林大学研究生“中科美菱奖学金”。同一学年度内，校级社会奖学金不可兼得。

四、评审程序

1.发布通知。党委研究生工作部在校内办公网上发布评选工作通知。

2.个人申报。研究生向所在培养单位提出申请并提交相关材料。

3.单位评选。研究生培养单位进行初评，并将初评结果在本单位内部进行为期3个工作日的公示，无异议后确定拟获奖人选，并上报学校。

4.学校审核。党委研究生工作部会同设奖方对拟获奖人选进行审核，确定获奖人选。

5.学校公示。获奖人选在校内办公网上进行为期5个工作日的公示。

五、材料报送

相关研究生培养单位结合本单位实际情况认真组织评选推荐,于2025年3月14日（周五）13：00前将以下材料统一发送至yjsgl@jlu.edu.cn：

1.《吉林大学研究生“中科美菱奖学金”申报审批表》PDF版（需培养单位主管思政工作领导签字并加盖公章），文件命名为：中科美菱奖学金-培养单位全称-姓名-申报表；

2.《佐证材料》PDF版（本学历（截止目前）以吉林大学为第一作者单位，申请人为第一作者或除导师外第一作者的学术成果、竞赛、项目及案例等(填写最重要的3篇或3项)和各类荣誉称号或获奖证明等），文件命名为：中科美菱奖学金-培养单位全称-姓名-佐证材料。
