【吉林大学邀请函】东北五校2027届毕业生秋季双选会吉林大学专场
发布：刘子祯 创建时间：2026-09-20 15:22:01 点击量：

尊敬的用人单位：

东北五校毕业生就业工作协作体衷心感谢贵单位多年来对吉林大学、大连理工大学、哈尔滨工业大学、东北大学、哈尔滨工程大学的重视、信任与支持。

为全面落实党中央、国务院对高校毕业生就业创业工作的决策部署，为用人单位和毕业生搭建供需精准对接平台，为区域经济振兴和人才储备提供持续动力，东北五校将联合举办2027届毕业生秋季双选会。吉林大学2027届毕业生秋季双选会定于2026年10月21日（星期三）召开，诚挚邀请贵单位莅临参加。

各高校将提供协议酒店信息，参会代表可根据需要自行预订宾馆房间，各高校不再统一安排参会代表住宿及宾馆用餐。

会议费按参会单位预订展位数量收取，标准为800元/展位，每展位一般可容纳两人。

招聘会当日，各高校为参会单位代表提供1餐工作餐。

会务具体事宜以各高校安排为准，详尽安排参见各校就业网。


东北五校毕业生就业工作协作体

2026年9月15日

 


吉林大学双选会安排

一、时间及地点

举办时间：2026年10月21日（星期三） 9:00-15:00

地点：中心校区-宋治平体育馆

二、报名方式

（一）报名时间：2026年9月17日—10月15日

（二）报名方式

方式一：PC端报名网址：Dongbei.ApplyOffer.com

方式二：手机端报名

 

（三）注意事项

请报名单位于10月15日12:00前完成缴费，否则视为放弃报名资格，不予保留展位。

请在网上报名时认真填写发票信息，信息一经提交将无法修改。发票将以短信形式统一发送至预留手机，请注意查收。本次双选会仅能开具增值税普通电子发票，发票内容为“招聘服务费”，开票方为本次双选会协办方。

组团报名请联系会务组专属报名联络专员，双选会大型宣传品申报请联系吉林大学学生就业中心市场科。

三、会场展位

会场设在吉林大学宋治平体育馆，展位为1.2m×1m的标准展位，内含两个座位。请参会单位根据展位大小自备宣传材料。原则上各用人单位不单独摆放桁架、不悬挂横幅等，以网上宣传为主。

 

四、食宿

1.本次双选会参会代表食宿自理。

2.招聘会当日中午，学校提供工作餐。

3.协议酒店信息（预订酒店时需说明是参加吉林大学毕业生双选会）

五、接送站安排

为方便各参会单位代表顺利抵达酒店，会务组将于10月20日（星期二）安排接送站班车，在协议酒店提供定点接送服务。请需要乘坐接送站班车的单位代表务必于10月15日（星期四）12:00前，扫描下方二维码并准确填写信息。

 

本次接送站服务仅在10月20日提供，10月21日会议当天将安排从协议酒店至会场的车辆，详情请留意微信群内通知。
