2023级免试推荐研究生工作通知5- 关于公示2023级推免综合成绩的通知

发布日期：2026-09-06 发布人： 点击量：

根据《计算机科学与技术学院推荐2027年优秀应届本科毕业生免试攻读研究生实施办法》、《素质类项目加分细则》的要求，学院教务办汇总了2023级推免学业成绩、素质项目加分，计算出2023级推免综合成绩及排名，现进行公示。

公示期为：2026年9月6日-2026年9月12日，如有异议，请实名向学院反映。

联系人：王老师

邮箱：wangqiangqiang@jlu.edu.cn
