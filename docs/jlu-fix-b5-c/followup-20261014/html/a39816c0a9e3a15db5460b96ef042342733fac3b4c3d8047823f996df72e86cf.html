广西2023年定向吉林大学招录选调生拟录用人选公示

广西2023年定向吉林大学招录选调生

拟录用人选公示

 

    根据《广西2023年定向吉林大学招录选调生公告》的有关规定，经过志愿报名、资格审查、笔试、面试、考察、体检等工作程序，经研究，确定王诗弈等10名同学为广西选调生拟录用人选，现予以公示：

    王诗弈、姜  鹏、唐文根、周盼盼、吕鸿汀、蒋小梅、莫佳欣、韦  玮、黄真福、黄晓鑫

    公示期：2023年6月29日—7月5日。

    如对公示人选有异议，请以书面形式并署真实姓名,于2023年7月5日前向广西自治区党委组织部干部队伍建设规划办公室反映（直送的以送达日期为准；邮寄的以邮戳日期为准）。如实反映拟录用人选有关问题受法律保护。

地址：广西南宁市民族大道103号广西自治区党委组织部干部队伍建设规划办公室，邮编：530022

联系方式：0771—8808579
