关于组织我校在校生报名杭州市余杭区暑期实习“朝露计划”活动的通知
发布：王硕 创建时间：2026-06-04 14:54:58 点击量：

为抢抓就业工作冲刺关键期，进一步提升我校学生综合素质能力，推动校地融合发展，我校应余杭区邀请组织我校学生参加余杭区“朝露计划”暑期实习，具体安排如下：

一、招募计划及对象

面向全校在读学生，具体岗位及专业要求见附件。

二、基本要求

1.品学兼优，表现突出，具有较强的思想政治素质。

2.具有较好的理论功底、文字表达能力。

3.学生本人具有参加本次实习实训活动的意愿，并能够保证全程、全心参与实习实训活动。

4.有较强的沟通协调能力和团队协作意识。

三、实习计划及报名方式

（1）政务实习

1.实习生报到时间暂定为7月14日，实习期限根据具体岗位要求（1个月-3个月）。

2.政务实习生由学校推荐报名。交通、住宿、餐食学生自理，杭州籍同学优先。

3.报名方式：6月14日18:00前将【政务实习】学生信息表发送至jdjy85167001@163.com并以姓名-学院-余杭区政务实习命名。

（2）企业实习

1.实习生报到时间暂定为7月14日，具体实习期限可由实习生与企业商议。

2.实习薪资由实习生与企业自行商议，交通、食宿由实习生与用人单位协商解决。

3.报名方式：6月15日前将实习生报名表与个人简历发送至yhrcfw@163.com，缺少材料视作报名失败；最终是否被应聘公司录用，以用人单位通知为准。

联系电话：0431-85167001
