打包验收最初的测试夹具缺少 SQLite 必填默认值，且对内置来源直接改测试库地址会被既有配置同步覆盖；改为独立来源代号和完整测试记录后通过。来源级抓取计数按真实 API 的 `source_results` 读取，未修改应用契约或放宽断言。最终通过轮只访问回环控制页面；早期误用了内置蓝桥杯来源的一轮仍遇到已记录的 TLS 失败，没有冒称其联网恢复。

暂存扫描共 18,325 个文件、3,586 个不同 blob，无私钥/真实令牌/数据库命中。新增 `.gitattributes` 保持原始证据和测试夹具的字节，不清理历史空白；17,797 个证据/夹具文件逐一与暂存 blob 对照，0 个差异。全部可公开审计证据按用户要求上传；旧测试私钥和所有私有备份留在本地。

发布前通过连接器与本机 Git 确认远端 master 为 `0f1fa9c6b95893873f59a249d7ddb30d84b336ea`，没有 v0.7.5 标签或 Release，现有凭据具备推送权限。本机默认网络路径与现有代理均遇到 TLS EOF，后使用既有可用节点启动发布专用临时回环代理，通过 WLAN 成功访问 GitHub。临时进程不启用 TUN/DNS，不修改现有 Clash、系统代理、路由或证书；完成上传后关闭。
