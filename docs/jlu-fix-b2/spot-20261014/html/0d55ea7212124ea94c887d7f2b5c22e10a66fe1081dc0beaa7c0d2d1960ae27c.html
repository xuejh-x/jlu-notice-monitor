吉林大学附属中学2026年公开招聘教师（第三批次）笔试合格、进入面试环节人员名单公示
作者：  时间：2026-09-06  点击数：

吉林大学附属中学依据《吉林大学附属中学2026年公开招聘教师公告》中的工作安排，于2026年9月5日进行笔试，现将笔试合格、进入面试环节人员名单进行公示：

赵洺函

请笔试合格、进入面试环节人员于2026年9月7日按照学校电话通知的内容，携带本人身份证到吉林大学附属中学参加面试。未按照约定参加面试者视为自动放弃面试资格。
