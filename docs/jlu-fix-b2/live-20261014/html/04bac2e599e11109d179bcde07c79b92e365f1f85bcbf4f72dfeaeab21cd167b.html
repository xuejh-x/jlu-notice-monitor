关于补发两名同学2026-2027学年退役士兵国家助学金公示的通知
发布日期：2026-10-14

各相关学院：

根据《财政部 教育部 人力资源社会保障部 退役军人部 中央军委国防动员部关于印发〈学生资助资金管理办法〉的通知》（财教〔2021〕310号）、教育部全国学生资助管理中心《关于做好2026年服兵役高等学校国家教育资助等信息录入审核工作的通知》（教助中心〔2026〕27号）等文件精神和要求，经个人申报、学院初审、党委学生工作部审核，拟确定文学院暨新闻与传播学院王珺琦等2名同学为2026-2027学年退役士兵学生享受国家助学金拟资助人员（名单及资助金额见附件）。

公示期为2026年10月14日至10月20日。如对公示名单有异议，请在公示期内具实名以书面或电子邮件形式如实向党委学生工作部资助管理科反映。
