关于评选2026年“唐敖庆化学奖学金”的通知
作者：  时间：2026-10-13  点击数：

为支持化学学科人才培养，推动学科发展，吉林大学唐敖庆教育基金会专门设立“唐敖庆化学奖学金”。根据吉林大学唐敖庆教育基金会工作安排，“唐敖庆化学奖学金”2026年评奖工作已经开始，现将奖学金评选工作相关事宜通知如下：

一、参评单位名单：

本年度“唐敖庆化学奖学金”参评单位共计26家，分别为：

1、清华大学、北京大学、北京化工大学、北京师范大学、东北师范大学、中山大学、上海交通大学、复旦大学、中科院大连化学物理研究所、南开大学、山东大学、四川大学、厦门大学、南京大学、兰州大学、武汉大学、中科院化学研究所、长春应用化学研究所、浙江大学、中国科学技术大学、南方科技大学、西安交通大学、华南理工大学、苏州大学和杭州师范大学：以上25个单位每单位评选2人；

2、吉林大学：评选6人。

二、奖励名额：

本年度“唐敖庆化学奖学金”拟授研究生共56人

三、奖金数额：

本年度“唐敖庆化学奖学金”奖金金额为2万元/人
