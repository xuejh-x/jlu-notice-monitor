关于公布2026年中美青年创客大赛校赛评审结果的通知

发布日期：2026-05-27作者：点击：

校内各教学单位：
    根据《关于举办2026年中美青年创客大赛校赛的通知》（2026年4月27日）要求，学校于5月15日组织专家对参赛作品进行了评审工作，通过评审及答辩环节，评出校赛一等奖2项，二等奖4项，三等奖6项，优秀奖8项。现将获奖名单予以公布，详见附件。

创新创业教育学院
