关于召开中共吉林大学第十五届委员会第五次全体会议的通知
2026年10月10日 15:02  党委办公室

校内各单位：

    为深入学习贯彻落实习近平总书记重要贺信精神，牢记嘱托、勇担使命，感恩奋进、勇毅前行，奋力推动中国特色世界一流大学建设迈上新台阶、开创新局面，学校党委决定召开中共吉林大学第十五届委员会第五次全体会议。具体事宜通知如下：

    一、会议时间
    2026年10月14日（星期三）9:00
    二、会议地点
    中心校区鼎新大讲堂
    三、主  持
    中共吉林大学第十五届委员会常务委员会
    四、主持人
    田  辉  党委书记
    五、会议议程
    （一）党委书记田辉代表党委常委会作工作报告；
    （二）校党委委员对《中共吉林大学第十五届委员会第五次全体会议决议（草案）》进行表决。
    六、出席人员
    学校党委委员
    七、列席人员
    学校纪委委员；校学术委员会、校学位评定委员会、校教学委员会负责人；全校处级领导干部；师生代表。
    八、其他事项
    （一）全体参会人员穿着正装，党员佩戴党徽；
    （二）请各单位高度重视、认真组织，提前统筹工作、预留时间，确保参会人员按时参加，于10月12日（星期一）12时前填写参会情况统计表（见工作群）；
    （三）请参会人员严格遵守会场纪律，提前15分钟签到入场，无特殊原因不得请假，确需请假需在参会情况统计表中详细说明原因。

    联系人：纪核鑫  85155365、15764403222
