关于计算机科学与技术学院2024级邢航毓同学数据结构课程设计课程成绩更正的公示

发布日期：2026-10-09 发布人： 点击量：

转本科生院通知：

根据《关于进一步明确本科生课程考核等有关问题的通知》（校教字[2018]47号）文件有关精神，现对以下课程成绩更正进行公示：

公示日期: 2026年_10月_9日至2026年_10月_14日如有异议请于公示期内向本科生院教学运行科反映。


开课学期 2025-2026学年第2学期 课程名称 数据结构课程设计
课程号 ae22213003 课序号 02
开课单位 计算机科学与技术学院 任课教师 孙成敏,孙成敏
联系电话 13596094596
变更理由及
学生基本信息		 变更理由：成绩核查过程中，发现计算机科学与技术专业邢航毓（学号：40240120）同学的《数据结构课程设计》课程期末总成绩合分错误，期末成绩录入有误。
该课程为实验类考查课，平时成绩由4次实验组成。在记录成绩时，教师未计入该生第3次实验成绩，导致该生最终成绩为良好。而该生第3次实验的实际成绩为满分。经重新计算，邢航毓（学号：40240120）同学成绩更正为优秀。
计算机科学与技术学院计算机科学与技术2024级邢航毓40240120
