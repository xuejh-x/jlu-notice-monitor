第17届蓝桥杯大赛报名通知
来源： 发布日期：2025/10/31 点击量：

蓝桥杯全国大学生软件和信息技术大赛（原蓝桥杯全国软件和信息技术专业人才大赛，简称蓝桥杯大赛），由中国软件行业协会指导、蓝桥杯全国大学生软件和信息技术大赛组委会主办、国信蓝桥教育科技股份有限公司承办。


第17届蓝桥杯大赛的赛项主要包括6大类：

1）软件赛：C/C++程序设计、Java软件开发、Python程序设计、Web应用开发、软件测试、网络安全

2）电子赛：单片机设计与开发、嵌入式设计与开发、EDA设计与开发、FPGA设计与开发、物联网设计与开发、5G全网规划与建设

3）人工智能赛：人工智能应用、数据分析与可视化、智能体开发

4）视觉艺术设计赛：AIGC微短剧创意设计、包装设计、插画设计、动画设计、工业产品设计、海报设计、环境艺术设计、交互设计、视频设计、文创设计、信息可视化设计

5）数字科技创新赛：数字科技应用创新、RISC-V应用创新、智能装备数字化建模

6）专项赛。


【参赛对象】具有正式全日制学籍且符合相关科目报名要求的研究生、本科生（以报名时状态为准）。

【报名和比赛时间】

软件赛、电子赛、人工智能赛的报名时间：2025年10月20日10:00至2025年12月15日14:00，比赛时间：2026年4月至6月

视觉艺术设计赛、数字科技创新赛的报名及提交作品时间：2025年10月20日10:00至2026年4月27日14:00

专项赛的报名及提交作品时间单独通知，详见官方网站。


拟报名参赛的学生，请访问如下链接或扫描二维码，了解报名方式。

蓝桥杯大赛（吉林大学）：lus-jlu.github.io/lqb
