人体解剖学系慕课西行同步课堂顺利启动
发布日期：2023-11-30 点击次数：

11月29日，为积极响应教育部高教司“慕课西行2.0”行动的号召，扎实推动优质教育资源互联共享，提升吉林大学一流课程辐射力和影响力，基础医学院人体解剖学系和赤峰学院基础医学院解剖教研室以云端直播的方式开展慕课西行——《系统解剖学实验》课程同步课堂活动。本次活动由智慧树负责联络及直播，直播地点在人体解剖学系第四实验室。

在白求恩医学部的指导下，吉林大学基础医学院-赤峰学院基础医学院开展了多次《系统解剖学实验》同步课堂线上讨论会，讨论并协商同步课堂的时间和内容，制定了课程的直播计划。

同步课堂启动仪式由吉林大学基础医学院副院长刘海岩主持，吉林大学白求恩医学部副学部长金祥雷、赤峰学院医学部副主任张俊毅分别致辞，表示希望以本次“慕课西行”同步课堂为契机，共同打造和培育建设符合高等教育发展、人才培养规格的一流课程，进一步加强校际间合作与交流，创新教研形态，实现更多的优秀教学资源共建、共享。

同步课堂第一课由人体解剖学系卢岩老师讲授，她结合视频动画生动形象地讲述了中枢神经相关内容。授课过程中，她熟练运用多种信息化教学手段，引导学生们完成课堂练习，并组织同学们积极讨论，尽管直播教室相隔千里，丝毫不影响课堂热烈的氛围。学生们纷纷表示，这样的授课方式有创新、有活力、有吸引力。

“慕课西行”是教育部推动教育资源共享、支持西部地区高等教育均衡发展倡导的重要公益教育行动，也是学校扎实推进教育数字化转型的重要依托。今后我院将深入实施同步课堂活动，持续拓围、深化、创新，推动更多优质教学资源的共享共建，努力开拓智能化课堂建设新局面。
