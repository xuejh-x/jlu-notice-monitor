笔墨承初心 数艺铸红魂 艺术学院“初心映吉大”红色书法VR展全网绽放

日期：2026-07-01 点击数： 来源:

为庆祝中国共产党成立105周年、纪念中国工农红军长征胜利90周年，深入推进美育与思想政治教育深度融合，在学校党委宣传部统筹指导下，艺术学院倾力打造全国首个红色书法专属360°全景VR线上展“初心映吉大——龚文政红色书法线上VR展览”，以笔墨赓续红色血脉，以数字技术赋能红色文化传播。

本次展览由艺术学院美术系教师龚文政创作完成，精选105幅红色主题书法作品，涵盖楷、行、隶、草等多种书体。作品紧扣建党伟业、长征精神、红色经典等主题内容，将革命精神融入笔墨书写之中，集中展现中国共产党人的初心使命与精神品格。

展览可借助VR眼镜进行身临其境体验

展览依托360°全景VR技术打造云端展厅，观众可通过手机、电脑等终端沉浸式观展，近距离感受书法作品的笔墨意蕴与红色内涵。作为学院继“远道传红韵”龚文政书法展之后持续推进红色美育的重要成果，本次展览进一步形成了“线下实体展览、线上云端传播”的育人格局。其中，2025年线下展览共展出书法及瓷上作品180余件，2026年线上VR展览实现红色文化资源数字化转化和长效传播。

新华网推送单篇突破135万阅读量

人民日报客户端予以推送


光明日报客户端予以报道


吉林省宣传部“吉宣要情”平台予以推送

展览推出后受到多家主流媒体关注报道。新华网、人民日报客户端、光明日报客户端、中国日报网、中央广电总台国际在线、中国新闻网、中国教育新闻网及《吉林日报》彩练新闻等相继推送相关内容，新华网单篇阅读量突破135万，展览全网观览量突破1000万，形成了良好的传播效果和社会反响。

此次红色书法VR展，是艺术学院立足专业特色、推动“艺术+思政+数字科技”融合育人的生动实践。下一步，学院将继续坚持立德树人根本任务，持续深化红色文化、传统艺术与数字技术融合创新，不断提升艺术教育育人实效，为培养具有家国情怀、审美素养和创新能力的新时代艺术人才贡献力量。
