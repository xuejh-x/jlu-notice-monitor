关于申报吉林省科技发展计划2027年度项目的通知

发布日期：2026-08-06 发布人： 点击量：

（一）申报方式

本次申报采取“无纸化”申报方式，申报人登陆吉林省科技计划项目管理信息系统http://www.jlkjxm.com，在系统中按照申报类别填报申报书，并上传指南要求相关附件材料，提交至所在中层单位，并提交“吉林省科技发展计划2027年度项目申报汇总表”（详见附件5）电子版至邮箱：jjj@jlu.edu.cn。中层单位对本单位申报项目的负责人申报条件、申报材料等进行审核，审核无误后推荐至学校科研院。

（二）时间安排

1.学院限额推荐的项目：《吉林省自然科学基金—青年科学基金A、B、C类（指南P1页）》、《科技人才培养---中青年科技创新人才（团队）培育项目（指南P121页）》、《科技人才培养---青年科技人才培养项目（指南P125页）》，申报以上项目的老师，请把相关项目“限项申报表”电子版及申报材料电子版（申报书和相关附件材料请合并成一个PDF，并以申报项目类别+负责人姓名命名）发送至邮箱：jjj@jlu.edu.cn，提交截止时间为8月14日（星期五）。

2.学校限项推荐的项目：《重点研发（高新技术领域）---产业关键技术（指南P58页）》、《重点研发（现代农业领域）---产业关键技术（指南P70页）》、《重点研发（社会发展领域）---产业关键技术（指南P78页）》、《重点研发（医药健康领域）---产业关键技术（指南P93 页）》，申报以上项目的老师，请把相关项目“限项申报表”电子版及申报材料电子版（申报书和相关附件材料请合并成一个PDF，并以申报项目类别+负责人姓名命名，合作协议和合作企业财务审计报告可先不提供，校内评审后补齐即可）发送至邮箱：jjj@jlu.edu.cn，提交截止时间为8月17日（星期一）。

3.申报其他项目：请在8月22日（星期六）前完成申报书系统提交及“汇总表（附件5）”电子版的提交。汇总表中的项目信息与系统中的项目信息一致，申报材料准确、真实、完整，无形式问题。

（三）申报要求及限期申报具体内容等请查看：

https://oa.jlu.edu.cn/defaultroot/PortalInformation!getInformation.action?id=69355655&channelId=179577

（四）申报老师请扫码加入《2027年省科技厅项目申报群》(二维码请在学院群或邮件上查看）。
