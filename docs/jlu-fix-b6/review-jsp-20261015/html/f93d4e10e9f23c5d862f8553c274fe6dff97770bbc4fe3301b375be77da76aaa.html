关于公示国家卓越工程师学院“长春市卓越工程师培养工程”培养对象遴选名单的通知

发布时间：2026-10-12 点击：

根据长春市人社局相关文件要求及《关于开展长春市卓越工程师培养对象遴选工作的通知》，经个人申报、中层单位初审、国家卓越工程师学院复审，拟在新材料领域遴选培养对象3名、新能源领域遴选培养对象2名。现将拟遴选名单予以公示。

公示期：2026年10月12日至10月14日，公示地点：国家卓越工程师学院6楼623室。如对公示人选有异议，请在公示期内实名以书面或邮件形式向国家卓越工程师学院反映。

联系人：王老师

电子邮箱：jluees@jlu.edu.cn
