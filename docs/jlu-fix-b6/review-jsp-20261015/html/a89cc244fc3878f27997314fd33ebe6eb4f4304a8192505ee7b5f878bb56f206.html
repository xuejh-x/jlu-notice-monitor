吉林大学历史文化学院2026年“中华优秀传统文化专项计划”硕士研究生招生报名通知

发布时间：2026-03-31浏览次数：

根据学校相关要求，现将吉林大学历史文化学院2026年硕士研究生招生“中华优秀传统文化专项计划”招生信息公布如下：


一、招生专业及人数


中国史：7人


二、招生条件


初试成绩达到招生专业所划定的学院复试线且复试成绩达到及格线的上述专业考生，可报名中华优秀传统文化专项计划。本专项计划不接受跨专业报名。


三、报名时间：3月31日至4月1日


报名考生须于4月1日下午15:00前将《吉林大学历史文化学院2026年中华优秀传统文化专项计划硕士研究生报名表》电子版发送至qixm@jlu.edu.cn，邮件主题命名：中华优秀传统文化专项-姓名。逾期不再受理。


四、录取原则


1.根据招生计划按招生考试总成绩排序由高向低依次录取，录满为止。若出现分数相同，则按初试专业课成绩（如果是两门专业课，使用两门专业课成绩之和）从高到低排序；若初试专业课成绩仍然相同，则按复试“专业笔试”和“综合素质能力”分数之和从高到低排序，择优录取。


2.中华优秀传统文化专项计划报名结束后，若普通计划有缺额，将根据招生考试总成绩顺位递补的原则进行补录，拟录取名单将一同公示。




中华优秀传统文化专项简介

为深入贯彻落实习近平总书记关于传承弘扬中华优秀传统文化的重要讲话精神，增强中华文明传播力、影响力，提高中华文化的文化自觉与文化自信，2020年11月26日，尼山世界儒学中心联合研究生院在山东曲阜尼山正式揭牌成立，研究生院院长由尼山世界儒学中心理事会理事长靳诺同志担任。在2023年8月17日召开的联合研究生院院务委员会专题会议上，尼山世界儒学中心联合研究生院更名为“尼山中华优秀传统文化联合研究生院”。

联合研究生院由尼山世界中华优秀传统文化中心联合中共中央党校（国家行政学院）、中国社会科学院大学、北京大学、清华大学、中国人民大学、北京师范大学、复旦大学、山东大学、四川大学、武汉大学、中山大学、吉林大学、南开大学、南京大学、浙江大学、兰州大学等16所一流院校，以共建共享方式开展硕士、博士研究生教育，发挥山东传统文化资源优势，汇聚全国顶尖研究力量，培养中华优秀传统文化领域的高端专业人才。

作为16所共建院校之一，吉林大学充分发挥综合性大学的学科资源优势，于2025年12月25日经第二十四次校长办公会议研究决定，成立“吉林大学中华优秀传统文化研究院”，依托历史文化学院运行。

吉林大学中华优秀传统文化研究院以服务国家文化强国战略为使命，致力于打造集人才培养、科学研究、教育教学、师资交流、学科建设、咨政服务“六位一体”的跨学科深度合作平台。研究院由韩喜平教授担任院长，整合历史文化学院、哲学社会学院、文学院、马克思主义学院、考古学院等10个学院的优质资源，汇聚了一批在中华优秀传统文化研究领域具有深厚造诣的学术领军人才。研究院的成立，标志着我校中华优秀传统文化传承发展与人才培养工作迈入系统化、建制化的新阶段。

吉林大学深度参与尼山中华优秀传统文化联合研究生院建设，聚焦特色学科方向，系统打造专题共同课与精品课程体系。学校积极组织专项研究生赴山东开展研修活动，定期举办专项研究生学术论坛，持续完善教学培养机制。依托CSSCI来源期刊《史学集刊》、CSSCI辑刊《华夏文化论坛》等高水平学术平台，吉林大学中华优秀传统文化研究院将与联合研究生院及其他共建院校协同发力，力争到2026年将联合研究生院建设成为中华优秀传统文化创造性转化、创新性发展人才培养的国际性高地。
