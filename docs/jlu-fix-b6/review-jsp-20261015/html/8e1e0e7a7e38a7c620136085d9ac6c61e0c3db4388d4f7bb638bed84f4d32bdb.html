软件学院

软件工程

软件工程

物理

专业学科门类为工学类，国家级一流本科专业建设点、吉林省特色专业、吉林省品牌专业，全国首个通过工程教育专业认证的软件工程专业，国家卓越工程师教育培养计划专业；软件工程学科是国家首批一级学科博士学位授予权点和吉林省优势重点学科；国家级一流本科课程7门，国家级实验教学中心2个，国家级教学团队1个，主编国家级规划教材12部、“101计划”教材2部，牵头斩获4项国家教学成果二等奖；研究方向聚焦“智能软件”特色方向，在智能制造、卫星遥感、生物制药、医疗健康、新兴材料等国家战略性新兴产业中应用，打造了“AI+软件+X”拔尖创新人才培养新范式；核心特色课程涵盖数据结构、离散数学、程序设计基础、操作系统、数据库系统原理、人工智能引论等；与悉尼科技大学开展3+2人才联合培养项目。

吉林大学软件学院2001年入选首批国家示范性软件学院，2021年入选首批特色化示范性软件学院，始终位于软件领域科研与人才培养第一梯队，具备坚实的专业基础；专业以产教融合创新与关键技术突破为导向，秉持“厚基础、重实践、严要求”的育人传统，培养兼具复杂工程问题解决能力、核心技术驾驭能力、产业发展引领能力，以及国际化视野与独立创新素养的软件工程师、算法工程师和研究型人才，构建支撑国产软件产业可持续发展的多层次人才生态体系；学院师资实力雄厚，现有教职工103人，其中教师88人，包括中科院外籍院士1人、欧洲科学院院士2人，万人教学名师等国家级人才8人，国务院特殊津贴专家、教育部新世纪优秀人才等各类人才29人；聘请30名中国一汽、中国电信、中科方德、长光卫星等企业总裁或总师担任企业导师，核心团队稳定且兼具前沿技术研发与教育教学经验；专业依托国内最早开展人工智能与软件理论教学科研的学科基础，汇聚丰富且与产业发展高度匹配的教学、科研、产业资源，有2个教育部重点实验室和1个工程研究中心，获省部级科研一等奖10余项，承担多项国家科技重大专项和重点研发计划等项目，形成“理论攻关-技术创新-行业应用”的智能软件研发布局；本科生中约30%左右的同学被保送或考取到北京大学、清华大学、中国科学院等院校研究生，部分同学就职于百度、腾讯、华为等著名IT企业工作，毕业生一次就业率达到90%以上，受到了用人单位的普遍好评。

数据科学与大数据技术

数据科学与大数据技术

物理

该专业学科门类为理学类，是吉林省一流本科专业建设点，是响应国家大数据产业发展需求而建设的新专业，该专业具有新工科专业的引领性前沿、交融性学科、创新性属性、跨界性产业和发展性动态特征，专业建设坚持“学生中心、成果导向、持续改进”工程教育认证的引领性前沿理念，夯实数据科学与大数据技术人才的数学基础，创新的建构数据思维和智能算法知识体系，紧跟产业发展动态，注重实践解决复杂工程问题能力，培养熟悉智能算法，掌握数据分析与处理技术，具备跨界学习能力，面向未来产业发展的工程人才和领军人物；依托计算机科学与技术和软件工程两个一级学科建设，有国家级一流本科课程7门，国家级实验教学中心2个，国家级教学团队1个，主编国家级规划教材12部、“101计划”教材2部，牵头斩获4项国家教学成果二等奖；研究方向聚焦“数据+智能”特色方向；核心特色课程涵盖数据结构、统计计算、并行与分布式计算、人工智能引论、机器学习、分布式存储等；与悉尼科技大学开展3+2人才联合培养项目。

吉林大学软件学院2001年入选首批国家示范性软件学院，2021年入选首批特色化示范性软件学院，始终位于软件领域科研与人才培养第一梯队，具备坚实的专业基础；专业依托计算机科学与技术和软件工程两个一级学科建设，是国内最早开展人工智能等数据驱动研究型的教学与科研单位，专业秉持“厚基础、重实践、严要求”的育人传统，培养具备扎实的数据科学知识和理论基础，掌握大数据分析与处理技术，具备运用专业知识解决复杂工程问题能力的大数据高级复合型人才；学院师资实力雄厚，现有教职工103人，其中教师88人，包括中科院外籍院士1人、欧洲科学院院士2人，万人教学名师等国家级人才8人，国务院特殊津贴专家、教育部新世纪优秀人才等各类人才29人；聘请30名中国一汽、中国电信、中科方德、长光卫星等企业总裁或总师担任企业导师，核心团队稳定且兼具前沿技术研发与教育教学经验；专业依托学科有2个教育部重点实验室和1个工程研究中心，获省部级科研一等奖10余项，承担多项国家科技重大专项和重点研发计划等项目，形成“数据驱动-理论创新-行业应用”的数据科学研发布局；本科生中约30%左右的同学被保送或考取到北京大学、清华大学、中国科学院等院校研究生，部分同学就职于百度、腾讯、华为等著名IT企业工作，毕业生一次就业率达到90%以上，受到了用人单位的普遍好评。
