汽车工程学院召开2026级班主任聘任工作会

日期：2026-09-30 11:54:42 作者： 访问量：

为落实立德树人根本任务，履行全员全程育人要求，帮助我院本科新生尽快适应大学学业生活，培养专业志趣、提高人才培养质量，9月30日上午，汽车工程学院2026级班主任聘任工作会在南岭校区汽车工程大楼召开。学院党委书记黄忠华、院长朱冰、相关科室负责人及2026级全体新聘班主任参会，会议由副院长王军年主持。

会上举行了班主任聘书颁发仪式。黄忠华书记为2026级新任班主任逐一颁发聘书，正式明确育人岗位职责，压实班级管理工作责任，为新生培养工作筑牢队伍保障。

王军年副院长解读《汽车工程学院班主任工作实施细则》，围绕班主任岗位职责、学期重点任务、考核评价标准及配套保障机制等核心内容进行系统阐释，进一步明晰工作规范、细化工作要求，帮助新任班主任全面掌握岗位工作内容，明确工作方向与履职标准。

2025级班主任代表孙博华结合自身工作实际，分享班级管理、学风建设、新生适应引导、学生问题疏导等实操工作经验，为新任班主任快速上手、高效开展育人工作提供了务实参考。

2026级新生辅导员李娇针对本科生日常管理重难点问题进行专项说明，详细讲解新生管理工作注意事项，重点强调要常态化关注学生思想动态，及时回应学生需求，协同做好新生教育服务工作，助力学生平稳适应大学生活。

黄忠华书记作总结讲话。他强调，全体班主任要践行教育家精神，传承弘扬吉大汽车精神，坚守育人初心、深耕育人主业。同时对学生培养工作提出六点明确要求，希望班主任着力培育学生家国情怀，引导学生积极参与社会实践、锤炼团队协作能力、树立创新探索意识、保持身心健康状态，督促学生主动沟通交流、常态化与家人保持联系，全方位助力学生成长成才。

此次会议的召开，进一步明确了学院班主任工作的方向要求和任务重点，增强了新聘班主任的责任感与使命感。在学院党委的领导下，在全体班主任的共同努力下，汽车工程学院将持续优化育人环境，提升育人质量，为培养更多优秀汽车专业人才贡献力量。
