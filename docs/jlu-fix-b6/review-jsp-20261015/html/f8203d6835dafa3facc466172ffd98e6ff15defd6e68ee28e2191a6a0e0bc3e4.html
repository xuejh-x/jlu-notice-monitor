植物科学学院召开2025年秋季学期督导专项工作会

日期：2026-01-06 点击数： 来源:

为落实立德树人根本任务，切实保障课堂教学质量，植物科学学院于2026年1月4日组织召开2025年秋季学期教学督导专项工作会议。学院教学督导组组长席景会、原亚萍，以及督导组与教学委员会全体成员出席会议。会议由教学副院长吴涛主持。

吴涛首先汇报了2025年秋季学期教学督导工作的总体情况，强调督导工作始终秉持“以学生为中心”理念，聚焦“教、学、管”三个维度，通过线上线下听课、教学检查、座谈交流等多种形式，实现了全院课程督导全覆盖。随后，督导组专家与教学委员会成员结合具体听课案例逐一发言，对教学中存在的问题进行了精准反馈。

整体看来，当前课堂教学存在三大突出问题：一是部分教师授课过度依赖PPT，内容呈现文字堆砌、重点不突出，影响了知识传递效果；二是课堂设计缺乏巧思，部分课堂仍沿用“灌输式”教学，互动不足且形式单一，难以激发学生主动思考；三是数智工具应用不足，未能与教学内容实现深度融合。与此同时，部分课堂后排学生低头使用手机、注意力不集中等现象较为普遍，反映出课堂吸引力不强、学习目标引导不足以及课堂管理尚待优化等问题。

针对上述问题，与会人员积极提出改进建议。在教学方法方面，倡导教师优化PPT设计，增加可视化元素，强化板书与PPT的互补配合；丰富课堂互动形式，融入科研案例与行业前沿内容，推动科教融合；加强课堂管理，着力提升学生“抬头率”；通过“以老带新”机制加强课程团队建设，助力青年教师准确把握教学重难点。在学生培养方面，应推动课堂管理理念从“约束行为”向“服务成长”转变；将课堂表现纳入平时成绩考核，以评价机制激发学生学习动力；结合学生年级与专业特点灵活调整教学策略，积极推行小班教学，增强课程实用性与吸引力，并有机融入课程思政元素，提升学生的专业认同感。

吴涛在总结中强调，教学质量是学院发展的生命线，督导所反映的问题直指育人关键环节。下一学年，学院将持续开展“听课磨课”活动，加强青年教师培训与新任教师考核，强化实践教学督导，鼓励探索AI辅助教学等创新模式，推动课堂教学从“知识传授”向“能力培养”转型。

本次会议为学院教学工作进行了精准“画像”，为实现靶向“施策”提供了重要依据。学院将以此为契机，进一步完善教学质量监控体系，全面提升课堂教学实效，筑牢高素质人才培养的教学根基。
