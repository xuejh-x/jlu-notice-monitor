关于化学学院2025－2026学年研究生优秀奖学金、优秀研究生、优秀研究生干部拟推荐名单（第一批）公示及第二批申报的通知

日期：2026-10-14 点击数：

根据我校2025－2026学年研究生优秀奖学金、优秀研究生、优秀研究生干部评选工作的总体安排，依据《吉林大学化学学院研究生优秀奖学金评审工作实施细则（2026修订）》、《吉林大学化学学院优秀研究生评审工作实施细则（2024修订）》、《吉林大学化学学院优秀研究生干部评审工作实施细则（2024修订）》等文件，化学学院拟推荐名单（第一批）公示如下（见附件）。

公示时间：2026年10月14日至10月16日（共3个工作日）

公示期间，如有异议，请实名向学院研究生办公室反映。

联系人：赵晓杰

联系电话：0431-85168583

办公地点：唐敖庆楼A205办公室


目前剩余部分名额，未获奖同学可申报第二批次研究生优秀奖学金、优秀研究生、优秀研究生干部，申报人请于10月15日20：00前填写https://f.wps.cn/g/EriCK3vG/【WPS表单】「2026年化学学院研究生评奖评优第二批申报」。
