行政学院2024年本科生招生宣传动态（四）——张贤明院长赴五峰土家族自治县高中进行招生宣讲并参加授牌仪式

发布时间: 2024-04-16点击:

2024年4月13日，行政学院院长张贤明教授与行政学院张力伟副教授赴湖北省五峰土家族自治县高中（以下简称五峰高中）进行招生宣讲并参加吉林大学优秀生源基地授牌仪式。五峰土家族自治县副县长王进、五峰土家族自治县委组织部副部长李相林、五峰高中党总支书记刘绍华、校长陈鑫淼接待了张贤明院长一行并出席相关活动。

授牌仪式上，刘绍华书记向张贤明院长一行表达了诚挚的欢迎，并简要介绍了五峰高中的基本情况。张贤明院长代表吉林大学向五峰高中授予吉林大学优秀生源基地牌匾，陈鑫淼校长代表五峰高中领取牌匾并合影留念。随后，张力伟副教授向五峰高中高三学生作了题为“逐梦起航在吉大”的招生宣传演讲，介绍了吉林大学的基本简介、师资力量、教学资源、人才培养成果、生活设施等内容。与此同时，张力伟副教授向学生们生动地介绍了东北的风土人情，并表示热烈欢迎同学们积极报考吉林大学。

授牌仪式结束后，张贤明院长一行同王进副县长开展座谈，并参观了五峰高中校园以及观摩了五峰高中的学生活动。

此次授牌仪式充分体现了吉林大学对湖北省招生工作的重视，拓展了吉林大学的优秀生源地，进一步提升了吉林大学在湖北省的影响力。
