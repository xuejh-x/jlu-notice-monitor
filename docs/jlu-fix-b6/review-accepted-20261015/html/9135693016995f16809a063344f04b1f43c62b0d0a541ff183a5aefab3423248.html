新能源与环境学院关于聘任2026-2027学年本科毕业论文（设计）指导教师的通知
发布日期：2026-10-10 10:58:09 作者：   来源：    阅读： 次

根据《吉林大学本科毕业论文（设计）工作管理办法》（校教字〔2020〕117号），通过个人申报，基层推荐，于2026年10月9日经学院教学委员会会议审核通过，决定聘任董德明等94人为我院2026-2027学年本科毕业论文（设计）指导教师。具体名单如下：
