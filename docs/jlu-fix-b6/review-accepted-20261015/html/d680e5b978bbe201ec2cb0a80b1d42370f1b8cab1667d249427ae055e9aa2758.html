关于在动物科学学院评选2026年度 “禾丰董事长助学金”“禾苗奖学金”的通知

发布日期：2026-10-15 作者： 点击：

  各位同学：

  为激励动物科学学院本科生勤奋学习，全面发展，禾丰牧业股份有限公司在我院设立“禾丰董事长助学金”“禾苗奖学金”。为做好2026年度评选工作，现将相关事宜通知如下。

  一、评选范围

  动物科学学院二年级（含）以上全日制本科生

  二、奖励人数及金额

  1.禾丰董事长助学金：

  2024级本科生1人，2025级本科生1人，奖励金额：3000元/人。

  2.禾苗奖学金：

  2023级本科生1人，2024级本科生3人，2025级本科生3人，奖励金额：2000元/人。

  三、评选标准

 （一）基本条件

  热爱国家，拥护党的基本路线，遵守国家法律法规和校规校纪，在校期间无任何违规违纪行为。

 （二）具体条件

  1.二年级（含）以上全日制在读本科生，本科期间曾获得过“禾丰董事长助学金”“禾苗奖学金”的不得再次申请。

  2.刻苦学习，成绩优异。申报“禾丰董事长助学金”要求本学年综合平均学分绩点排名在本专业方向前50%，无挂科情况；申报“禾苗奖学金”要求本学年无挂科情况。

  3.同等条件下，“禾丰董事长助学金”优先考虑在校表现突出，具有见义勇为、助人为乐、奉献爱心、服务社会、自立自强的申请人；“禾苗奖学金”优先考虑积极参加学校活动和社会活动，具备较强的组织协调能力和团队合作精神，具有学生干部经历的同学。

  4.本年度内院级社会奖学金不可兼得。

  四、评审流程

  1.学生申请：符合申请条件的学生填写《动物科学学院“禾丰董事长助学金”“禾苗奖学金”申请表》，一式两份，并提交相关附件材料。

  2.材料评审：动物科学学院筛选并初审学生材料。

  3.推荐名单：本科生由辅导员/班主任推荐，经学生工作办公室审议，拟定奖学金获奖人员名单。

  4.结果公示：将评审结果在学院网站公示5日，评审结果公示无异议后，向捐赠方报备评选结果及相关材料。

  五、所需材料

  1.《动物科学学院评选2026年“禾丰董事长助学金”“禾苗奖学金”申请表》一式两份（注：按要求填写，必须有照片，经辅导员签字后盖学院公章）。

  2.个人获奖情况及其它证明材料复印件（注：获奖证书、已发表论文目录、专利证书等）。

  3.成绩单（注：加盖学校成绩管理部门公章）。

  六、材料提交时间及联系人

  申报学生需在2026年10月16日（星期五）下午4：30前将附件1（电子版）发送至邮箱：dkxgb202@163.com，附件2（纸质版）提交至学生工作办公室，逾期不予受理。
