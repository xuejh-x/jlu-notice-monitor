计算机科学与技术学院党委隆重举行庆祝中国共产党成立103周年暨“两优一先” 表彰大会

发布日期：2024-07-09 发布人： 点击量：

    为庆祝中国共产党成立103周年，充分展示学院党委基层党支部和党员在各项工作中取得的丰硕成果和精神风范，大力弘扬信念坚定、对党忠诚、勇于担当、无私奉献的崇高品格，7月1日，计算机科学与技术学院党委在王湘浩楼B108报告厅召开“两优一先”表彰大会，对优秀党员、优秀党务工作者和先进基层党支部进行表彰，学院全体领导班子成员、党委委员、纪委委员、党支部书记、支部委员、受表彰人员和师生党员代表130余人参加了本次表彰大会。会议由院长杨博同志主持。大会在雄壮的国歌声中拉开帷幕。

首先，党委副书记杜天宝同志带领与会全体党员面向鲜红党旗，重温入党誓词，用铿锵有力的誓言，表达对党的庄严承诺和为党为人民服务的坚定信念。随后，党委副书记高战国同志宣读了《中共吉林大学计算机科学与技术学院委员会关于表彰优秀共产党员、优秀党务工作者和先进基层党支部的决定》，与会领导为获奖支部和个人颁发了荣誉证书。

优秀党员代表刘宇舟、侯星宇，优秀党务工作者代表刘小华、先进基层党支部代表许志军分别上台发言，分享了他们和他们所在集体永葆初心使命、坚守责任担当，发扬党的优良作风和光荣传统，发挥基层党支部战斗堡垒作用和共产党员先锋模范作用的先进事迹和宝贵经验。

学院党委书记宫皓宇向受表彰的集体和个人表示衷心祝贺，并指出：近年来，学院党委坚持以党建为引领，团结依靠全院各党支部、全体党员和广大师生员工，埋头苦干，奋进拼搏，在学科建设、人才培养、科学研究等方面取得了骄人的成绩。成绩的取得是广大师生团结奋斗的结果，凝结着党员同志的心血和汗水。受到表彰的优秀共产党员、优秀党务工作者和先进基层党支部是近年来在加强党的建设、推动学院中心工作中涌现出来的先进集体和优秀个人，他们紧密围绕高校立德树人根本任务，踔厉奋发、务实奋进，努力发扬党的优良作风和光荣传统，在推进学院高质量发展进程中发挥了积极的作用。

宫皓宇强调：希望受到表彰的党组织和共产党员珍惜荣誉，再接再厉，继续发挥共产党员的先锋模范作用：一是坚定理想信念，不忘初心使命；二是加强党的建设，提高党组织的凝聚力和战斗力；三是发挥党建文化培育作用，持续将红色基因的传承深度融入立德树人全过程。历史昭示未来，沧桑成就正道，计算机科学与技术学院全体党员必将以最坚定、最忠诚、最实在的行动向党的生日献礼！

大会在庄严的《国际歌》中圆满结束。
