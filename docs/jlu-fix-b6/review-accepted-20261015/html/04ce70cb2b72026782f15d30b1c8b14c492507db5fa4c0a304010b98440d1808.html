致吉大计算机学科全体教职工的一封信

发布日期：2022-03-17 发布人： 点击量：

致吉大计算机学科全体教职工的一封信

尊敬的全体教职工：

当前，吉林省疫情防控形势到了前所未有的严峻时刻，学校疫情防控工作也进入了最关键阶段！学校已进入全封闭管理状态第五天，我们所面临的严峻形势、复杂工作程度对于我们都是巨大的挑战。计算机学院和软件学院分别有2630名和1668名同学生活在封闭的校园里，学校相关部门、学院领导和教职工、以及一大批优秀的学生志愿者正在不分昼夜、全力以赴地确保同学们的正常学习和生活，全国各地的校友也在以各种方式传递着对母校的款款深情。在这样一个全民抗疫的非常时期，更需要我们上下团结起来，共克时艰。两院和中心认真贯彻落实校党委书记姜治莹同志在3月7日全校疫情防控工作专题视频会精神，把抓好疫情防控工作作为落实党和国家战略部署的实际行动，作为体现学校治理水平、确保学校有序运转的关键环节，作为锤炼党性修养、彰显担当精神的重要举措。校长张希同志强调，要坚持以学生为本，强化协同育人，相关部门要高度重视学生诉求，解决学生关切，提供优质服务。辅导员、班主任、心理健康教师要加强协同，密切关注学生身心健康，注意保护个人隐私，让学生安心、家长放心。

在此，计算机学院、软件学院和公共计算机中心倡议：

请广大教师坚守居家课堂，善用信息技术，带着“为党育人，为国育才”的责任，认真上好每一堂课。既要上好专业课，同时也要在课堂上真正实践课程思政，传播正能量。在大学的殿堂里，老师不仅是学生的专业导师，更是人生导师，尤其在学生面对人生考验的时候更要给他们关怀和鼓励，引导学生们调整心态，静下心来，潜心学习，思考人生，立志成才。

请各位研究生导师、班主任老师积极发挥协同育人作用，通过本科生线上班会、研究生线上组会等各种方式，加强线上教学指导，加强学生心理健康关怀，主动问需，积极回应学生诉求，努力提供优质服务，广泛收集学生建议，畅通信息渠道，及时高效的把学生的诉求反馈给我们，共同协调解决。

请全体行政管理人员知其责、尽其力，全力做好疫情防控任务的落实工作，科学做好物资储备，不断提升应急能力，根据工作分工及时做好各种信息统计和报送工作，要把学校防疫的相关要求通知落实到每一个人，充分做到关口前移、抓小抓早，把疫情防控的主动权掌握在自己手中，将师生的安全感和满意度作为检验疫情防控工作成效的重要标准。

请全体教职工严格按照学校和所在社区的相关要求，从我做起，有效落实责任。严格遵守疫情期间学校管理规定，严格执行每日健康打卡，严格落实健康监测，配合做好全员核酸检测；勤洗手、常通风，避免人员集中，降低疫情传播风险。

老师们、同志们，我们现在大多居家办公授课，而学生近期只能在寝室学习和生活。让我们用真诚和爱陪伴学生们走过这段艰辛的心路历程，在共克时艰中写下计算机人的情怀、能力和担当！疫情来势汹汹，就如这两日料峭的风、纷飞的雪；但我们相信在学校党委的坚强领导下，各位老师的积极配合下，我们以紧急“战时”状态统一共识、同心协力、共克时艰，保护自己、守护学院和中心，让我们的吉林大学成为最安全的校园。

风雪过后，春城已是晴空万里。我们终将战胜疫情，迎来春暖花开。愿所求皆所愿，山河无恙，岁月安康。
