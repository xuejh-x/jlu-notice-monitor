吉林大学考古学院举办2025年青年教师科研成果汇报交流会
作者：苏海波 时间：2026-01-04 点击数：

2025年12月30日，为总结过去、以新的面貌迎接作为“十五五”规划开局之年的2026年，考古学院在新启用的吉林大学学科交叉创新中心“考古与文明探源分中心”，举办了2025年青年教师科研成果汇报交流会。考古学院院长段天璟，副院长方启、任瑞波、彭善国，边疆考古研究中心副主任刘伟，各系主任及全体青年教师出席会议。会议由彭善国副院长主持。

会议伊始，彭善国副院长介绍了学院青年教师队伍现状。他指出，学院40岁以下教师已占半数，35岁以下教师亦达三分之一。考古学院已进入以青年教师为主体的新发展阶段，青年教师正日益成为教学科研工作的中坚力量。举办此次交流会，旨在为青年教师的成长搭建展示与交流的平台。

会上，16位35岁以下青年教师依次进行汇报，围绕过去一年的科研成果、在研项目、学术交流活动以及面临的挑战与困难，进行了全面而深入的分享。他们立足学术前沿，积极融入学院平台，在论文发表与项目研究等方面均取得实质进展，并通过参与国内外学术交流活动，有力传递了吉大考古的学术声音。汇报交流现场气氛热烈，充分展现了青年教师广阔的学术视野、丰硕的研究成果与积极的探索精神。学院领导就青年教师关心的实验设备、成果认定、资源支持等问题进行了积极回应。彭善国副院长对本次汇报给予充分肯定，指出此类活动对进一步增进学院教师的学术交流和青年教师的成长发展具有重要意义，学院未来将持续完善并办好年度交流活动。

段天璟院长在总结发言中指出，本次会议既是一次科研交流，也是一次全院范围的学术分享，充分展现了学院青年力量的蓬勃朝气与学术初心。围绕青年教师的成长需求，他提出三点期望：一是鼓励青年教师坚守学术初心，积极动笔，勇于表达，坚持思考，坚持做有品位的学术研究；二是学院将持续推动与国内外考古文博机构的合作，从青年教师发展需求出发，开拓多样化的合作交流模式；三是希望青年教师积极进取，勇于担当，共筑精神家园，既要有成为学科“明星”的自觉，也要恪守教书育人的本职。他勉励全体青年教师携手努力，共同擦亮吉大考古的“金字招牌”，在新的一年里取得更大突破。

本次青年教师科研成果汇报交流会，为青年教师提供了展示交流的平台，有力促进了学科交叉与交流合作，也为学院进一步精准支持青年人才成长、迎接2026年“十五五”开局之年奠定了扎实基础。
