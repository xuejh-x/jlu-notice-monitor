白求恩第三临床医学院关于申请2025-2026学年优秀学生干部和单项奖学金的通知
发布时间：2026.09.29
点击数：1348次
字体：小大

各班级：

根据《吉林大学白求恩第三临床医学院本科生学年奖学金评选办法》和《吉林大学白求恩第三临床医学院优秀本科学生干部评选办法》的有关要求，学院定于近期开展2025-2026学年优秀学生干部和单项奖学金评选工作，现将相关事宜通知如下。

一、奖励名额

本学年，学校下达到我院的校优秀学生干部16名、院优秀学生干部27名和单项奖学金54名，具体分配如下：

各年级专业如有符合条件的候选人人数少于分配指标的情况，学院收回相应指标，并统筹调整到其他年级专业中。

二、优秀学生干部申请条件及资格

1.优秀学生干部评选对象为我院在籍本科学生。

2.基本条件：

（1）热爱祖国，热爱人民，拥护中国共产党领导；

（2）遵守宪法和法律，遵守学校规章制度, 具有良好的道德品质和行为习惯；

（3）勤奋学习，成绩优良，完成参评学年内教学计划规定的学习任务且必修课程和限定选修课程等均一次性通过，综合素质测评总成绩排名应在专业前50%（含50%）；

（4）在校、院学生组织或者班级内担任学生干部且连续工作满1年（或1届），热心服务师生，发挥模范带头作用；

（5）积极参加体育锻炼，《学生体质健康标准》测评成绩合格。

3.参评学年内受到纪律处分且处分未解除的，取消参评资格。

三、单项奖学金申请条件及资格

1.单项奖学金评选对象为我院在籍本科学生。

2.基本条件：

（1）热爱祖国，热爱人民，拥护中国共产党领导；

（2）遵守宪法和法律，遵守学校规章制度，具有良好的道德品质和行为习惯；

（3）勤奋学习，成绩优良，完成参评学年内教学计划规定的学习任务且必修课程和限定选修课程等均一次性通过；

（4）积极参加体育锻炼，《学生体质健康标准》测评成绩合格。

3.参评学年内受到纪律处分且处分未解除的，取消学年奖学金参评资格。

4.单项奖学金采取申报制，申报学生应符合以下相应条件。

（1）学术科技奖

积极参加学术活动或科学研究，公开发表与专业相关的学术文章或取得发明专利，或在相应学科竞赛中取得突出成绩。

（2）文体活动奖

在学校（学院）组织或代表学校（学院）参加的各类文艺、体育等活动和比赛中，表现突出或取得突出成绩。

（3）社会实践奖

积极参加校内外社会实践、志愿服务等活动，表现突出或取得显著成效、良好反响。

（4）社会工作奖

在服务社会或校内外集体活动中，积极承担相关工作，组织协调能力突出，得到师生广泛认可。

（5）道德风尚奖

具有较高思想政治素质和道德品质，模范遵守法律法规和社会公德，自觉投身于校园文明建设，能够在学生中起到榜样示范作用。

（6）国防贡献奖

积极响应国家号召，在校期间应征入伍，服役期间表现良好。国防贡献奖应在退役复学当年申请。

四、学院初评

学院成立本科生奖助工作领导小组，负责本学院优秀学生干部和单项奖学金的申报和初评工作。

1.学院本科生奖助工作领导小组根据学校下发的优秀学生干部和单项奖学金按年级和专业进行分配，并在学院网站公布。

2.发布通知后，符合条件的候选人，于10月5日中午12点前，同时发送邮件和在智慧学工申请，报名方有效。智慧学工系统将于10月1日开启申请模块。

候选人须填写《白求恩第三临床医学院2025-2026学年优秀学生干部报名申请表》及提供相关佐证材料、填写《白求恩第三临床医学院2025-2026学年单项奖学金报名申请表》及提供相关佐证材料，发送至下列邮箱，收到自动回复邮件视为发送成功。注意申请理由和佐证材料必须为2025-2026学年之间。邮件名请按照“学号-年级-姓名-优秀学生干部申报材料”“学号-年级-姓名-单项奖学金申报材料”进行命名。同时申请优干和单项奖学金的，请分别发送邮件至邮箱。

申请优秀学生干部，需提供相应佐证材料，例如担任学生干部证明、参加活动新闻报道和活动现场照片等材料。请将相关佐证材料插入word中并作为邮件附件发送。

申请单项奖学金，需提供相应佐证材料，例如已发表文章电子版、获奖证书扫描件、担任学生干部证明、参加活动新闻报道和活动现场照片、志愿时长和社会实践证明等材料。其中，申请学术科技奖学金并且申请依据为发表学术论文的，需注明文章名称、期刊名称、期刊类别（中文核心/中文一般/SCI等）期刊分区、发表时间、第几作者、影响因子等关键信息（论文必须见刊，SCI论文需同时标注JCR分区和中科院分区）；申请学术科技奖学金并且申请依据为参加学科竞赛的，需注明竞赛名称、项目名称、获奖等级、本人排序等关键信息；申请学术科技奖学金并且申请依据为申报大创等科研项目的，需注明科研项目名称、研究项目名称、获批等级、本人排序等关键信息。申请文体活动、社会实践、社会工作等单项奖学金的，需详细注明自己承担或参与的活动，以及取得的成绩。申请道德风尚和国防贡献奖的，请慎重申请。请将相关佐证材料插入word中并作为邮件附件发送。

发送邮箱如下：

2022级、2025级：zrlyyyxb02@126.com

2023级、2024级：zrlyyyxb03@126.com

3.各年级学生奖助工作小组进行资格审核和材料推荐，以综合素质测评总成绩排名为主要依据，结合申请人的日常工作表现，选定比例不超过年级和专业优秀学生干部或单项奖学金评选指标的200%的申请人进入材料评审环节。

4.学院学生奖助工作领导小组组织专业教师、辅导员和各年级奖学金工作小组成员代表作为评审小组，并采取材料评审的形式，根据评选结果按照年级和专业提出拟获校优秀学生干部、院优秀学生干部和单项奖学金名单。

5.拟获优秀学生干部和单项奖学金名单经学院学生奖助工作领导小组审议后，在学院网站、公示栏等固定场所公示，无异议报党委学生工作部。

四、相关说明

1.同一学年内，校、院优秀学生干部统一进行评选。校、院优秀学生干部可兼报，但不能兼得。同时申报校优秀学生干部和院优秀学生干部的申请人，如未获评校优秀学生干部荣誉，可继续参与院优秀学生干部评选，根据优秀学生干部评选结果，可获评相应等级荣誉。在智慧学工中，优干只能申请一个等级，学院后期根据评审结果在系统中调整等级。

2.申请单项奖学金的，各类别奖项原则上可兼报，但不可兼得。兼报学生获评单项奖学金的，各年级学生奖助工作小组依照申请人意愿，确定最终拟获评奖项。在智慧学工中，单项可以申请多个奖项。如未在系统申请相应单项，不能获评相应单项奖学金，请注意系统申请奖项和表格申请奖项保持一致。

3.其他评审相关内容，请参考《吉林大学白求恩第三临床医学院优秀本科学生干部评选办法》《吉林大学白求恩第三临床医学院本科生学年奖学金评选办法》。
