吉林大学动物科学学院2027年推荐免试攻读研究生招生录取工作实施细则

发布日期：2026-09-16 作者： 点击：

为了确保我院2027年推荐免试攻读研究生（以下简称“推免生”）的复试录取工作规范有序，根据教育部关于推免生相关文件及《吉林大学2027年推荐免试攻读研究生招生录取工作办法》等文件精神，结合我院推免生招生录取工作实际，制定本办法。

一、招生录取工作原则

1.坚持科学方法，选拔优秀人才。采用综合性、多元化的考察方式和方法，遵循高层次专业人才的选拔规律，坚持学术标准，择优录取，宁缺毋滥，确保生源质量。

2.坚持全面考察，注重客观评价。在对考生德智体等方面综合考察的基础上，突出对专业素质、动手能力及创新精神等方面的考核。

3.坚持公正公开，维护考生权益。政策规范透明，程序公正公开，结果主动公示，监督机制健全，以人为本，切实维护考生合法权益。

二、组织管理

（一）动物科学学院研究生招生工作领导小组全面负责学院研究生招生录取工作。负责制定招生录取工作实施细则，指导招生录取小组开展相应工作，处理招生过程中考生提出的质疑和申诉。研究生与科研办公室负责学院推免生招生录取工作的组织实施和协调管理。

（二）成立复试命题组。按照难度适宜、数量充足、开放性试题为主的原则，分专业按照招生简章颁布的复试科目，拟定复试试题。

（三）成立复试考核组。分别确定复试考核的具体内容、评分标准和操作程序，制定对考生的考察评价标准。

（四）成立资格审查小组。严格按照《吉林大学2027年接收优秀应届本科毕业生免试攻读研究生招生简章及专业目录》及工作要求，初步形成进入复试考生名单。

（五）成立监督检查小组。对复试录取的工作程序、保密规定、信息公开公示、考生复试纪律和工作人员的廉洁廉政等监督检查。

（六）成立材料审核组。成立材料审核专家组，按照材料审核办法及工作要求，对推免生的申请材料进行客观独立打分，形成审核成绩（满分100分），并依据审核成绩确定复试名单。材料审核成绩不计入综合考核成绩，但不合格者（低于60分）不予录取。

三、报考条件

1.推免硕士生报考条件

（1）拥护中国共产党的领导，遵纪守法，品德良好。

（2）具有所在学校推免生资格的优秀应届本科毕业生。

（3）学术研究兴趣浓厚，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

（4）不存在考试作弊和学术不端行为。

（5）身体和心理状况符合国家和招生单位规定的体检要求。

2.推免直博生报考条件

（1）拥护中国共产党领导，遵纪守法，品德良好。

（2）具有所在学校推免生资格的优秀应届本科毕业生。

（3）学习成绩优秀，对学术研究有浓厚兴趣，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

（4）不存在考试作弊和学术不端行为。

（5）身体和心理状况符合国家和招生单位规定的体检要求。

（6）有至少两名所报考学科专业领域内的教授(或相当专业技术职称的专家)的书面推荐意见。

3.按照《吉林大学2027年接收优秀应届本科毕业生免试攻读研究生招生简章及专业目录》中规定的招生计划进行录取，招生专业、招生人数等详见目录（附件1）。

四、申请程序

考生应在9月21日前，登录吉林大学研究生招生网站报名（网址：https://yzbbm.jlu.edu.cn/），并将所有需提交材料的电子版按顺序制作成1份PDF文件以“报考专业方向+姓名+资格审查材料”命名，发送到指定邮箱，材料清单如下：

1.居民身份证、学生证。

2.《吉林大学2027年接收推荐免试研究生申请表》。

3.加盖所在学校教务部门公章的本科期间成绩单。

4.在校期间发表的论文、获得专利的证书、研究成果证明、获奖证书、外语水平考试证书等材料。

5.《吉林大学动物科学学院2027年推免生复试考生诚信考试承诺书》，填写完整、本人签字。

6.其他证明材料，包括科研活动、获奖荣誉等佐证材料。

以上材料如个别同学在截止前不能准备齐全，请先尽可能提供已有材料，暂时无法提供的材料请在邮件中说明原因，补齐后尽早发到邮箱。

资格审查有下列情况之一者取消复试资格和录取资格：

资格审查不合格者；材料造假或不符合要求者；毕业证、居民身份证及复试表上的照片与本人不相符者；在读非应届毕业的大学生；与《吉林大学2027年推荐免试攻读研究生招生录取工作办法》所要求的条件不相符者。

五、复试的主要方式和内容

1.复试方式

采用网络远程复试方式，使用腾讯会议软件为线上复试软件。采取随机选定考生次序、随机确定面试专家组组成人员、随机抽取面试试题的“三随机”方式。

2.复试要求

每生面试时间一般不少于20分钟，考生明确表示已作答完毕的可提前结束考核；复试全程录音录像。所有纸介质材料均须进行电子扫描保存，其中纸介质材料至少保留1年，电子材料至少保存5年。

3.复试内容

主要考查考生专业基础知识、逻辑思维能力、语言表达能力、分析解决问题能力、创新潜质，以及思想道德品质、外语听说能力等综合素质。

专业素质和能力（40分）：

考核大学阶段学习情况及成绩；对本学科、专业（领域）理论知识和应用技能掌握程度，利用所学理论发现、分析和解决问题的能力，对本学科发展动态的了解以及在本专业（领域）发展的潜力；创新精神和创新能力，科学精神、学术道德和专业伦理。

以硕士招生专业目录中各专业（方向）的复试科目为重点，由考生在复试现场随机抽取1套试题，当场回答；现场专家可以根据试题回答情况即时提问，由考生作答。

综合素质和能力（30分）：

考核思想政治素质和品德，内容包含推免生的政治态度、思想表现、道德品质、遵纪守法、诚实守信等方面；本学科、专业（领域）以外的学习、科研、社会实践（学生工作、社团活动、志愿者服务等）或实际工作表现等方面的情况；心理健康情况等。

考核现场由考核组组长组织考核专家与考生交流问答。

外语听说能力测试（30分）：

考察考生的英语听、说、读能力。

以现场评委与考生交流考察的形式进行。

（4）思想政治考核

六、复试成绩及录取

1.复试成绩满分100分，60 分以上（含60分）为合格，复试成绩保留小数点后两位，不合格者不予录取。

2.拟录取推免生按照复试成绩由高到低择优录取。

3.思想政治素质和品德考核结果作为录取的首要依据，考核不通过者不予录取。

4.学院将组织拟录取推免生在规定时间内通过“全国推荐优秀应届本科毕业生免试攻读研究生信息公开暨管理服务系统”完成网上“同意待录取”确认。

七、信息公开

1.学院网站提前向社会公布推免生招生录取工作实施细则及进入复试考生名单。

2.学院网站公示各专业拟录取推免生（含直博生）名单，名单包括推免生姓名、复试成绩、拟录取专业等信息，公示期为3天。同时公布咨询电话，解答考生的咨询和质疑。

八、违规处理

1.严肃处理推免招生工作中违规违纪行为。对在违反遴选推荐、招生管理规定和考场纪律，影响招生公平、公正的招生单位、相关工作人员、推免生，一律按有关法律法规规章严肃处理。

2.推免相关工作人员有直系亲属或利益相关者报名参加本单位推免招生的应主动报备并全程回避。对未按要求回避的推免相关工作人员，学校将依规依纪严肃处理。对未按回避制度规定报备且影响推免招生工作过程和结果公平公正的学生，取消其推免录取资格。

3.对于在推免招生过程中弄虚作假，存在考试作弊、提供虚假材料、以及剽窃、抄袭、侵占他人学术成果等学术不端行为的，或有其他严重影响推免过程和结果公平公正行为的学生，一经查实，由责任单位取消其推免生资格、录取资格和学籍，并报所在地省级教育招生考试机构按规定将相关事实记入《国家教育考试考生诚信档案》、通报其所在学校、记入学生人事档案，作为其今后升学和就业的重要参考依据。

4.对于在推免招生工作中未严格履行工作职责的，违反推免招生政策规定的相关工作人员和指导教师，学校将其列入研究生招生工作“黑名单”，严禁其参与今后研究生招生工作，对研究生导师核减其研究生招生名额、暂停或取消其研究生导师资格。

九、工作日程

9月16日前：在学院网站公布推免生招生录取实施细则。

10月15日前：结合考生报名等情况，开展推免生复试，公示拟录取推免生名单。组织复试合格推免生通过教育部推免生信息公开暨管理服务系统完成“待录取确认”。

十、其他

1.参加我院2026年校园学术开放日或线下招宣，并在活动中学术能力考核合格的同学，具备推荐免试硕士研究生资格者，不需要登录吉林大学研究生招生网站报名，不需要提供资格审查材料。

2.所有报名考生需加入吉大动科2027年推免生QQ群（群号：418955374）获取相关信息。
