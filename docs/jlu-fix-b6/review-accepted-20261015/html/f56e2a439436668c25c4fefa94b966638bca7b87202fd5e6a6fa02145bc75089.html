东北亚研究中心、东北亚研究院成功举办中韩国际学术会议

日期：2019-11-25 点击数：

2019年11月22日，东北亚研究中心、东北亚研究院、朝鲜韩国研究所与韩国庆熙大学国际地域研究院共同举办国际学术研讨会，主题为“朝鲜半岛局势变化与中韩合作”。庆熙大学国际地域研究院院长金俊烨教授、技术经营大学院院长申尚协教授一行6人和来自吉林大学东北亚研究院国际政治研究所、世界经济研究所的部分教师参加了会议。东北亚研究院院长于潇教授和国际地域研究院院长金俊烨教授在开幕式上致辞。

会议就朝鲜半岛局势、东北亚国家间关系、中国与朝鲜半岛的经济合作等三个议题深入展开了交流，中韩两国参会学者就当前朝鲜半岛问题的进展、中美贸易摩擦、日韩贸易摩擦、美国对日韩的贸易政策、中韩经济合作、中韩朝俄铁路合作等问题进行了充分而深入的讨论。

会议期间，东北亚研究院院长于潇教授、东北亚研究中心副主任张慧智教授与金俊烨院长和申尚协院长进行了会谈，双方对彼此间的交流合作表示满意，并就进一步推动深入合作，如教师短期互访、互派交换学生等达成了初步共识。
