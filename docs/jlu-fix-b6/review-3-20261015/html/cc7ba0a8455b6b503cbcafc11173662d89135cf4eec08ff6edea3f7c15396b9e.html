关于开展长春市卓越工程师培养对象遴选工作的通知

发布时间：2026-09-29 点击：

校内相关培养单位：

根据长春市人社局2026年度《关于实施“长春市卓越工程师培养工程”的通知》及《关于推进“长春市卓越工程师培养”的通知》文件要求，我校国家卓越工程师学院成功入选2026年度“长春市卓越工程师培养工程”培养载体名单，现就我校开展长春市卓越工程师培养对象遴选工作通知如下。

一、培养领域及名额

专业领域：新材料、新能源

培养名额：5人

二、申报对象及条件

1.我校全职在编在岗工程系列人员，年龄不超过50周岁。

2.从事新材料相关工程技术工作，需符合长春“3转、4强、7新”现代化产业体系中氢能和新型储能、新型半导体、前沿新材料、航空航天及应用等产业发展方向。在本领域、本专业从事工程技术工作3年以上。

3.专业背景：需为化学、材料与化工、高分子化学与物理、电子信息、能源动力等相关专业。具备深厚的专业知识，强于技术创新创造，善于解决复杂工程问题，在本领域、本行业具有一定影响力。

4.遵守职业道德，无违法违纪和失信行为记录。

5.优先遴选与长春本地重点企业有合作基础、可依托企业真实工程项目开展研究的人选。

6.已被确定为长春市卓越工程师的人才，不可纳入培养对象范围。

三、申报材料

1.《长春市卓越工程师培养对象申报表》，“单位意见”由所在学院负责人签字并加盖学院公章；

2.申报人身份证等有效身份证件；

3.在职证明；

4.职称证明，以及申报人在本领域、本专业从事工程技术3年以上，体现专业技术能力的佐证材料（结合申报人实际提供，如：称号、项目、专利、标准、创造效益及荣誉奖项等）；

5.公安部门出具的“无犯罪记录证明”。

6.《“长春市卓越工程师培养工程”培养对象名单》

材料1-5按序扫描合并成一个PDF，文件命名：学院—姓名—长春卓工培养对象申报；材料6以Excel版发送。

四、聘用管理

培养期不少于1年，对培养期满符合条件的人才（相关培养方案另行通知），聘为“长春市卓越工程师”纳入人才库统一管理。

五、申报要求

请符合要求的人员积极申报，并于2026年9月30日11:00前将电子版材料发送至jluees@jlu.edu.cn。压缩包命名：学院代码+姓名+卓工培养工程申报。纸质版材料请于2026年10月15日14:00前送至长白山实验室A栋6楼623室。

联系电话：85168206
