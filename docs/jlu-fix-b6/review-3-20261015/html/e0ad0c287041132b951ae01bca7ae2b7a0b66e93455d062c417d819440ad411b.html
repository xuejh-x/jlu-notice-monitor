105500药学

①101思想政治理论

参考书目

349药学综合：

1.《药物化学》（第9版），徐云根主编，人民卫生出版社，2023年7月出版。2.《药理学》（第9版），陈忠、杜俊蓉主编，人民卫生出版社，2022年7月出版。3.《生物化学与分子生物学》（第10版），高国全、汤其群主编，人民卫生出版社，2024年5月出版。

药学综合（349）的考查内容同步进行调整，详细分数构成及考查要点参见考试大纲（附件）。

说明：原学术学位硕士一级学科生物医学工程（代码107200）停止招生，上述学科导师调整至药学（代码100700）再生医学方向招生。
