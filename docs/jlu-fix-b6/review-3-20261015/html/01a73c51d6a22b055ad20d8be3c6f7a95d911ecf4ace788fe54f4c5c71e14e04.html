学院快讯

以建党精神凝心铸魂，用长征精神聚力前行——吉林大学文学院党委举办“七一”专题党课

发布日期：2026-07-03 作者： 点击：

为庆祝中国共产党成立105周年，纪念红军长征胜利90周年，继承和弘扬伟大建党精神和伟大长征精神，7月1日下午，吉林大学文学院党委在东荣会议中心二楼多功能厅举办“七一”专题党课。本次党课由正军职退休干部邵忠海同志担任主讲，吉林省军区长春第三离职干部休养所主要领导和相关负责同志出席会议，学院领导班子成员、党委委员、纪委委员、各党支部书记及师生党员代表参加党课。会议由学院党委副书记兼副院长葛宗梅主持。

 

 

 

 

邵忠海老首长紧扣建党105周年与长征胜利90周年两大历史节点，围绕三条“道路”展开阐释。一是回望来时路，读懂百年党史，读懂伟大长征，带领大家重温党的伟大历程，回顾了长征的历史背景、艰辛历程与伟大意义，阐释伟大建党精神和长征精神在中国共产党人精神谱系中的核心地位及其对今天的启示，号召广大师生党员牢记红色政权来之不易，从革命历史中汲取奋进力量。二是立足当下发展路，结合我国对外开放、一带一路等发展成果，客观分析了我国现阶段面临的发展机遇与挑战，把当下考验比作为新时代的“雪山草地”，讲述新时代共产党人的使命和责任。三是走好新的长征路，邵忠海老首长聚焦个人成长之路，对照“四好党员”标准，勉励广大师生党员，要时刻以“心中有党、心中有民、心中有责、心中有戒”为行为准绳，坚持终身学习，立足本职岗位，甘于吃苦奉献，勇于实干担当，在新时代新征程中践行初心使命，为民族复兴伟业贡献智慧和力量。

 

学院党员代表为邵忠海老首长献上鲜花，表达感谢和敬意。

 

此次专题党课是在中国共产党成立105周年、红军长征胜利90周年、文学院与吉林省军区长春第三离职干部休养所共建共育39周年之际开展的一次重要的党员教育培训。希望学院全体党员能够以此次党课为契机，铭记建党来时路，以伟大建党精神凝心铸魂，用伟大长征精神聚力前行，不断提升党性修养，坚定理想信念，赓续红色血脉，明确使命任务，为学院和学校发展贡献力量，为中华民族伟大复兴勇担重任。
