吉林大学东北亚学院2027年推荐免试攻读研究生招生录取（第二批）工作通知

日期：2026-09-28 点击数：

吉林大学东北亚学院热烈欢迎全国各高校的优秀应届本科毕业生免试来我院攻读硕士学位。现开展东北亚学院2027年推荐免试攻读研究生招生录取（第二批）工作。

一、招生计划及专业

我院2027年推免生招生计划详见《吉林大学2027年接收优秀应届本科毕业生免试攻读研究生招生简章及专业目录》，专业目录内各专业的招生计划仅供考生参考。

（一）硕士推免生招生专业

人口学、区域国别学（1.东北亚区域国别经济方向；2.东北亚区域国别政治方向）

（二）直博生招生专业及导师

详见《吉林大学2027年接收优秀应届本科毕业生免试攻读研究生招生简章及专业目录》。直博生报考前需要和导师取得联系。

二、复试安排

（一）线上报名

9月28日13:00—10月7日16:00，请考生线上报名，推免报名网址：https://yzb.jlu.edu.cn/。

（二）提交材料进行审核

9月28日13:00—10月7日16:00，请考生提交以下申请材料电子版或彩色清晰扫描件至指定邮箱进行报名。

申报专业名称

接收邮箱

区域国别学－东北亚区域国别经济

报名材料打包压缩，邮件的主题、压缩包的命名格式：“报考专业名称－姓名－推免报名（或直博生报名）”，报名截止日期：10月7日16时，逾期不予补报。注：纸质版原件不需邮寄，妥善保存好，待正式录取后收取复查。

  1. 《吉林大学东北亚学院2027年接收推荐免试研究生申请表》（打印并手写签字盖章后扫描）。文件命名方式：“1. 报考专业名称－姓名－申请表”。

  2. 第二代居民身份证复印件一份（正反面扫描在同一页面上），文件命名方式：“2. 报考专业名称－姓名－身份证”。

  3. 每学期均已注册的学生证复印件，包括信息页和注册页，文件命名方式：“3. 报考专业名称－姓名－学生证”。

  4. 加盖所在学校教务部门公章的本科期间成绩单，文件命名方式：“4. 报考专业名称－姓名－成绩单”。

  5. 在校期间发表的论文、获得专利的证书、研究成果证明、获奖证书、外语水平考试证书等材料复印件（原件远程连线时审核）。文件命名方式：“5. 报考专业名称－姓名－佐证材料”。

  6. 申请直博生须有至少两名所报考学科专业领域内的教授（或相当专业技术职称的专家）的书面推荐意见。文件命名方式：“6. 报考专业名称－姓名－专家推荐书”。

    材料审核有下列情况之一者取消复试资格和录取资格：

    1.政治审查不合格者；

    2.材料不齐全或不符合要求者；

    3.第二代居民身份证、《吉林大学2027年接收推荐免试研究生申请表》及复试表上的照片与本人不相符者。

    （三）线上测试及综合面试时间另行通知。

    四、其他事项参照《吉林大学东北亚学院2027年推荐免试攻读研究生招生录取工作实施细则》

    网址：http://nasa.jlu.edu.cn/info/1056/6561.htm
