生物与农业工程学院、仿生科学与工程学院就业工作概况


吉林大学生物与农业工程学院、仿生科学与工程学院深入学习贯彻习近平总书记关于高校毕业生就业工作的重要指示批示精神，全面落实党中央、国务院决策部署，全力促进毕业生高质量充分就业，构建实施具有吉林大学特色的“两主两双一核心”高质量就业育人新体系新模式。

一、往届毕业生就业情况

学院往届研究生毕业生就业情况整体质量较高，去向广泛，层次多元。毕业生流向涵盖高等教育、科研机构、国有企业、民营企业及机关事业单位等多个领域。从学历层次看，大部分博士毕业生进入吉林大学、苏州大学、吉林农业大学、中国科学院长春光学精密机械与物理研究所等高校或研究所从事教学科研，部分选择博士后研究，亦有部分进入制造业企业就业。硕士毕业生大部分以直接就业为主，进入“潍柴雷沃”“中国重型汽车集团”“中车长春轨道客车”“中国第一汽车”“航天精工”等国有企业，担任工程技术、研发岗位；在“华为”“比亚迪”等民营企业主要从事技术研发、项目管理工作；另有部分进入“吉林省财政厅”“辽宁省教育厅”等机关事业单位。

学院往届本科毕业生的就业情况呈现出升学深造为主导、就业形式多元化的特点。超过一半的毕业生选择了国内外高校继续攻读硕士学位，其中以推免进入吉林大学、哈尔滨工业大学、西安交通大学、浙江大学、北京航空航天大学等国内高校为主；同时，有部分学生赴香港科技大学、伦敦大学学院、新加坡国立大学、东京工业大学等海外名校深造。在直接就业方面，毕业生去向广泛：众多学生进入以“比亚迪”“中国一拖”“中联重科”“徐工集团”“潍柴动力”为代表的制造业企业（民企、国企为主）从事技术与工程岗位；部分学生进入公务员系统和事业单位。
