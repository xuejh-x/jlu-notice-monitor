关于设立深入贯彻中央八项规定精神学习教育网络意见箱的公告

发布日期：2025-06-10 发布人： 点击量：

关于设立深入贯彻中央八项规定精神学习教育网络意见箱的公告


按照《关于深入贯彻中央八项规定精神学习教育的实施方案》（院党发〔2025〕3号），为做好开门教育，设立深入贯彻中央八项规定精神学习教育网络意见箱，面向广大师生征求意见和建议。

一、征求内容

该网络意见箱主要用于收集广大师生员工对学院党委及领导班子成员、各党支部和党员干部在贯彻落实中央八项规定精神方面的意见和建议，包括但不限于形式主义、官僚主义问题，违反廉洁自律规定的行为，以及改进工作作风、提升工作效能等方面的意见和建议。

二、征求渠道

电子邮箱：changyue@jlu.edu.cn

三、意见处理

对收到的意见和建议，我们将认真梳理、分析、研究，作为加强和改进工作作风的重要依据，切实推动中央八项规定精神在学校落地见效。同时，我们将严格保护反馈人的个人信息和隐私。

感谢您的关心和支持！
