计算机科学与技术学院党委组织召开疫情防控工作专题视频会

发布日期：2022-03-16 发布人： 点击量：


3月16日上午，计算机科学与技术学院党委组织召开疫情防控工作专题视频会，计算机科学与技术学院、软件学院和公共计算机教学与研究中心领导班子成员参加了此次视频会。

视频会上，党委书记宫皓宇传达了3月13日学校疫情防控工作专题视频会会议精神，强调全院教职工应共同努力，做好疫情防控工作。要时刻关注学校、社区、省市和国家的疫情防控的相关通知，工作群内会第一时间传达的疫情防控的相关信息，例如《关于进一步加强校园疫情防控工作的通知》等，希望全体教职工认真落实各项防控要求和工作要求，积极配合社区核酸检测，在做好个人防护的同时完成各项本职工作。

宫皓宇向坚决服从大局的全院师生表示衷心的感谢，向心系师生安危、无惧风险挑战的防控人员表示崇高的敬意。目前学校全封闭管理期间，高战国、张达鑫、杜天宝3位党委副书记带领何江海、侯树范、于纯浩、张译心、王星阳、王天放等6名辅导员坚守在为学生教育和服务保障的校内一线岗位上。

视频会中，计算机科学与技术学院院长杨博传达了学校纪委的14项监督检查清单，与班子成员逐项讨论交流形成工作共识。杨博强调，学院全体领导班子成员要时刻做好准备，及时按照学校要求研究解决疫情防控工作中遇到的问题，安排好线上办公、教学等工作，抓好学生和教工的疫情防控工作，不能把责任全压在一线的学工同志身上，既要分担他们的压力，也要更加关心关爱他们，全院上下共同努力打好疫情攻坚战。

会议要求：一是进一步加强疫情期间宣传工作，加强新闻宣传和信息报送，加强意识形态管理和舆情推动化解。二是加强疫情期间排查流调工作，严格落实学校每日健康申报情况，全面统计掌握全体师生情况，做到不漏一人，为在校封闭的学生提供周到细致服务。三是学院开展线上教学，落实“责任到人、协同配合、维护秩序、保证质量”精神，保障疫情防控期间本科教学秩序和教学质量。四是加强总体掌握学生思想动态，做好上传下达工作，将上级和学校的有关政策文件精神传达给每一名学生，创新工作形式有针对性地进行思想引领和政治教育。五是对本单位负责的学生教学场所以及无人值守的实验室等重点部位的水、电、气、暖等设施和物品开展巡查检查。
