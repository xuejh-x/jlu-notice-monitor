关于申报2020年度吉林大学国家发展与安全（生物安全）专项研究课题的通知

发布时间：2020-03-27  点击：次


校内各有关单位：

为进一步提高我校国家发展与安全相关问题方向的研究能力，发挥我校综合性大学学科齐全的优势，吸引更多科研力量向国家发展与国家安全相关研究领域汇聚，形成一批具有理论性和方法性、政策性和现实性、战略性和前瞻性的高质量、高水平研究成果，为国家发展与安全决策和政策实施提供支持参考，现面向全校开展2020年度吉林大学国家发展与安全（生物安全）专项研究课题申报工作。相关事宜通知如下：

一、指导思想

高举中国特色社会主义伟大旗帜，以马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九大和十九届二中、三中、四中全会精神，认真贯彻落实习近平总书记关于防控新冠肺炎疫情的一系列重要讲话精神和在中央全面深化改革委员会第十二次会议上关于全面提高生物安全治理能力、把生物安全纳入国家安全体系的重要指示精神，紧紧围绕国家生物安全领域决策和政策的重大理论与现实问题组织开展多学科交叉研究，充分发挥高校思想库、智囊团作用，为推动国家生物安全治理体系和治理能力现代化提供理论支撑、贡献智力支持。

二、项目类别

本专项研究课题分为重点课题和一般课题两类，重点课题的研究期限一般为1年，一般课题的研究期限一般为3个月。

三、立项数量

重点课题拟立5项，每项资助经费3万元。

一般课题拟立10项，每项资助经费1.5万元。

四、选题范围

结合防控新冠肺炎疫情的新形势和新趋势，聚焦国家生物安全决策和政策的重大理论与现实问题，以基础理论、法律法规、制度体系、体制机制、国际合作、战略前瞻等问题为重点研究领域，申请人依据或结合《2020年度吉林大学国家发展与安全（生物安全）专项研究课题选题方向》具体拟定题目申报。

五、申报条件和要求

1、申报人应为我校在编在岗教师，应坚持正确的政治方向、价值取向和研究导向，恪守学术规范，严格学风要求，能够独立开展科学研究工作。

2、申报选题要跨两个及两个以上一级学科，应开展多学科交叉融合研究。

3、申报人同年度只能主持本专项研究一个课题，且不能作为课题组成员参与其他项目的申报。

六、项目评审与管理

由吉林大学国家发展与安全研究院组织专家委员会，对申报项目材料进行评审，并最终确定立项名单。立项评审包括通讯评审和会议评审两个环节。根据新冠肺炎疫情形势变化，科学安排立项评审工作。

经社会科学处同意，本项目作为校级课题立项，并遵照吉林大学哲学社会科学基本科研业务费项目管理。申报人应按照《吉林大学基本科研业务费管理办法（修订）》的要求，根据实际需要科学合理编制项目经费预算。

七、成果形式与结项要求

1、成果形式：公开发表的学术论文或政策性研究报告。

2、结项成果应符合《吉林大学哲学社会科学学术刊物等级目录》《吉林大学哲学社会科学报告类成果实施细则》的要求，重点课题在结项时应有不少于1篇社科处认定的C类及以上成果或2篇D类成果，一般项目在结项时应提交查重率不高于10%、字数不少于3万字的综合研究报告。

3、所有成果应标注“吉林大学国家发展与安全（生物安全）专项研究课题（课题名称，编号：XX）”，未标注的成果不予承认。

4、严禁剽窃、抄袭、作假等现象发生。对存在学术不端行为的课题负责人及其团队，将纳入本研究计划的“学术失信名单”，5年内不得申报本专项任何课题，并将相关情况通报所在单位。

八、研究成果用途

课题研究成果将以内参、信息或工作建议等形式报送中央有关部门和吉林省委省政府，为中央和地方决策提供重要参考，或根据需要纳入《吉林大学国家发展与安全研究报告简报》《吉林大学国家发展与安全研究报告汇编》《吉林大学国家发展与安全研究系列丛书》等研究类成果的内部或公开出版物。

九、申报办法和材料报送要求

1、申报人填写《立项申请书》《活页》电子版。

2、请各单位科研秘书于2020年4月15日（星期三）下班前，将本单位申报材料和《申报汇总表》电子版报送吉林大学国家发展与安全研究院的指定电子邮箱。要求每位申报人一个文件夹且以申报人姓名（如“XXX”）命名，文件夹内的文件应按照“XXX申报书”“XXX活页”的方式命名，PDF格式和WORD格式各1份。个人申报和逾期申报，不予受理。
