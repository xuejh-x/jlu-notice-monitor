行政学院2026年度“宝钢优秀学生奖学金”候选人名单公示

发布时间: 2026-09-22点击:

根据学校《关于在本科生中评选2026年度“宝钢优秀学生奖学金”的通知》有关要求，经学生申请、学生工作办公室审核、学院奖助工作小组实名票决，拟推荐2023级本科生裴嘉琳为我院2026年度“宝钢优秀学生奖学金”候选人，现予以公示。如有异议，请于公示期间向学院反映。


公示时间：2026年9月22日至9月24日（3个工作日）


联 系 人：曹烨、张雨琦

办公地点：东荣大厦1203室

联系电话：0431-85166162
