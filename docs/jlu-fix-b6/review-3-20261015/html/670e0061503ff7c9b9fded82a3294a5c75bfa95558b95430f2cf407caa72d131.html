    关于评选吉林大学机械与航空航天工程学院2026年度优秀学生和集体的通知
    发布时间：2026-10-14        作者：        编辑：张健       审核：       浏览：次

    为全面贯彻党的教育方针，落实立德树人根本任务，鼓励和促进学生在学业上积极进取，奋发图强，德智体美劳全面发展，树立我院优秀典范，营造创先争优、勤奋向上的氛围，机械与航空航天工程学院拟开展2026年度优秀学生和集体评选及表彰工作。现将评选工作相关事宜通知如下：

    一、评选类别及名额

    （一）个人奖项

    “领航者”十佳大学生10人

    “砺刃”大学生自强之星10人

    “聚力”优秀学生干部10人

    “启智”新锐之星6人

    “拓航”科创菁英6人

    “风华”文体菁英6人

    “薪航”奉献先锋8人

    （二）集体奖项

    “卓越”领航班集体8个

    “凝心”优秀学习小组8个

    “润心”文明寝室8个

    “知行”社会实践优秀团队2个

    二、评选条件

    具体评选条件见机械与航空航天工程学院2026年度优秀学生和集体评选细则（附件1）

    三、评选流程

    1.个人申请。请有意向申请奖项的个人和集体于10月16日下午16:30前将对应的电子版申请表发送至1018671584@qq.com，纸质版材料交至机械馆510办公室。

    2.资格审查。学院学生工作办公室对学生的申报信息进行逐一审核，确认是否符合申报条件、申报信息是否符合填写要求、申报材料是否真实、完整。

    3.组织评选。学院奖助学金评审小组对符合评选资格的申报个人及集体进行评选。获奖名单将在全院公示3个工作日。

    机械与航空航天工程学院

    2026年10月14日
