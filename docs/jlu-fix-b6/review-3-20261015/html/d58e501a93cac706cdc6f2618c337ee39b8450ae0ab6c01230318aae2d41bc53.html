行政学院2024年本科生招生宣传动态（三）——王娜老师受邀参加湖北省巴东一中建校80周年庆典大会

发布时间: 2023-12-18点击:

12月15日-12月16日，行政学院王娜老师受邀代表吉林大学参加湖北省巴东一中建校80周年庆典大会。我校同时也发送贺信，热烈庆祝巴东一中建校80周年，并表达了进一步加强两校的交流与合作的意愿。

湖北省巴东县第一高级中学创办于1943年，高考成绩连年位居恩施州同类学校第一。巴东一中是全国文明单位、全国民族团结进步模范集体、湖北省示范高中，学校以其深厚的底蕴、和谐的环境、浓郁的氛围、一流的质量，成为修养心智、潜心求学的理想之地。自建校以来，数千学子考入“985”、“211”工程大学，位居全省县市高中前列，教育教学质量享誉全省，被誉为“荆楚名校”。

近5年来，巴东一中向我校稳定输送优质生源。2022年6月27日，公共卫生学院代表我校授予巴东一中“吉林大学优秀生源基地”称号。
