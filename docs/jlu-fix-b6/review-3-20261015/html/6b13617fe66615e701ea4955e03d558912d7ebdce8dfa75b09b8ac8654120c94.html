东北亚国别与区域研究高端讲坛——“概念与分期：世界历史教学中的方法论问题”

日期：2021-06-17 点击数：

2021年6月14日，“东北亚国别与区域研究高端讲坛”之“概念与分期：世界历史教学中的方法论问题”在吉林大学顺利举行。本次讲座由吉林大学东北亚研究中心、吉林大学东北亚学院、东北亚研究院、吉大—莫大历史学研究中心联合举办，在线上、线下同步开展。东北亚学院邀请到了莫斯科大学历史系主任列夫·谢尔盖耶维奇·别洛乌索夫(Лев Сергеевич Белоусов)教授，带领中国师生们进行了一次精秒绝伦的学术之旅。讲座由吉林大学东北亚学院历史与文化研究所所长、“匡亚明学者”卓越教授张广翔主持。讲座伊始，张广翔教授代表吉林大学东北亚学院院长吴昊教授向别洛乌索夫院士表示了热烈的欢迎和崇高的谢意。

别洛乌索夫教授是俄罗斯国内研究意大利史的权威，同时作为俄罗斯教育科学院院士，长期关注历史教科书中的历史观念和历史分期问题。在讲座中，别洛乌索夫教授从整个人类历史发展的脉络出发，对教科书中通行的“近代史、现代史、当代史”的分期提出了质疑，并提出了关于世界历史分期的新观点。首先，他认为“近代早期”开始于17世纪初，到法国大革命为止。而接下来的“近代”则一直延续到一战结束之后，因为俄国的十月革命给资本主义世界体系打开了缺口。其次，他根据“近代早期”的概念创造出“近代晚期”的概念，认为20世纪的大部分时间并不是我们通常认为的“现代”，而是属于“近代”的自然延伸。苏联的社会主义制度试图截断资本主义的发展，最终以失败告终，但是促进了世界资本主义制度的转型。再次，他认为真正的“当代史”并非起源于二战结束之后，而是出现在20世纪七八十年代至90年代初，在此时间内，苏联社会主义制度的崩溃与资本主义内部的变化几乎同时发生，而在此之后，整个世界进入了全新的历史阶段——当代史。在这一阶段，信息社会、全球化、通信革命、社交网络、数字经济、国际恐怖主义等等因素，导致当代社会的面貌与以往有了重大差别。最后，他提出传统的世界历史分期已经过时，应该放弃“现代史”的概念，从本质上把握世界历史进程的特征。当然别洛乌索夫教授也指出，自己的观点是具有争议的，他希望学术界能就此问题展开进一步讨论。讲座结束后，别洛乌索夫院士热情地为青年师生们答疑解惑，并对提问的水平给予了高度评价。

活动尾声之时，张广翔教授表示，别洛乌索夫院士的讲座及其系列研究价值极高，为吉林大学俄国史团队廓清研究思路、发掘新的研究视角助益甚多。张广翔教授转达了吴昊院长的诚挚邀请，希望别洛乌索夫教授及其团队能在疫情之后出访吉林大学，再续两校情谊，共谱历史华章。
