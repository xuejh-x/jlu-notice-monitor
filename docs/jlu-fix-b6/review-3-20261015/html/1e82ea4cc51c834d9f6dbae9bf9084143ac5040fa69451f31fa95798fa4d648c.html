关于2025-2026学年本科生学年奖学金、优秀学生和优秀学生干部拟获奖名单的公示
发布日期：2026-10-09 点击次数：

根据《吉林大学本科生学年奖学金评选办法》（校发〔2019〕382号）、《吉林大学优秀本科学生评选办法》（校发〔2019〕383号）和《吉林大学优秀本科学生干部评选办法》（校发〔2019〕384号）的有关要求。现将我院2025-2026学年本科生学年奖学金、优秀学生和优秀学生干部拟获奖名单进行公示。

见附件：《2025-2026学年本科生学年奖学金、单项奖学金、优秀学生干部、优秀学生拟获奖名单》

公示时间：5个工作日（2026年10月09日—10月14日）

如有异议，请在公示期内具实名以书面或电子邮件形式向学院反映。

联 系 人：王老师

联系电话：0431-85619463

电子邮箱：563621707@qq.com

办公地点：基础医学院309室
