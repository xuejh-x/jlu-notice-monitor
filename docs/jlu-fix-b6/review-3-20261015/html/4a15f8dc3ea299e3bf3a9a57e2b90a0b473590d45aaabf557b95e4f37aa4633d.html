招生宣传 | 行政学院2024年本科生招生宣传动态（七）——党委副书记史慕华、政治学系薛洁教授受邀参加湖北省鄂南高级中学建校40周年庆典大会

发布时间: 2024-10-13点击:


10月3日-4日，党委副书记史慕华、政治学系薛洁教授受邀代表吉林大学参加湖北省鄂南高级中学建校40周年庆典大会。吉林大学同步发送贺信，向鄂南高级中学全体领导、老师和同学们致以节日的问候和崇高的敬意，并衷心希望双方进一步加强交流、携手合作，共同为祖国的教育事业做出贡献。

湖北省鄂南高级中学成立于1984年，是咸宁市政府举办的全市唯一的一所省级重点高中和省级示范中学。建校以来，为国家和社会培养了大批高素质人才，累计共万余名学生考入各类重点大学，一大批优秀毕业生已成为各行各业的领军人才。近5年来，鄂南高级中学向我校稳定输送优质生源， 2024年鄂南高级中学有5名优秀毕业生考入吉林大学。2023年5月16日，行政学院代表学校授予鄂南高中“吉林大学优秀生源基地”称号。
