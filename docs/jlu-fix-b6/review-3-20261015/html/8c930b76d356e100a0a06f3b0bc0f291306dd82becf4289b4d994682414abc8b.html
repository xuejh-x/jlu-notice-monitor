汽车工程学院2026-2027学年团学组织学生干部名单公示

日期：2026-10-12 13:24:36 作者： 访问量：

根据我院下发的《汽车工程学院团学组织2026-2027学年学生干部换届通知》要求，在学生自愿报名的基础上，经过资格审核，按照综合素质评分，结合学生干部一年来的工作表现和现场述职情况，确定新一届汽车工程学院团学组织主要学生干部，现对名单进行公示。

公示时间为2026年10月12日至2026年10月15日，如对上述人员任职情况有异议，请在10月15日前与汽车工程学院学生工作办公室联系。


共青团吉林大学汽车工程学院委员会

2026年10月12日
