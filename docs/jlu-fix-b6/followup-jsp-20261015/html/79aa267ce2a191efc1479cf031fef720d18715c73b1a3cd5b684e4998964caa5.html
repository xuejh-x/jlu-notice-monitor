关于开展超期研究生学籍清理工作的通知
发布日期：2026-09-14 12:43:50 作者：   来源：    阅读： 次

相关研究生同学：

为进一步规范研究生学籍管理工作，提升管理水平，根据《吉林大学研究生管理规定》（校发〔2024〕132号）等文件要求，本着老人老办法（2017级及以前）、新人新办法（2018级及以后）的工作原则，拟对相关年级超期且未申请结业的研究生（以下简称超期研究生）进行学籍清理，现做如下工作安排：

一、清理范围

2020级及之前年级博士研究生；2022级及之前年级三年制全日制硕士研究生；2023级及之前年级两年制全日制硕士研究生；2021级及之前年级非全日制硕士研究生。

二、工作程序

1.向超期研究生送达《退学通知书》。学院以邮寄、微信、邮件、电话等方式向超期研究生送达《退学通知书》，研究生本人回复并同意办理退学手续。

2.对失联研究生进行公告。与培养单位或导师失去联系、无法送达《退学通知书》的超期研究生，由学院将拟清退学生信息在本单位网站上进行公告（仅公示学号、专业等非敏感信息），公告期为30天，并通过管理系统、邮箱等发送提示信息。

3.公告结束后，学院向学校提交《退学通知书送达情况》、《学籍清理网上公告情况》等相关材料，对超期研究生启动学籍清理程序。

三、工作要求

研究生学籍管理工作是研究生教育管理的重要内容，是提高研究生培养质量的重要保证。相关导师和研究生同学要及时了解《吉林大学研究生结业实施细则》等有关文件要求，保障好研究生权益，严格按照通知要求开展工作。
