    关于商学与管理学院2027年接收推荐免试攻读研究生预报名的通知

    时间：2026-09-14      作者：      点击：

    为了确保我院2027年接收推荐免试攻读研究生（以下简称“推免生”）的复试录取工作规范有序，现开展我院2027年推免生预报名工作。

    一、申请条件

    （一）硕士生

    1.拥护中国共产党领导，遵纪守法，品德良好。

    2.具有所在学校推免生资格的优秀应届本科毕业生。

    3.学术研究兴趣浓厚，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

    4.不存在考试作弊和学术不端行为。

    5.身体和心理状况符合国家和招生单位规定的体检要求。

    （二）直博生

    1.拥护中国共产党领导，遵纪守法，品德良好。

    2.具有所在学校推免生资格的优秀应届本科毕业生。

    3.学习成绩优秀，对学术研究有浓厚兴趣，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

    4.不存在考试作弊和学术不端行为。

    5.身体和心理健康状况符合国家和招生单位规定。

    6.有至少两名所报考学科专业领域内的教授(或相当专业技术职称的专家)的书面推荐意见。

    二、招生计划

    （一）硕士生

    招生计划详见《吉林大学2027年接收推荐免试硕士研究生招生专业目录》（https://yzb.jlu.edu.cn/info/1047/3637.htm）

    （二）直博生

    具体招生专业、招生导师情况参见《吉林大学2027年接收推荐免试直博生招生专业目录》（https://yzb.jlu.edu.cn/info/1047/3637.htm）

    注：直博生报考前需和导师联系，征得导师同意后，再报名。

    三、申请程序（含直博生）

    1.从即日起至2026年9月16日晚上20点前，申请人登录吉林大学研招网推免生预报名系统（网址为https://yzb.jlu.edu.cn/）进行报名，仅招收第一志愿申请者报名，逾期不予补报。

    2.提交材料

    （1）《吉林大学2027年接收推荐免试研究生申请表》扫描件（见附件1），须签字盖章。

    （2）加盖所在学校教务部门公章的本科期间成绩单扫描件。

    （3）长期有效第二代居民身份证扫描件（正反面扫描在同一页面上）、学生证扫描件（有学校盖章的个人信息页面和注册章页面）、外语水平考试证书、在校期间发表的论文、获得专利的证书、研究成果证明、获奖证书等材料的扫描件。

    （4）申请直博生须提交两名报考学科专业领域内的教授（或相当专业技术职称的专家）的书面推荐意见扫描件（见附件2）。

    申请人须将以上材料合并成一个PDF文件，文件以“报考专业名称+姓名+推免生/直博生”命名，发送至各专业指定邮箱：

    学院将在审核材料后，确定复试名单，并在学院官网公示。复试采用线上面试方式，具体实施细则另行通知，请申请者关注学院网站通知。
