关于2022年度“李四光优秀学生奖”推荐人选的公示
发布日期：2022-05-18 21:46:05 作者：   来源：    阅读： 次


根据吉林大学党委学生工作部、党委研究生工作部关于推选2022年度“李四光优秀学生奖”候选人的通知要求，我院开展了评选推荐工作。经个人申报、学院专家初审，现将推荐人选公示如下：

李四光优秀博士研究生奖推荐人选：于涵、柴娟芬

李四光优秀硕士研究生奖推荐人选：丁小凡、张思宇

李四光优秀大学生奖（本科生）推荐人选：华聪

此推荐人选结果公示期为2022年5月18日-5月24日。若有异议，请于5月24日17：00前与学院学生工作办公室、研究生办公室联系。

研究生联系人：李老师，联系电话：15543108251；

本科生联系人：安老师，联系电话：18543145314。
