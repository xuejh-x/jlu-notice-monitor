“第六届中国治理创新论坛：数智时代的政府创新与高效能治理”征稿启事

发布时间: 2026-09-30点击:

高效能治理是习近平总书记提出的重大原创性命题，要求以高效能治理促进高质量发展和高水平安全良性互动。这为数智时代的政府创新的理论和实践指明了方向，也为从事政府治理研究的理论工作者提出了新的命题和任务。

为贯彻习近平新时代中国特色社会主义思想，加快构建中国哲学社会科学自主知识体系，吉林大学中国地方政府创新研究中心、吉林大学行政学院和《协商治理研究》编辑部诚邀相关领域的学者和实务部门的专家相聚长春，围绕数智时代政府创新与高效能治理的理论和实践前沿分享学术观点、进行学术交流，共同推进国家治理现代化的理论创新与实践发展。

“中国治理创新论坛”是吉林省人文社科重点研究基地吉林大学中国地方政府创新研究中心的原创学术活动品牌，在2016、2019、2021、2022、2025年先后围绕地方政府创新发展、公共管理学科建设、基层治理体系和治理能力现代化、应急管理现代化建设和公共管理基础理论建构举办学术会议、学术讲座等一系列活动。本次会议内容主要包括领域内知名学者的主旨演讲，实务部门专家的经验分享，设立分论坛进行深度研讨，并与知名学术期刊进行合作。

一、主办单位

吉林大学中国地方政府创新研究中心

吉林大学行政学院

《协商治理研究》编辑部

二、会议主题

1.政府创新推动高效能治理的理论基础

2.数智时代政府效能提升路径研究

3.高效能治理模式创新的典型案例研究

4.政府创新与高效能治理的实证研究

5.基于数智技术的地方政府创新能力建设研究

6.高效能治理促进高质量发展研究

7.高效能治理和高水平安全良性互动研究

8.数智赋能政府创新的路径和机制研究

三、期刊支持

会议拟邀请专业学术期刊编辑参加论坛研讨，积极开展学术对话，推动学者与期刊工作者的双向交流，助力高水平学术成果的产出。

四、征稿要求

研讨会以文会友、择优录用。请从事相关研究的学者围绕会议主题，提交1篇尚未公开发表的学术论文参会，字数以12000-15000字为宜。中文论文格式请参照《协商治理研究》相关要求，英文论文格式请采用APA格式。提交论文全文的截止时间为10月17日。征稿邮箱：jluinnovations@163.com。

五、会务须知

参会学者10月24日报到、25日召开会议、26日离会。会务组将通过电子邮件邀请被录取的论文作者参会。主办方将负责入选的论文作者（限1人）会议期间的食宿安排，来往长春的交通费用敬请自理。
