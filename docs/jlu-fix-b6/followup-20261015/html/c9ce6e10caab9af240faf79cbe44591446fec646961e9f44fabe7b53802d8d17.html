吉林大学白求恩口腔医学院关于调整硕士研究生招生考试初试参考书目与题型的公告

日期：2026-04-07 点击数： 来源:

为进一步提升硕士研究生招生选拔质量，优化人才培养结构，适应口腔医学学科发展与专业人才培养需求，经教学委员会、院长办公会、党委会研究决定，对我院硕士研究生入学考试初试参考书目予以调整，调整自2027年硕士研究生招生考试初试（2026年12月）起执行。现公告如下：

一、调整内容

（一）保留原参考书目

高岩主编：《口腔组织病理学》（第八版），人民卫生出版社

边专主编：《口腔生物学》（第五版），人民卫生出版社

何三纲主编：《口腔解剖生理学》（第八版），人民卫生出版社

（二）新增参考书目

张志愿主编：《口腔颌面外科学》（第八版），人民卫生出版社

赵铱民主编：《口腔修复学》（第八版），人民卫生出版社

周学东主编：《牙体牙髓病学》（第五版），人民卫生出版社

闫福华主编：《牙周病学》（第六版），人民卫生出版社

葛立宏主编：《儿童口腔医学》（第五版），人民卫生出版社

（三）题型：

选择题（A型题）、简答题、问答题

二、其他说明

本次调整自2027年硕士研究生招生考试初试（2026年12月）起执行，请广大考生明确时间节点，避免歧义。

2027年硕士研究生招生考试其他相关要求，以吉林大学研究生院及白求恩口腔医学院后续发布的招生简章、专业目录和相关通知为准。

请广大考生密切关注官方信息，合理安排复习备考。

特此公告。

吉林大学白求恩口腔医学院

2026年4月7日
