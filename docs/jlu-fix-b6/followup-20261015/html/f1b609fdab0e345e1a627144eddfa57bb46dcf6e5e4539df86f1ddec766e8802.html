体育学院关于2027年推荐优秀应届本科毕业生免试攻读研究生综合成绩排名的公示
发布日期：2026-09-04

 

根据《吉林大学推荐优秀应届本科毕业生免试攻读研究生工作管理办法》（校发〔2022〕59号）《关于开展2027年推荐优秀应届本科毕业生免试攻读研究生学业成绩核对和综合排名工作的通知》和《体育学院2027年推荐优秀应届本科毕业生免试攻读研究生工作实施细则》要求，现对体育学院2023级社会体育指导与管理专业和2023级运动训练专业的推免综合成绩排名予以公示，具体情况见附件。

公示期为2026年9月4日至2026年9月10日，公示期间如有异议，请具实名向体育学院教务办公室反映。

 

联系人：刘佳宁

联系地址：吉林大学前卫南校区前卫体育馆219办公室

联系电话：0431-85167838
