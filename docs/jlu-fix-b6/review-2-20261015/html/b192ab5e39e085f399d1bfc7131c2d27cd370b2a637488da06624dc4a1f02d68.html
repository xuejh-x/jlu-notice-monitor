关于资料室2025年暑假值班时间的通知

日期：2025-07-09 点击数： 来源:


各位师生：

根据学校及我院2025年暑假总体安排，暑假期间资料室值班时间安排如下：

1.值班日期：7月17日，7月18日，8月11日，8月12日

值班时间：上午8：30-11：30，下午13：30-16：30

2.暑假期间，需要收取既存资料、借还图书和期刊的师生，请于值班时间前来办理。对于暑假期间收到的中国邮政机要信件、挂号信、取款通知单等资料，工作人员会单独通知到相关师生，请相关师生于每周三上午8：30-11：30到匡亚明楼收发室（匡亚明楼242）领取。

3.办公电话：0431－85166090

祝各位老师、同学假期愉快！
