强农兴农，逐梦启航——官方兽医系列报告 从兽医研究生到海关兽医官的成长路径

信息来源： 发布日期：2024-04-27

强农兴农，逐梦启航。为进一步拓宽我院学生的职业生涯规划视野，帮助同学们对海关兽医官的职业需求、工作内容和发展前景有更多的了解，动物医学学院于2024年4月26日上午9：00在吉林大学和平校区科学讲堂300举办了以“强农兴农，逐梦启航”为主题的职业生涯规划讲座。本次会议由秦明副书记主持，特别邀请长春海关技术中心动物检疫实验室主任、海关总署国家禽与经济动物疫病检测重点实验室主任、我校2005级兽医学博士宋战昀研究员作分享。研究生辅导员王慧丽老师出席报告，200余名动物医学学院研究生参加报告。

宋战昀研究员介绍海关系统架构

首先，宋战昀研究员为我们详细阐述了海关系统的组织架构，不仅解析了公务员编制和事业单位编制两大体系的内部运作机制，而且对它们的具体职责、晋升路径以及未来前景进行了深入剖析。其次，宋战昀研究员以其丰富的专业知识和实践经验，向我们生动地阐释了海关兽医官在进出境动物和动物产品检疫检验方面的重要职责，展现了其高超的业务水平和卓越的专业素养。最后，宋战昀研究员针对同学们关于职业发展的诸多疑问进行了详尽解答，充分展示了他对行业知识的广泛掌握，也体现出他对母校学子职业发展的深切关怀和对学院学科建设的深沉期待。

宋战昀研究员分享职业发展规划

宋战昀研究员为学生答疑解惑

此次讲座干货满满，不仅让同学们深入了解了从兽医研究生到海关兽医官的职业成长路径，更拓展了同学们的视野，为他们成为海关兽医官或其他官方兽医职务提供了全面的准备指导。讲座不仅强调了职业生涯规划的重要性，鼓励同学们根据个人兴趣和专业优势明确职业方向，还着重强调了强农兴农的责任感和使命感。通过此次讲座，希望同学们能够清晰地认识自己的职业发展道路，积极投身于兽医相关领域，以推动兽医学科和农业的持续健康发展为己任，为实现强农兴农的目标贡献自己的力量。
