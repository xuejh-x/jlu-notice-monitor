历史文化学院本科学生党支部专题学习习近平总书记致吉林大学建校80周年贺信精神

发布时间：2026-10-15浏览次数：

10月13日上午10时，历史文化学院本科学生党支部在东荣大厦A202会议室专题学习习近平总书记致吉林大学建校80周年重要贺信精神。会议由支部书记王可佳主持，全体学生党员参加。

会议首先开展专题学习。全体党员集中观看《新闻联播》相关报道，认真收看习近平总书记致吉林大学建校80周年重要贺信有关新闻，随后集体研读贺信原文，结合学校发展历程、历史文化学科特色，认真记录学习要点，进一步深刻认识贺信的重大意义，真切感受总书记对吉林大学的殷切关怀和深情嘱托。

支部书记王可佳围绕贺信的重大意义、精神实质、实践要求作领学解读，系统阐释贺信的核心要义和丰富内涵，并结合学生党员实际情况，引导党员深刻感悟总书记对吉林大学的殷切期望和深情嘱托，进一步坚定理想信念、明确奋斗方向，把贺信精神转化为刻苦学习、勇担使命的强大动力。

随后，学生党员结合学习科研、服务同学、成长成才等实际逐一交流发言。大家立足自身经历，畅谈学习体会，分享感悟收获，有的从实习经历出发谈知行合一，有的从学术研究出发谈创新报国，有的从学生工作出发谈服务奉献，发言内容务实深入，现场气氛热烈。全体党员一致表示，要将贺信精神内化于心、外化于行，在学习和实践中锤炼本领、担当使命。

此次会议既是一次深刻的思想淬炼，也是一次严肃的组织生活。与会党员纷纷表示，将以此次学习为契机，持续深化贺信精神学习，把学习成果转化为实际行动，为支部建设和学院发展贡献力量。
