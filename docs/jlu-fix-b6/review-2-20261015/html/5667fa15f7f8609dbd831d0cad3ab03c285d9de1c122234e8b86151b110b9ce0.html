关于2026年度自然资源科学技术奖推荐成果的公示（三）

发布时间：2026-09-14来源：浏览次数：次

根据《自然资源科学技术奖章程（暂行）》的有关规定和《关于开展2026年自然资源科学技术奖推荐工作的通知》（自然奖字〔2026〕1号）要求，对王明等参与申报的2026年度自然资源科学技术奖推荐成果进行公示，公示内容如下：

成果名称：青藏高原古老陆块物质组成与聚散过程

报奖奖种和等级：科技进步奖 特等奖或一等奖

主要完成人：胡培远、翟庆国、董昕、徐旺春、李才、刘一鸣、唐跃、王明、张泽明、戚学祥、杨宁、李金勇、巫凌放

主要完成单位：中国地质科学院地质研究所、中国地质大学（武汉）、吉林大学

公示期：9月14日至9月18日

对公示成果的公示内容持有异议的，应当在公示期内以书面形式向学院提出，并提供必要的证明材料。为便于核实查证，确保客观公正处理异议，提出异议的单位或者个人应当表明真实身份，并提供有效联系方式。凡匿名、冒名或超出公示期限的异议不予受理。
