吉林大学法学院第二届长白民法学博士生论坛征文公告
发布者：科研     发布日期：2026年01月31日 11:06     点击数：

为深入贯彻落实党的二十大精神，推进中国民法学自主知识体系建构，吉林大学法学院拟于2026年6月7日（暂定）举办“第二届长白民法学博士生论坛”。本次论坛在吉林长春举行，由吉林大学法学院主办。特面向全国民法学博士生、在站博士后开展主题征文活动，诚挚邀请各位惠赐稿件、踊跃参与研讨。现将征文活动有关事宜公告如下：

一、征文主题

中国民法学自主知识体系建构

二、征文对象

全国范围内从事民法学研究的博士生、在站博士后

三、征文要求

作者可以在征文主题范围内自拟题目，立足于中国视角进行研究，每人限投稿一篇。会议主办方将组织专家进行匿名评审，评选获奖论文并邀请优秀论文作者参加本届研讨会。征文的具体要求如下：

（一）坚持以习近平新时代中国特色社会主义思想为指导，贯彻习近平法治思想，以中国问题为导向，紧扣研讨主题，突出理论思维。

（二）征文截止时间：2026年4月30日，期前请发至minfa4@163.com。

（三）稿件须尚未公开发表，独立作者。

（四）征文的格式要求：

1. 为便于匿名评审，请将邮件主题统一命名为“作者姓名-单位-稿件名称”。请将论文第一页设置为作者信息页，内容包括论文题目、作者姓名、作者单位、导师姓名、联系电话、电子邮箱。正文部分请勿透漏作者个人信息。

2. 全文在30000字以内，中文摘要200-300字，5个关键词，正文首页列目次。

3. 征文主标题三号黑体，居中；一级标题小四号黑体，居中；二级标题五号宋体，不居中；正文五号宋体，固定行距20磅；摘要和关键词五号楷体。

4. 注释和引用文献采用脚注形式，参照《当代法学》的注释体例。

四、评审安排

吉林大学法学院第二届长白民法学博士生论坛将组织相关专家对征文稿件进行匿名评审，获奖论文作者将有机会受邀参加本次论坛。获奖论文将择优推荐至《当代法学》。

受邀参会作者的食宿费用由主办方承担。

五、联系人及联系方式
