关于开展哲学社会学院2026年度学生外语资格考试支持计划（第二批）的通知

日期：2026-09-22 点击数： 来源:

 

我院将于2026年度继续开展“学生外语资格考试支持计划”，对外语资格考试中取得优秀成绩的学生予以资助。

一、资助项目

1. 雅思（IELTS）

2. 托福（TOEFL iBT）

3. 德福（TestDaF）

4. 日本语能力测试（JLPT）

5. 韩语等级考试（TOPIK）

6. 俄罗斯联邦对外俄语等级考试（ГТРКИ）

7. 其他小语种参照同等级国际认证考试

二、资助对象

哲学社会学院全日制在籍本科生、硕士生和博士生。

三、资助要求

1. 学生取得外语资格考试成绩单后，方可提出申请。未拿到正式成绩单，只有临时成绩单或者网上成绩单者提出的申请，不予受理；

2. 每名学生在本科、硕士或博士阶段只能各申请一次资助；

3. 2026年1月1日之前取得的外语资格考试成绩不执行此“支持计划”。

五、资助申请

1. 申请方式：

（1）申请人于指定日期内提交《2026年度哲学社会学院“学生外语资格考试资助”申请表》（附件1）和外语成绩单复印件，携带学生证、外语成绩单原件以备查验；

（2）同时填写《2026年度哲学社会学院“学生外语资格考试资助”一览表》（附件2），发送到邮箱zhangxinyao@jlu.edu.cn（注明：“2026年外语考试资助申请+姓名”）。

2. 申请材料受理日期：2026年9月28日

3. 办公地点：哲学社会学院党委办公室（东荣大厦A916）

4. 联系人：张心耀    联系电话：0431-85168727
