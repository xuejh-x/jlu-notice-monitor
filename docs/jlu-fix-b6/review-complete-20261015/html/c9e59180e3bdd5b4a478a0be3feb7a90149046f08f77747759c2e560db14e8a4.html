外国语言文化学院2026年本科生集中考核转专业工作实施细则

发布时间：2025-12-30 浏览次数：次


为满足学生的专业兴趣，促进人才的个性化发展，依据《吉林大学本科学生转专业工作管理办法》（校发〔2024〕201号）的有关精神及《关于开展2026年本科生集中考核转专业工作的通知》的相关要求，特制订外国语言文化学院2026年本科生集中考核转专业工作实施细则：

一、组织领导

1.学院成立2026年本科生转专业工作小组：

组长：潘海英

组员：房颖、陈慧羲、孙明丽、李丽、金晶、张蕊

2.学院成立2026年本科生转专业监督小组：

组长：张国兴

组员：王英娜、刘垣菲、宋婷、张宁宁、金明艳、李晨溪（2023级学生）

二、接收计划

根据学校文件规定及学院实际情况，2025级普通专业拟接收人数不低于2025级招生人数的20%，双学位专业拟接收人数不低于2025级招生人数的30%，2024级各专业拟接收人数不低于2025级招生人数的10%，具体如下:

三、报名条件及要求

    学院对拟申请转出的学生不设置转出比例及资格限制，但应满足《吉林大学本科学生转专业工作管理办法》第三章的转专业基本条件。

申请转入我院各专业的学生除需符合《吉林大学本科学生转专业工作管理办法》规定的基本条件外，还需符合以下条件：

1.身体条件符合转入专业高考录取体检的有关要求；

2.大学外语水平需达到C级及以上（包括免修级）；

3.自学生入学至转专业前，所有学期的必修课及限选课课程考核成绩全部合格；成绩排名在学生原专业前70%。成绩排名以第一次考试成绩为准，重修、加分的成绩不参与排名计算。经本科生院批准的缓考、补考成绩，按第一次考试成绩计算排名。

如学生在全国大学英语四、六级考试中取得600分及以上或在《吉林大学本科学生学科竞赛体系》外语类竞赛中获得国家级三等奖及以上，不要求专业排名。有以上成果的学生，可于3月4日-3月11日，将成果扫描件及排名证明发送至外国语言文化学院教学办邮箱616799124@qq.com。

5.不曾受过学业预警；

对申请转入的学生的转入年级做如下要求：

（1）2025级申报转入英语专业的学生，原则上平级转入，或根据学生本人意愿降级就读。2024级原则上转入新专业后应降级至2025级。

（2）2025级申报转入俄语、日语、西班牙语、朝鲜语、俄语+国际经济与贸易、日语+国际经济与贸易、朝鲜语+国际经济与贸易专业的学生，有相应语言基础的非零起点学生，可申请平级转入，或根据学生本人意愿降级就读。2024级原则上转入新专业后应降级至2025级。

（3）2025级申报转入俄语、日语、西班牙语、朝鲜语专业、俄语+国际经济与贸易、日语+国际经济与贸易、朝鲜语+国际经济与贸易的学生，无相应语言基础的零起点学生，转入后需降至2026级就读。

四、考核及录取

学院对申请转入的学生进行资格审核，所有通过资格审核的学生均需参加由外国语言文化学院组织的转专业考核。考核分为笔试和面试两个部分。具体要求如下：

1.申报英语专业：英语专业笔试科目为英语和中文作文，每门考试总分均为100分，各占转专业总成绩的30%；面试总分为100分，占转专业总成绩的40%。以上三门考试成绩都必须在60分以上（含60分），单科不及格者不予录取。

2.申报俄语、日语、西班牙语、朝鲜语、俄语+国际经济与贸易、日语+国际经济与贸易、朝鲜语+国际经济与贸易专业：有相应语言基础和相关知识（非零起点）的学生，笔试科目为申报专业语种外语和中文作文，每门考试总分均为100分，各占转专业总成绩的30%；面试总分为100分，占转专业总成绩的40%。以上三门考试成绩都必须在60分以上（含60分），单科不及格者不予录取。

3.申报俄语、日语、西班牙语、朝鲜语、俄语+国际经济与贸易、日语+国际经济与贸易、朝鲜语+国际经济与贸易专业：无相应语言基础（零起点）的学生，笔试科目为英语和中文作文，每门考试总分均为100分，各占转专业总成绩的30%；面试总分为100分，占转专业总成绩的40%。以上三门考试成绩都必须在60分以上（含60分），单科不及格者不予录取。

各专业均按转专业考核总成绩由高到低进行排名，并分别按2025级、2024级确定名单报本科生院汇总投档。具体如下：

学院在录取时如出现考核成绩同分的情况，则按照以下原则优先录取：

1.志愿优先。一志愿者成绩按100%计入，二志愿者成绩按90%计入，三志愿者成绩按80%计入。

2.GPA排名有先。考核成绩同分、志愿顺序一致时，有先录取GPA排名靠前者。

3.与志愿专业相关的竞赛获奖或学术成果，由转专业小组认定后，可根据成果类型及等级按一定比例加分，加分幅度不超过转专业考核成绩的3%。

五、日程安排

外国语言文化学院按照《关于开展2026年本科生集中考核转专业工作的通知》开展各阶段工作，具体时间另行通知。

六、其他

其他未尽事宜按照《吉林大学本科学生转专业工作管理办法》（校发〔2024〕201号）有关规定执行。
