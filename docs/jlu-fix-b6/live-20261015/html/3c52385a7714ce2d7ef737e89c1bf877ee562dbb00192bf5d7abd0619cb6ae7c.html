吉林大学通信工程学院胡云峰教授团队博士后招聘启事

发布日期 ：2026-07-29作者 ：点击 ：

吉林大学是教育部直属的全国重点综合性大学，坐落在吉林省长春市。学校始建于1946年，1960年被列为国家重点大学，1984年成为首批建立研究生院的22所大学之一，1995年首批通过国家教委“211工程”审批，2001年被列入“985工程”国家重点建设的大学，2004年被批准为中央直接管理的学校，2017年入选国家一流大学建设高校。

一、导师简介：

胡云峰，吉林大学唐敖庆领军教授，博士生导师，国家级青年学者，吉林省杰青，中国自动化学会预测控制与智能决策专委会委员。主持国家自然科学基金区域创新发展联合基金、科技创新2030-“新一代人工智能”重大专项－课题及吉林省重大科技专项－子项目等项目10余项。以第一责任作者在IEEE-CAA JAS、IEEE TII、IEEE SMC及《自动化学报》等期刊上发表论文80余篇，其中中科院一区论文21篇，授权国家发明专利60余件。

二、研究方向：

智能汽车决策与控制、迭代学习控制等。

三、招收类型及人数：

项目资助博士后，1人。

四、应聘条件：

1．具有坚定的政治立场，身心健康，年龄35周岁及以下，获得博士学位一般不超过3年，应届博士毕业生优先。

2．已初步选定科研团队或课题组，具备一定的科研能力和发展潜力。

3．满足合作导师或科研团队规定的其他条件。

4. 包括但不限于以下方向：智能汽车决策与控制、迭代学习控制等。

五、岗位职责：

1.复杂环境智能汽车自学习预测规划控制：研究交通参与者运动特性建模与预测方法、多车博弈交互机理与路径预测规划方法、预测规划算法在线自适应持续学习方法及划算法嵌入式系统高效实时计算与加速测试技术；

2.迭代学习预测控制在智能汽车规划控制中的应用：研究基于数据驱动的迭代学习预测控制方法，通过融合车辆运行数据与历史控制经验，构建自适应预测模型与优化策略，设计具有在线学习能力的控制算法，实现动力系统的高效节能控制。

六、薪酬待遇：

按《吉林大学博士后招收管理实施办法》（校发〔2020〕67号）文件执行。

七、申请流程：

1．填写吉林大学项目资助博士后申请书（一式两份）；

2．将两份申请书、学历学位证书以及相关科研证明材料报送至学校博士后流动站所在中层单位；

3．中层单位对申请人资格进行审查、组织考核；

4．将拟聘人选名单经博士后流动站所在中层单位领导签字后加盖公章，报送学校博士后工作办公室审核；

5．中层单位进行结果公示（5个工作日）；

6．准备进站材料，办理进站手续。
