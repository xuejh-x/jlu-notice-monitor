吉林大学动物医学学院2027年推免生招生录取工作实施细则

信息来源： 发布日期：2026-09-15

为了确保我院2027年推荐免试攻读研究生（以下简称“推免生”）的招生录取工作规范有序，根据教育部关于推免生相关文件及《吉林大学2027年推荐免试攻读研究生招生录取工作办法》等文件精神，结合我院推免生招生录取工作实际，制定本实施细则。

一、工作原则

坚持科学方法，选拔优秀人才；坚持全面考察，注重客观评价；坚持公正公开，维护考生权益。

二、组织管理

成立学院2027年推免生招生录取工作领导小组、复试小组、资格审查小组、监督检查小组。

三、申请条件

（一）硕士生

1.拥护中国共产党领导，遵纪守法，品德良好。

2.具有所在学校推免生资格的优秀应届本科毕业生。

3.学术研究兴趣浓厚，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

4.不存在考试作弊和学术不端行为。

5.身体和心理状况符合国家和招生单位规定的体检要求。

6. 满足本专业目录中规定的报考条件

（二）直博生

1.拥护中国共产党领导，遵纪守法，品德良好。

2.具有所在学校推免生资格的优秀应届本科毕业生。

3.学习成绩优秀，对学术研究有浓厚兴趣，有较好的专业素养，有较强的创新意识和创新能力，有较高的培养潜质。

4.不存在考试作弊和学术不端行为。

5.身体和心理健康状况符合国家和招生单位规定。

6.有至少两名所报考学科专业领域内的教授(或相当专业技术职称的专家)的书面推荐意见。

7.满足本专业目录中规定的报考条件

三、申请程序

具有推荐免试资格的考生，须在国家规定时间内登录“全国推荐免试攻读研究生（免初试、转段）信息公开暨管理服务系统”（网址：https://yz.chsi.com.cn/tm）填报志愿并参加复试。

（一）提交材料

1.《吉林大学2027年接收推荐免试研究生申请表》扫描件。

2.加盖所在学校教务部门公章的本科期间成绩单扫描件。

3.在校期间发表的论文、获得专利的证书、研究成果证明、获奖证书、外语水平考试证书以及长期有效第二代居民身份证等材料扫描件。

4.申请直博生须提交两名所报考学科专业领域内的教授(或相当专业技术职称的专家)的书面推荐意见扫描件。

推免生请于2026年9月21日16:00之前，通过预报名系统https://yzbbm.jlu.edu.cn/  进行报名，同时以上材料原件扫描制成一个压缩包，发送到邮箱364190792@qq.com，邮件请体现“姓名-学校-推免硕士/直博生”。如个别同学在9月24日前不能准备齐全，请先尽可能提供已有材料，缺失材料或暂时无法盖章请在邮件中说明原因，补齐后尽早发到邮箱。

我院2026年学术活动开放日成绩合格的同学，无须再提交材料和参加复试，但需以邮件形式确认报考信息。

考生须承诺申请材料的真实性和准确性。不符合条件者将被取消复试资格。未进行资格审查或资格审查未通过的考生一律不予录取。对弄虚作假者，取消其复试、录取资格。

（二）复试流程

1.资格审核。学院组织推免生资格审核。

2.参加复试。学院预计在2026年9月22日组织复试，复试采用网络远程复试方式，具体以学院后续复试通知为准。复试主要考察学生历年的学习情况，考核学生的外语运用、综合素质、创新能力、业务水平以及其它特长。考生可准备3-5分钟自我介绍PPT，包括个人情况、本科成绩、科研情况等。复试时保证网络畅通，通信畅通，请熟练掌握腾讯会议中共享和结束共享PPT的操作。

3.信息查询。复试时间、要求等具体信息，可在吉林大学动物医学学院网站和招生QQ群查询。

申报学生请加QQ群2027吉大动医研招群（894466163），“姓名-本科院校”实名申请进群。暑期加过“学术活动开放日群”的同学，不用再加此群。

（三）复试内容

1.专业素质和能力包括：大学阶段学习情况及成绩；全面考核推免生对本学科（类别）、专业（领域）理论知识和应用技能掌握程度，利用所学理论发现、分析和解决问题的能力，对本学科（类别）发展动态的了解以及在本专业（领域）发展的能力；创新精神和创新能力；科学精神、学术道德和专业伦理。

2.综合素质和能力包括：思想政治素质和品德考核，内容应包含推免生的政治态度、思想表现、道德品质、遵纪守法、诚实守信等方面；本学科（类别）、专业（领域） 以外的学习、科研、社会实践（学生工作、社团活动、志愿者服务等）或实际工作表现等方面的情况；心理健康情况等。

3.外语听说能力测试

由复试小组自行组织，主考教师由精通外语的教师担任，开展外语听说能力测试。

（四）成绩录取

1.复试成绩满分100分，60分以上（含60分）为合格。复试成绩取整数分值（保留小数点后两位）。复试不合格者不予录取。

2.拟录取推免生严格按照复试成绩由高到低择优录取。

3.思想政治素质和品德考核结果作为录取的首要依据，考核不通过者不予录取。

4.拟录取推免生在规定时间内通过“全国推荐免试攻读研究生（免初试、转段）信息公开暨管理服务系统 ”完成网上“ 同意待录取确认 ”。

四、信息公开

我院在本单位网站提前向社会公布推免生招生录取工作实施细则及进入复试推免生名单，公示拟录取推免生（含直博生）名单，名单包括推免生姓名、复试成绩、拟录取专业等信息，公示期为3 天。
