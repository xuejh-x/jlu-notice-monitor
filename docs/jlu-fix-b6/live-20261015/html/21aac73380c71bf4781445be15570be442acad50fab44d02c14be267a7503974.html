计算机科学与技术学院党委书记宫皓宇为2024届毕业生讲授“最后一次党课”

发布日期：2024-07-09 发布人： 点击量：

为扎实推进党纪学习教育，进一步强化毕业生党员教育，激励毕业生党员争做有理想、敢担当、能吃苦、肯奋斗的新时代好青年，在毕业生群体中充分发挥模范带头作用，6月20日下午，计算机科学与技术学院、软件学院2024届毕业生党员“最后一次党课”在王湘浩楼A108报告厅成功举办。学院党委书记宫皓宇、党委副书记张达鑫、毕业生辅导员、各学生支部书记以及全体2024届毕业生党员参加了本次活动。活动由党委副书记侯晓宇主持。

会议伊始，宫皓宇以“严守党纪践初心·奋发有为担使命”为主题，为毕业生党员送上了一堂内容丰富的党课。他从党纪学习教育整体部署安排、党纪学习教育需明晰的几个方面、“条例”制定和修订过程、修订重点和意义、党的纪律建设历程、示例等方面，结合当前国家发展大局和青年成长成才的需求，勉励毕业生党员以“五要”加强终身教育：一要坚定共产党人理想信念；二要牢固树立党的意识、党员意识；三要强化党的宗旨意识；四要积极践行社会主义核心价值观；五要始终做到心中有戒。在授课的最后，宫皓宇同志祝福各位毕业生党员发展越来越好，以实际行动和更加优异的成绩为党旗和母校增辉！

最后，计算机科学与技术学院毕业生党员代表郭泽阳同志带领全体党员面向党旗庄严宣誓，在铮铮誓言中重温入党初心，坚定理想信念，牢记职责使命。
