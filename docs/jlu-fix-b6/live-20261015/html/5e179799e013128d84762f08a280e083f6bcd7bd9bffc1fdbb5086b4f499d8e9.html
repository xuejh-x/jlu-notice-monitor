【招聘信息】影子科技2025“万有影力”校园招聘

发布时间：2024-10-12 点击：次

分享：

一、单位名称：广州影子科技有限公司

二、单位介绍：广州影子科技有限公司为扬翔股份互联网事业部，于2018年6月成立，致力于成为农场到餐桌全产业链智能化解决方案服务商。利用基因科学、区块链、人工智能等技术，驱动产业链智能化转型升级。旗下拥有深圳数影科技有限公司、深圳万德厨科技有限公司、武汉影子基因有限公司、南宁影子信息科技有限公司、贵港万得科技有限公司等多家子公司。团队已逾600人，在广州、深圳、武汉、南宁、贵港等地建立研发中心；拥有60多款自主设计制造的AIoT智能硬件设备、53项自主研发的软件系统及平台应用，已获授权专利115项。2023年获评“高新技术企业”；2024年当选广东省人工智能产业协会理事单位。
