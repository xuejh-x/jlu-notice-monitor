第十四届CALYPSO研讨会（第三轮通知）

时间：2026-10-10 10:34:33 点击：

随着近年来第一性原理计算和材料结构预测方法的快速发展，只根据给定化学组分的材料结构预测已经成为可能，并迅速成为国际热点，在三维晶体材料、二维层状材料、二维表面重构、零维团簇和功能材料的结构设计等方面取得了一批原始创新性成果。未来材料结构预测研究的创新式发展将有力推动我国物理、化学、材料、信息、地球、生物、工程等学科的发展，为我国国民经济的发展和国防建设做出贡献。

基于群体智能的CALYPSO材料结构预测方法和软件（详见 http://www.calypso.cn ），是我国自主创新发展的方法与系统。它不仅能够仅依据化学组分开展晶体、表面（含二维单/多层材料）、界面、团簇、吸附及过渡态的微观原子结构预测，实现功能导向（如能隙、硬度和电子密度等）的逆向材料设计，更在人工智能与数据基础设施驱动下实现了全面演进与跨越。目前，CALYPSO已深层次融入AI生成模型与高质量数据基础设施：通过整合CrystalFlow晶体生成模型与ApolloX非晶体材料生成模型，构建了涵盖晶体与非晶材料的多模态结构生成与智能搜索体系；结合Synthmind合成可能性及工艺设计模型，将传统的结构预测进一步延伸至材料的可合成性评估与工艺路线设计；同时依托高压晶体结构数据库（HPCSD）等核心数据基础设施，形成了“数据驱动—AI生成—结构预测—合成引导”全链条一体化的材料创新设计新生态。

CALYPSO软件学术使用免费，已经被79个国家和地区的5300余位同行签订版权协议使用。截止目前，国内外同行使用本软件已经在Nat. Chem.、Nat. Commun.、Sci. Adv.、PRL、PNAS、JACS等高水平学术期刊发表了2400余篇学术论文，解决了一系列与凝聚态物质结构密切相关的科学难题，设计了多种高温超导体、超硬材料和高效能量转换功能材料。

由吉林大学高压与超硬材料全国重点实验室、吉林大学物质模拟方法与软件教育部重点实验室和吉林大学物理学院联合主办，苏州大学能源学院承办的第十四届CALYPSO研讨会将于2026年10月16日-10月19日在江苏省苏州市召开。

一、会议专题

(a) 物理、化学和材料等领域计算模拟前沿研讨专题：国内顶尖计算领域的科学工作者聚焦国际计算前沿开展专题讲座；CALYPSO主创成员将针对CALYPSO方法原理、软件功能以及最新进展进行专题汇报。

(b) CALYPSO软件上机学习专题：精心设计了CALYPSO计算实例演示与同步上机练习。练习包括以下内容：CALYPSO在晶体、二维层状材料、团簇结构设计中的应用；机器学习加速的结构预测；晶体结构生成模型；晶体势能面解景观表示等。

二、会议注册

会议注册网站开放至2026年10月15日，敬请各位参会人员注册参会（注册网址：https://jsj.top/f/xrik2S）。同时，欢迎各位老师和同学通过海报形式交流最新研究成果。研讨会将评选最佳海报奖，并颁发证书和奖金（海报尺寸为80cm×120cm（竖版），请自行制作带至现场张贴，同时将海报信息发送至邮箱：zyh@calypso.cn，截止时间：2026年10月10日）。
