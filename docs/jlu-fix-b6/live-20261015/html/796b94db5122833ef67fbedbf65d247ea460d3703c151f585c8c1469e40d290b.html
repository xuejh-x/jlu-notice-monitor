东北亚国别与区域研究高端讲坛——“第三只眼看中朝关系”

日期：2021-06-16 点击数：

2021年6月11日，应吉林大学东北亚研究中心、东北亚学院、东北亚研究院共同邀请，韩国庆南大学极东问题研究所李相万教授以“第三只眼看中朝关系”为主题作了线上学术报告，吉林大学东北亚学院、东北亚研究院院长吴昊出席本次论坛并致辞。吴昊院长表示，这是吉林大学东北亚学院成立以后举办的首次高端学术讲座，有幸请到李相万教授作第一次报告，希望同学们能够充分交流、有所收获。本次讲座由吉林大学朝鲜韩国研究所所长张慧智教授主持。

李相万教授现为庆南大学极东问题研究所（IFES）中国中心主任，是韩国东国大学政治学和中国人民大学政治经济学双博士，曾在韩国忠北大学和中国西北政法大学任特邀教授，同时也是韩中社会科学研究会会长、韩中社会科学研究会执行编辑，对中国的政治经济、东北亚战略和中美关系有深入研究。

李相万教授本次报告围绕朝鲜半岛问题，特别是中朝关系的发展历程、特点、前景进行了深入浅出的分析，并提出了独到见解。他强调，朝鲜半岛问题是东北亚地区热点问题，无论是过去、现在抑或是未来对东北亚地区和平与发展具有重要影响。报告内容反响热烈，我院师生与李相万教授就报告主题进行了精彩的讨论，同学们一致认为讲座受益匪浅，拓宽了学术视野。

东北亚国别与区域研究高端讲坛是东北亚研究中心、东北亚学院和东北亚研究院共同策划的系列高端学术讲座，将邀请东北亚各国的知名学者围绕东北亚地区或国别的政治、经济、社会等主题发表研究成果，为关注东北亚问题研究的师生们带来最新的国际学术信息和多样的观点。
