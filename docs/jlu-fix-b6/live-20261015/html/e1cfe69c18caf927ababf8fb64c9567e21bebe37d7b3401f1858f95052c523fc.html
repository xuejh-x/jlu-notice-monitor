文学院2027年接收推荐免试攻读研究生（含直博生）复试成绩及拟录取名单公示（三）

发布日期：2026-09-20 作者： 点击：

一、现将吉林大学文学院2027年接收推荐免试攻读硕士研究生（含直博生）复试成绩及拟录取名单（三）进行公示，详见附件。如对复试成绩有异议，请于三个工作日内实名向文学院研究生办公室反映。联系方式：石老师 0431-85166006。

二、学校将在9月22日发送“复试通知”，9月24日发送“待录取通知”。拟录取考生务必在规定时间内完成网上填报志愿，请随时关注报名系统和短信提醒，及时点击确认“参加复试”和点击“确认录取”，完成最终录取工作，逾期则视为自动放弃。
