关于公示吉林大学2022-2023学年“一汽丰田·筑梦行动”资助拟推荐名单的通知

日期：2022-10-10 点击数： 来源:

根据学校《关于在本科生中开展2022-2023学年“一汽丰田·筑梦行动”资助工作的通知》要求，经学生本人申请，学院评议审核，推荐林可、孙海鑫同学为“一汽丰田·筑梦行动”资助候选人，特此公示。

公示期为五个工作日，如有异议，请向学院学生工作办公室反映。
