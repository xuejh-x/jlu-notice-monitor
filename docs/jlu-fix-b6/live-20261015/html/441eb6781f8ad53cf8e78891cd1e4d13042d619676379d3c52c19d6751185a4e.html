正大集团山东区猪事业招聘简章

发布日期：2016-10-18 作者： 点击：

总部设在泰国曼谷的正大集团（Charoen Pokphand Group）始创于1921年，目前是亚洲领先的综合性企业集团之一。集团及其下属公司涉及农牧、食品、零售、电信、地产、机车、制药、传媒、金融等行业，业务遍及中国、东南亚、东北亚、欧洲、美国等个国家和地区。

正大集团山东区猪事业有四家公司，分别在青岛即墨、潍坊高密、聊城东昌府、东营垦利县四地。分别有东营4800头种猪场1个，即墨3100头种猪场1个、即墨2400头种猪场1个、高密3100头种猪场1个、聊城1200头种猪场1个及其配套育肥场近二十个（另有多个在建猪场），养殖场采用现代化管理，先进的自动化设备，降低了人工工作量，采用自动喂料、自动喂水、自动温控湿控等。同时公司为所有员工提供优良的食宿条件，宿舍为标准两人间，宿舍内配有有线电视、空调、暖气、网络、橱柜、洗刷洗浴间、洗衣机等等。员工宿舍区配有休息室、棋牌室、篮球场等等，为员工提供良好的娱乐设施。提供免费三餐，饭菜质量好、品种多。员工福利好，收入稳定，当月发放工资。
