吉林大学行政学院2026年全日制博士研究生“申请考核制”（第四批） 网上补报名的通知

发布时间: 2026-05-29点击:

各位考生同学：

根据吉林大学行政学院政治学理论专业博士研究生“申请考核制”招生计划，现决定于2026年5月30-6月1日（每日8点—18点）开放博士研究生网上报名，请报名的考生及时登陆吉林大学招生网进行网上报名（网址http://zsb.jlu.edu.cn/）及缴费。

报考“申请考核制”的考生须提前联系招生导师（导师邮箱详见行政学院官网-队伍建设），报考具体要求及内容详见行政学院官网2025年11月14日发布的“吉林大学行政学院2026年博士研究生“申请考核制”招生实施细则”（https://adm.jlu.edu.cn/info/1121/29753.htm）。 符合报名要求的考生须于2026年6月1日（周一）晚18:00前将报考材料电子版发至指定邮箱，2026年6月2日（周二）中午12点前将报考材料纸质版用顺丰速运或EMS邮政快递邮寄到行政学院研究生办公室，截止时间前未能按通知要求提交全部材料者不计入报名序列。拟报名考生请加入QQ群进行咨询，群号为237445853。

进入综合考核的考生，请参照吉林大学行政学院2026年全日制博士研究生招生综合考核工作安排（https://adm.jlu.edu.cn/info/1121/29843.htm）做好相应准备，综合考核时间另行通知。
