化学

 本专业学科门类为工学类，所属仪器科学与技术为国家级一流本科专业建设点、吉林省高水平学科，列入吉林大学“地质资源与地质工程”“双一流”学科群建设；研究方向包括：1.精密测控与智能仪器研发；2.地球物理探测仪器与传感技术；3.智能感知与光电检测及AI融合应用。国家一流课程2门，多次获国家级、省级教学成果奖，核心特色课程涵盖传感器原理与检测技术、智能仪器、精密仪器设计、地球物理探测仪器设计基础等，有双语教学课程《仪器科学导论》《智能传感技术》；与丹麦奥胡斯大学、澳大利亚悉尼科技大学、台湾逢甲大学等多所高校有交流项目。建设有中国第一汽车制造集团、长光卫星等20余个实习实践基地，实现实习实践全覆盖。 吉林大学是我国最早建设仪器类相关本科专业的高校之一，1961年便开始招收地质电子仪器专业本科生，是我国地球探测技术及仪器高层次人才培养的基地和摇篮。师资实力雄厚，现有目前有中国工程院院士1人，双聘院士2人，全国优秀教师、长江学者特聘教授、国家优秀青年基金获得者等国家级称号人才5人，教授35人、副教授36人，90%以上的教师拥有博士学位，形成了一支兼具科研与教学能力的高水平师资队伍。拥有仪器科学与技术等优势学科，入选吉林省“十三五”高水平学科A类，依托“地质资源与地质工程”一流学科群，建设有深部探测与成像全国重点实验室、国家地球物理探测仪器工程技术研究中心、地球信息探测仪器教育部重点实验室等国家级实验基地，以及吉林省仪器电气实验教学中心等实践平台。本科毕业生去向主要包括华为、大疆、中国第一汽车集团、航天科技集团等国内外知名企业，同时约40%以上毕业生进入清华大学、北京航空航天大学等知名高校或科研院所攻读研究生，就业率近100%，社会认可度极高。学院大力支持基础学科与新兴学科交叉，深化“以赛促学、以赛促教、以赛促创”育人模式，多支学生团队斩获“TI杯”全国大学生电子设计竞赛一等奖、“西门子杯”中国智能制造挑战赛一等奖、高校电气电子工程创新大赛全国特等奖等国家级比赛大奖。

电气工程及其自动化












物理












化学

 本专业学科门类为工学‌类，为国家级一流本科专业建设点。研究方向包括：1电磁场数值模拟与测量技术‌；2脉冲功率源与控制技术；3电气装备智能化及车辆智能控制与测试技术。国家级一流本科课程2门，多次获国家级、省级教学成果奖，核心特色课程涵盖电力系统分析、电力电子技术、电机学等，有双语教学课程信号与系统。拥有电力电子技术、电机与电力拖动与控制、可编程控制技术、微机继电保护、高电压技术等多个专业实验室；在国网吉林省电力有限公司、大连红沿河核电站、大唐集团长春第二热电有限责任公司、吉林丰满水电站、长春市合心变电站、吉林长岭风电场等地建立了校外实习基地和联合实验室，拥有吉林省仪器电气实验教学中心、吉林省电子电工实验教学中心、吉林省仪器电气大学生课外创新示范基地等多个实践教学平台。 本专业师资实力雄厚，现有国家级、省部级人才6人、教授22人。电气工程学科入选吉林省十三五优势特色学科，目前承担和参与多项国家省部级项目，主持多项吉林大学的教学改革项目，以培养从事与电气信息相关领域的宽口径“复合型”人才为培养目标，强化电工理论基础课程，强调强弱电相结合，突出电气特色。创建了阶段性实验，分层次、多元化、综合性短学期实习、自主性毕业设计、创新性电子竞赛、开放性创新项目、本科生科研训练项目等多种实践方式相结合的电气特色实践环节体系，学院大力支持基础学科与新兴学科交叉，多支学生团队在电子设计等学科竞赛中取得了优异成绩。推荐和考入清华大学、西安交通大学、哈尔滨工业大学、华中科技大学、中国科技大学等全国著名高校的研究生，本科毕业生去向主要包括国家电网、中车长春轨道客车股份有限公司等知名企事业单位。
