关于赴辅仁大学法律学院进行交换学习的选拔通知
发布者：国合办     发布日期：2018年03月14日 18:10     点击数：
各位法学院同学：

    为了进一步加强我院学生与台湾地区学生的交流互访，经我院与辅仁大学法律学院协商决定，从我院选派五名硕士研究生，于2018年9月赴辅仁大学法律学院进行一个学期交换学习。

     报名注意事项：

    1、身份证原件及复印件、学生证原件及复印件

    2、研究生在读证明

    3、交换期间交通、食宿、课本等费用自理

     请感兴趣的研究生同学于发布通知之日起，到4月6日截止之前，到法学院研究生办公室（东荣大厦A311室）进行报名。

      选拔及面试时间、地点另行通知。
