关于公开选拔汽车工程学院团学组织2026-2027学年各部门负责人的通知

日期：2026-09-29 14:36:15 作者： 访问量：

共青团吉林大学汽车工程学院委员会下属本科生分团委、学业支持中心、宣传中心和公寓管理与服务学生委员会四大学生组织，是在校团委指导下学生自我管理、自我教育、自我服务的群众性组织，是学院联系学生的桥梁和纽带，为学院发展与建设作出了积极贡献。为了将习近平总书记关于青年工作的重要思想落实到团的全部工作和建设之中，加强学院学生工作队伍建设，更好地服务广大青年，共青团吉林大学汽车工程学院委员会将开展2026-2027学年各部门负责人选拔工作。本次换届工作秉持公平公正、择优录取的原则，旨在选拔德才兼备、品学兼优的学生干部带领学生组织更好的服务于广大同学。现将相关事宜通知如下：

一、报名条件

1. 原则上要求为汽车工程学院2024级全日制在籍本科生；成绩优异，原则上无挂科现象，无违纪处分；

2. 应具备学生工作经历和社会实践经历，并有良好表现；

3. 拥护中国共产党的领导，坚持四项基本原则，认真学习贯彻习近平新时代中国特色社会主义思想，具有坚定正确的政治立场和较高的政治素养；

4. 品行端正、诚实守信、团结同学，服务意识强、群众基础好，具有优良的道德素质、健康的心理素质和强烈的责任感；

5. 有较强的组织领导和沟通协调能力，以及较强的文字功底和语言表达能力，具有良好的团队意识和奉献精神，有较为充足的时间承担学生组织各项工作，能够保质保量地完成各项工作任务；

6. 有大局意识、团队意识和服务同学的热情，在学习和生活上能够严格要求自己，以身作则，起到带头模范作用。

二、选拔流程

1. 按照要求填写《吉林大学汽车工程学院团学部门负责人选拔报名表》（下称“报名表”），于2026年10月7日16：00之前，将电子版报名表和佐证材料发送至邮箱2803186557@qq.com，并将报名表和邮箱主题均命名为“申报岗位（第一志愿）+姓名+年级”，逾期不予受理。面试资格及时间地点安排将以院内通知形式告知。

2. 请获得答辩资格的同学按照学院通知的时间地点参加面试答辩，答辩时，可选择结合PPT进行竞聘陈述，限时3分钟。
