研究生教育

首页 >> 人才培养 >> 研究生教育
  • 研究生教育
  • 本科教育

实验室秉持培养创新人才为本，教学科研协调发展，强化人才实践能力，历经近二十年的发展，形成了高水平的从本科到博士、博士后的高级人才培养体系。建设了教学科研一体化教学团队，科研成果及时向教学转化，科研项目支持学生创新实践，教学科研实验室开放共享，学生直接参与重大科研项目，努力提升学生系统分析问题的能力、对基础知识深入理解及严谨的表达能力、科学论证的能力和发现新问题的能力，培养的学生得到了用人单位的广泛好评。

实验室还着重培养和支持一批学术基础扎实、具有创新能力和发展潜力的中青年人才，鼓励和支持青年教师出国深造，培养了一批具有国际合作和交流能力的青年学者。同时，实验室还特别注重研究生教育和科学素质的培养，每年为国内外大专院校、科研单位和社会各界输送了大批优秀的博士后、博士和硕士毕业生。
