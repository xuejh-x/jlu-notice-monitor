人才培养

本学科承担本科、硕士和博士研究生培养任务，吉林大学已从2009年开始招收本科生，每届50名。每年招收兽医公共卫生方向的硕士研究生20-30名，博士研究生（人兽共患病方向和动物性食品安全方向）7-10名。
