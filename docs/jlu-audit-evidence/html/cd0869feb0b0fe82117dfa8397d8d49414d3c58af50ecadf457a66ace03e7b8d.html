“网络安全学院学生创新资助计划四期”申报通知

发布日期：2026年05月12日 15:15 浏览量：

在中央网信办指导下，网信企业、一流网络安全学院、中国网络空间安全协会、中国互联网发展基金会共同发起网络安全学院学生创新资助计划（以下简称“创新资助计划”），为积极申报该计划，学院通知如下：

（一）报名事项

报名对象：学院的全日制在读本科生、硕士生、博士生。

报名时间：2026年5月12日－ 6月12日

报名方式：网上报名（有兴趣的同学请先加入项目申请的QQ群：565878311)。

报名须知：

1. 报名学生为中国籍（含港澳台学生）；

2. 报名学生不能是其他企业定向培养的学生；

3. 项目研究周期一般为一年，报名学生应保证在本校时间能覆盖研究周期；

4. 符合申报条件的资助对象可个人申请或组队申请，但每个研究团队人数不超过3人（含项目责人），且每名同学只能加入一个学生研究团队。采取组队申请，应选出一名队长，由队长作为代表进行申请，附团队登记表；申请人负责项目工作和经费的分配和管理，建议在学院指导下，团队内部签署任务分配与经费分配协议书。

5. 本培育项目与校内其它支持项目不冲突、不互斥。

（二）项目申请和初审

1.任务项目发布

资助计划三期的创新任务已全部发布在网络安全学院学生创新资助计划平台，本年度六家资助企业共提出107项创新任务。教师学生可在QQ群中看到查看网站方式。

2.任务项目申请

各学院组织学生参与申报，学生申请须填写《任务申请书》，并附相关证明材料；学生自由选择项目，可以多人选择同一项目。每项任务平均资助1-4名学生。学生申报时通过平台可以看到该课题已申报人数，建议不要扎堆儿申报。

每个学生研究团队可自愿（非必选）在学院内寻找一名相关领域教师作为指导教师，负责指导学生选择创新任务、制定实施方案、填写创新项目申请书，对课题研究进行指导，并对项目的阶段性汇报进行初审。为本科生申报创造条件，同时硕士、博士研究生结合研究方向、时间要求等情况综合考虑，在征求导师同意后再申报。

需要说明：

（1）《任务申请书》可从资助计划平台上下载。包括承诺书和申请书两部分，承诺书由学生签字，任务申请书由学生填写，在推荐院校意见处由学院院长签字并盖章。《任务申请书》须以附件形式上传至申报资助计划平台，作为申报材料的必选项。

（2）按照企业项目任务书描述，部分任务要求学生到企业实习或可实习者将获得优先立项。请学生认真阅读项目任务书要求。

3.学院初审

学院组织项目初审，对项目申请人提出的申报材料真实性、完整性，研究计划可行性，研究方案的原创性等进行审核把关。

学院视情况对项目申请人提出的研究计划创新性、先进性以及其工作基础、技术路线等进行综合评选和推荐度排序，推荐意见可填写在《任务申请书》“推荐高校意见”中，作为企业立项评审的参考。填写《项目申请汇总表》并提交至项目办。

需要说明：学院初审完成后，为符合条件的学生在《任务申请书》上盖章。学院平台管理员为学生开通账号，由学生自行通过资助计划平台提交项目申请。

4.经费管理

每位获得资助的学生可获得税前6万元资助，其中：各企业按照每位学生5万元（税前）的标准进行项目资助。资助企业根据立项情况，与资助学生签订协议并一次性拨付资助经费。中国互联网发展基金会网络安全专项基金对每个获项目资助学生配套资助经费1万元（税前），学生按照专项基金要求提供相关材料。经费用于开展项目研究，由获资助学生负责管理使用， 按照企业与资助学生签订的合同执行。

（三）学院安排

1.报名加群

有申报意愿的同学加QQ群，后续通知都在QQ群中。

2.学院初审

学院将在6月初举行学院初审会，具体时间地点在QQ群中通知，每个申请的同学参加答辩，确定学院推荐意见。

3、联系人

学院此项工作联系人为刘宇舟副教授，

联系方式：18166855855 （QQ：411196535）。
