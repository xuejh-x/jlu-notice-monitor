研究生办公室工作职责
¤ 负责各类研究生招生、录取、教学和学位授予等培养全过程的管理工作；
¤ 负责在站博士后的管理工作；
¤ 负责学位授权点的申报、学位与研究生教育质量评估及相关工作；
¤ 负责研究生日常思想政治教育，在院党委领导下进行研究生党建工作；指导研究生团委和研究生会工作；
¤ 负责研究生学籍管理、奖惩、奖学金核定，各类补贴、困难补助的审批上报工作；
¤ 组织召开学科学位评定分委员会会议，完成博士生、硕士生指导教师选聘工作；
¤ 组织召开学科学位评定分委员会会议，审核学院本年度博士、硕士学位授予、优秀学位论文推荐工作；
¤ 完成学科学位评定分委员会交办的工作；完成学院领导交办的其他工作。
