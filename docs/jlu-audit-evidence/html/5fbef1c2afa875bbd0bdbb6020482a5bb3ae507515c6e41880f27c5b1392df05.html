实验室简介
实验室以病理学系为基础，应用现代生命科学的理论与技术，研究疾病发生发展过程中的形态、机能和代谢变化，为人类疾病的诊断、治疗、预防和预后判定提供理论依据和应用技术。实验室2002年批准筹建，2003年通过验收，2005年、2010年和2016年3次通过评估，结果均为良好类。实验室先后成为吉林大学国家“985工程”和“双一流学科”建设单位。紧绕国家重大需求，以平台的优势研究为基础，与病理学的学科内涵相契合，实验室逐步形成了独具特色的干细胞组织工程与再生医学、恶性肿瘤早期诊断与治疗的分子机制、心脑血管及代谢性疾病的病理生物学、重大及新发传染性疾病的基础研究与转化等四个主要研究方向。在2017世界Nature Index Tables排行前100的科...
