吉林大学2026级研究生新生入学须知

更新时间：2026-06-25 点击次数：次

亲爱的2026级研究生同学：

欢迎来到吉林大学继续深造，为确保同学们顺利办理入学手续，现将报到相关事宜通知如下：

一、请持新生入学报到证、毕业证书、学位证书和有效身份证原件于2026年9月5、6日来校报到（卓越工程师学院（全日制）、卓越工程师学院（珠海）、珠海研究院及学科交叉创新中心研究生到校本部各相应培养单位报到，卓越工程师学院（非全日制）研究生到卓越工程师学院报到）。因故不能按期入学，请事先向研究生培养单位（以下简称培养单位）研究生办公室提出书面申请，延期入学时间最长为两周。若未请假或请假逾期两周不报到，除不可抗力等正当事由外，将被视为自动放弃入学资格。

二、根据国家规定，新生可自愿迁移户口（定向培养的新生不迁户口）。如若迁移户口，户口迁移证上的内容不得涂改，户口迁移证上的姓名、性别、身份证号码必须与录取通知书和考生本人档案一致。户口迁入的地址各专业一律填写“吉林省长春市吉林大学”，其中“婚姻状况”一栏必须要填写清楚。新生报到时，将身份证与录取通知书上下合并复印在1张A4纸上，与户口迁移证原件一并交到所在培养单位研究生办公室，由各培养单位研究生办公室负责老师与各校区户籍办老师联系办理落户手续。户口迁移材料收取时间暂定为2026年9月30日，如有变动另行通知。

三、党、团员必须带组织关系来校报到（在职的新生不转组织关系）。新生报到时，党员须到所在培养单位进行登记，经培养单位初审、学校复审合格后，方能办理组织关系转入手续。党组织关系转入的党员，其原所在党组织已开通“全国党员管理信息系统”的，可直接通过“全国党员管理信息系统组织关系转接子系统”网上转接。党员原所在党组织尚未开通“全国党员管理信息系统”的，须持“党员登记表”和“中国共产党党员组织关系介绍信”到入学所在院级党组织报到，“中国共产党党员组织关系介绍信”由可转接党员组织关系的党组织开具，“中国共产党党员组织关系介绍信”抬头为“中共吉林大学委员会组织部”。

团员须将团员档案直接寄到本人所在学院研究生办公室或报到时随其他材料一并上交，同时团员需在开学后一个月内完成“智慧团建”系统中团组织关系转接手续。

四、新生报到时须携带同一底片近期小二寸或一寸正面免冠半身蓝色背景照片四张。来校时须自备棉衣及被褥等日常生活用品。

五、新生赴校的途中路费、食宿费、物品托运费等均由本人自理。持“录取通知书”可购买半价火车票。

六、新生入学需缴纳学费、住宿费后方能申请注册，标准及缴费方式详见《吉林大学2026级研究生入学交费须知》（见附件1）。

七、家庭经济困难的研究生，可以在生源地办理助学贷款，也可在学校办理校园地助学贷款。如果经济困难暂时凑不齐学费、住宿费请在报到前登录吉林大学迎新网站（https://yx.jlu.edu.cn）填写吉林大学绿色通道申请，报到时持本人填写并签字确认的《家庭经济困难学生认定申请表》等相关佐证材料，经学校有关部门核实后，可以在缓缴学费、住宿费的情况下先期办理入学手续，待助学贷款发放后补齐相关费用。

八、新生入学期间请保管好个人财物，避免电信诈骗等情况发生。

九、研究生入学住宿相关事宜

1.需要在校居住的全日制研究生应提前到所在培养单位研究生辅导员（秘书）处申报床位，原则上学校不为非全日制研究生提供住宿，学生工作部学生公寓管理与服务中心将根据各学院报送信息分配住宿床位。因各校区学生公寓床位紧张，学生申请住宿后，原则上1年内不得退寝。

2.新生在报到前关注吉林大学迎新网站（https://yx.jlu.edu.cn），可以在“迎新报到”板块查看入住寝室地点。

十、定向培养研究生须于2026年9月10日之前将签订好的定向培养协议书寄（送）到录取培养单位研究生办公室。

十一、具体报到地点请咨询录取培养单位研究生办公室，其他未尽事宜也请与各培养单位联系。

十二、新生须在报到前（8月20日起）登录吉林大学迎新网站（https://yx.jlu.edu.cn）（用户名为新生录取通知书编号，密码为新生身份证后六位）或用手机扫描下方吉林大学迎新网站二维码进行线上预报到流程，阅读入学前相关注意事项，查询学号、班级等信息，同时填写个人预报到信息，并在报到当天于报到现场进行线下报到确认。如需了解更多信息，请登录吉林大学主页（http://www.jlu.edu.cn）查询，或拨打吉林大学校园服务热线0431-961946进行咨询。
