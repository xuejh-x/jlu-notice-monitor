# JLU Notice Monitor v0.7.4

Windows x64 通知抓取与客户端修复版本，保持现有应用标识、安装路径和数据目录兼容。

## 更新

- 修复通知列表误抓导航、正文整页回退、标题截断及发布日期混入活动日期的问题。
- 保留图片型正文的合法原始图片链接，补齐明确附件容器中的图片及其他附件类型；验证码下载入口保留原链接，不冒充下载成功。
- 适配就业网公开页面及已观察到的科研、团委等模板；未验收的新增候选继续禁用，不批量增加正式来源。
- Windows 使用原生可信证书链并打包必要 CA 数据，补充请求异常诊断；不关闭证书验证。
- 确定性 HTTP/权限/策略失败不重复重试，瞬时故障重试从原始 URL 重新校验跳转链。
- 统一识别教务栏目无权限提示。修复审计工具误删请求地址末尾斜杠的问题，保留正式来源身份规则。
- 搜索打开通知时保留列表筛选；分页外当前通知可临时展示并定位，阅读和收藏状态共享原缓存。
- 包含此前源码中的蓝桥杯单页监控和保留策略修复。

## 验证与边界

发布检查记录见 [0.7.4 发布验收](RELEASE_VERIFICATION_v0.7.4.md)。Windows 安装包同时提供 SHA-256 校验文件；未提供 Authenticode 签名。

OA 默认访问路径仍可能出现 TLS EOF，部分栏目需要权限，附件可能受验证码或 robots 限制。发布日期语义、历史分页、全部附件及真实 Cloud 运行仍按逐来源验收，不宣称全校已经支持。审计原始 HTML、运行日志、完整机器快照及本地私有配置不随源码上传，仓库报告中的本地证据路径可能仅在审计工作区存在。

## 升级

使用当前用户安装器覆盖升级，不提前卸载或删除数据。保留通知 ID、阅读/收藏状态、来源与监控基线；首次运行仍执行既有兼容初始化和保留策略。默认 365 天等已有保留规则可能清理过期通知，包含过期未读及收藏。升级前完整备份用户数据；不要用清空数据库解决错误。

此版本更新 GitHub 可下载安装包，不新增自动更新服务、不部署 Cloud、不修改系统网络配置。
