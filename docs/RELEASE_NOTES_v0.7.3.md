## 更新

- 新增蓝桥杯赛事信息单页监控来源，按最新届次及吉林大学组织、报名等重要章节检测实质变化，不监控大规模往届获奖名单。
- 首次成功检查只建立来源独立基线，不产生历史未读通知；后续变化展示实际修改内容，复用现有去重、分类、未读及原文跳转机制。
- 无官方发布日期的单页监控通知保留 `publish_date=null`，使用首次检测时间进行最新排序、首页最近通知和日期筛选；普通来源保持原有发布日期语义。
- 修复来源卡片手动检查的异步执行入口及短时任务完成后来源健康状态刷新。

## 数据与升级

- 本次新增功能不需要数据库 Schema Migration；基线使用已有 AppState，未改动既有数据库初始化/兼容逻辑。
- 安装器不携带用户数据库，不覆盖运行数据目录；来源配置和已读状态沿用原数据库。
- **既有保留策略仍会在程序启动/定时清理时删除超过配置保留期限的通知，默认 365 天，包括过期未读及收藏。** 这是 0.7.2 已有行为，不是本次新增；不得把安装器不删数据库等同于程序启动后所有历史记录绝不减少。升级前务必完整备份。
- 不自动修复历史 NEW/未读误报；不要通过删除数据库、重置基线或清空通知绕过升级问题。

## 本地监控限制

- 蓝桥杯监控需要本地后端运行并联网。完全退出桌面客户端后不继续监控，系统休眠期间不检查；恢复后可主动检查。
- 离线期间出现又撤回的网页变化可能无法检测。
- PostgreSQL 实机测试、Cloud 生产链路及本次 Windows 实际升级、原生通知验收尚未验证。
- 本轮不部署 Cloud、不启用自动更新，不改动用户真实数据；安装与发布均需用户后续确认。
